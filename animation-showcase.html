Animation & Motion Reference

Internal QA page — not linked from student navigation

dev only
What this page is for
Every motion pattern the platform uses, on one page, so timing and quality can be judged together rather than one lesson at a time. Change a motion token and check it here against all of them at once.

The three levels of motion

L1 · Micro-interaction

The interface acknowledging a touch. Hover, focus, button press, answer reveal. 120–200ms. Should be felt, not watched.

L2 · Educational transition

A component changing state: a node activating, a step advancing, a value changing. 200–320ms. Clearly visible, never distracting.

notice me 10

L3 · Educational simulation

The motion is the concept: order, flow, traversal, propagation. 520ms transformations, 760ms between narrated steps. Student-controlled.

see the diagram below

Duration tokens

Each bar runs for its own duration — press to compare

fast — below conscious notice; the interface simply responded. base — the shortest change the eye can reliably track. slow — an element entering or leaving a structure. deliberate — a transformation the student is meant to follow.

Easing

Easing carries meaning. Interface motion is eased; data travelling along a path is linear, because a value moving on a bus moves at a constant rate and easing it would misrepresent the mechanism.

TokenCurveUsed for
--ease-standardcubic-bezier(.2,.6,.3,1)General state change
--ease-emphasiscubic-bezier(.2,.9,.25,1)A change that must be noticed
--ease-entercubic-bezier(0,.7,.3,1)Element arriving — decelerates and settles
--ease-exitcubic-bezier(.5,0,.9,.3)Element leaving — accelerates away
--ease-flowlinearConstant-rate travel of data

What deliberately does not animate

14 of 22 diagrams stay static

Taxonomies, comparison tables and reference shapes are better still. Students screenshot them, print them and revise from them. Animation would add nothing and would cost the ability to take one in at a glance.

A beautifully animated but educationally unnecessary element should stay static.

Reduced motion

With prefers-reduced-motion: reduce:

  • Every CSS duration collapses to zero.
  • Step-revealed diagram elements render at reduced opacity instead of hidden, so the diagram still reads as one complete figure.
  • Narrated simulator sequences play out instantly and completely — every caption and output line is written at once. Less movement, not less teaching.
  • The pulse and travel primitives become no-ops.
