Grade 10 · Subject outline

Database Management System

डाटाबेस व्यवस्थापन प्रणाली

syllabus outline 7 units 64 theory hrs 4 credit hrs · 128 working hrs
What this page is

This is the complete official syllabus for this subject, taken straight from the CDC Computer Engineering curriculum (2078). Use it as your revision checklist — everything the written exam can ask comes from this list.

Full bilingual notes, simulators and a quiz for this subject are being written next, in the same style as Data Structure & OOP using C++.

यो पेज के हो

यो CDC कम्प्युटर इन्जिनियरिङ पाठ्यक्रम (२०७८) बाट सिधै लिइएको यस विषयको पूरा आधिकारिक सिलेबस हो। यसैलाई दोहोर्‍याउने चेकलिस्ट बनाउनुहोस् — लिखित परीक्षामा सोधिने सबै कुरा यही सूचीबाट आउँछ।

यस विषयका पूरा द्विभाषिक नोट्स, सिमुलेटर र क्विज क्रमशः लेखिँदैछन् — डाटा स्ट्रक्चर र OOP (C++) कै शैलीमा।

≡

Units and contents

युनिट र विषयवस्तु

64 hrs total
1

Introduction to Database System

डाटाबेस प्रणालीको परिचय
6 hrs
  • Concept of Data, Information, Database and Database Management System
  • Limitations of the File System
  • Advantages and Disadvantages of a Database System
  • Application of Database System
  • Types of Database Users
  • DBMS Architecture
  • Database Model
  • Database Schema
2

Entity Relationship Model (ER-Model)

ई–आर मोडेल
10 hrs
  • Introduction to ER-Model
  • Components — Entity, Weak Entity, Entity Set
  • Attributes and Types of Attributes
  • Relationship and Types of Relationship
  • Mapping Cardinalities
  • Keys in DBMS
3

Relational Model

रिलेसनल मोडेल
10 hrs
  • Introduction to Relational Model
  • Key Concepts — Tables; Tuple, Cardinality and Column; Attribute, Degree and Domain; Relational Instance; Relational Schema; Relational Key
  • Properties of Relations
  • Mapping ER-Model to Relational Model
4

SQL (Structured Query Language) Overview

SQL को सिंहावलोकन
14 hrs
  • Introduction
  • DDL — CREATE, ALTER, DROP, RENAME
  • DML — SELECT, INSERT, UPDATE, DELETE
  • DCL — GRANT, REVOKE
  • SQL Clauses — WHERE, AND, OR, WITH, ORDER BY
  • SQL Joins — Inner, Natural, Left Outer, Right Outer, Full Outer
  • SQL View
5

Relational Database Design

रिलेसनल डाटाबेस डिजाइन
8 hrs
  • Functional Dependency and its Types
  • Normalization — definition
  • Normal Forms — 1NF, 2NF, 3NF
6

Database Transaction

डाटाबेस ट्रान्ज्याक्सन
8 hrs
  • Introduction to Transaction
  • Concurrency in Transaction
  • ACID properties
  • States of a Transaction
7

Database Backup, Recovery and Security

ब्याकअप, रिकभरी र सुरक्षा
8 hrs
  • Introduction to Backup
  • Types of Backup — Physical, Logical
  • Reasons for Database Failure
  • Methods of Database Backup
  • Concept of Recovery, Redo / Undo
  • Introduction to Database Security
  • Common Threats in a Database
