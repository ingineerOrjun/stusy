A. Structured (Procedural) vs Object-Oriented Programming

BasisStructured / Procedural (POP)Object-Oriented (OOP)
Basic unitThe function is the basic unit.The object is the basic unit.
ApproachTop-down — big problem broken into functions.Bottom-up — objects built first, then combined.
FocusFocus is on the procedure / how to do it.Focus is on the data and the object.
Data securityData is mostly global, so it can be changed by any function — less secure.Data is private/hidden inside the object — more secure.
Data + functionData and functions are separate.Data and functions are bound together.
ReusabilityDifficult — no inheritance.Easy — supports inheritance.
OverloadingNot supported.Supported (function and operator overloading).
Suitable forSmall and simple programs.Large and complex programs.
Example languageC, Pascal, FORTRANC++, Java, Python, C#
छोटो सार

POP मा फङ्सन मुख्य हुन्छ, डाटा प्रायः global हुने भएकाले कम सुरक्षित हुन्छ, र यसले माथिबाट तलतिर (top-down) सोच्छ। OOP मा अब्जेक्ट मुख्य हुन्छ, डाटा private राखेर लुकाइन्छ, र तलबाट माथितिर (bottom-up) सोच्छ। ठूलो प्रोग्रामका लागि OOP राम्रो।

B. Function Overloading vs Function Overriding

BasisFunction OverloadingFunction Overriding
MeaningSame function name with different parameters in the same class.Same function name with the same parameters redefined in a derived class.
InheritanceNot required.Required — there must be a base and a derived class.
ParametersMust be different (number, type or order).Must be exactly the same.
Return typeMay be same or different (return type alone is not enough).Must be the same.
BindingEarly / static binding.Late / dynamic binding (when virtual is used).
TypeCompile-time polymorphism.Run-time polymorphism.
virtual keywordNot used.virtual is used in the base class.
PurposeTo give one name to similar jobs.To give the child a different version of the parent's job.
छोटो सार

Overloading = उही क्लासमा उही नाम तर फरक प्यारामिटर; inheritance चाहिँदैन; compile-time। Overriding = derived क्लासमा उही नाम र उही प्यारामिटर; inheritance चाहिन्छ; virtual राखे run-time।

C. Compile-time vs Run-time Polymorphism

BasisCompile-time (Static)Run-time (Dynamic)
When decidedWhile the program is being compiled.While the program is running.
Also calledEarly binding / static binding.Late binding / dynamic binding.
Achieved byFunction overloading, operator overloading.Function overriding with virtual functions.
SpeedFaster (decision already made).Slower (decision made during execution).
FlexibilityLess flexible.More flexible.
PointersBase class pointer not needed.Usually uses a base class pointer or reference.

D. Array vs Linked List

BasisArrayLinked List
MemoryContinuous (contiguous) memory.Scattered memory joined by pointers.
SizeFixed at declaration time.Dynamic — grows and shrinks while running.
AccessDirect / random access using index — fast.Sequential access from the first node — slower.
Insert / deleteSlow — other elements must be shifted.Fast — only pointers are changed.
Extra memoryNo extra memory needed.Extra memory needed for the pointer in each node.
Memory wasteUnused declared space is wasted.No waste — memory taken only when needed.
छोटो सार

Array: लगातार मेमोरी, साइज फिक्स, index ले सिधै पुगिन्छ (छिटो), तर थप्न/हटाउन सार्नुपर्ने भएकाले ढिलो। Linked list: छरिएको मेमोरी, साइज घटबढ, पहिलो नोडबाट क्रमशः जानुपर्छ (ढिलो), तर थप्न/हटाउन पोइन्टर मात्र फेरे पुग्छ (छिटो)।

E. Stack vs Queue

BasisStackQueue
PrincipleLIFO — Last In, First Out.FIFO — First In, First Out.
Ends usedOne end only, called top.Two ends — insert at rear, delete at front.
Operationspush(), pop(), peek()enqueue(), dequeue(), front()
PointersOne pointer: top.Two pointers: front and rear.
Real examplePile of plates; browser Back button; undo.Queue at a ticket counter; printer job queue.
Empty conditiontop == -1front > rear

F. Linear vs Non-Linear Data Structure

BasisLinearNon-Linear
ArrangementElements are in a sequence, one after another.Elements are not in a sequence; one connects to many.
LevelsSingle level.Multiple levels (hierarchical).
TraversalCan be traversed completely in one run.Cannot be traversed in one straight run.
Memory useOften less efficient for large data.Usually more efficient for large data.
ExamplesArray, Linked List, Stack, QueueTree, Graph

G. Class vs Object  ·  Constructor vs Destructor  ·  Abstraction vs Encapsulation

BasisClassObject
What it isA blueprint / template.An instance of a class.
MemoryDoes not take memory.Takes memory when created.
How manyDeclared once.Many objects from one class.
Created byclass Student { … };Student s1;
BasisConstructorDestructor
When calledAutomatically when the object is created.Automatically when the object is destroyed.
NameSame as the class name.Class name with ~ in front.
ParametersCan take parameters.Cannot take parameters.
OverloadingCan be overloaded.Cannot be overloaded — only one.
PurposeInitialise data / allocate memory.Clean up / free memory.
OrderBase first, then derived.Derived first, then base (reverse).
BasisAbstractionEncapsulation
HidesHides the complexity / implementation — the "how".Hides the data — the "what".
LevelA design-level idea.An implementation-level idea.
Achieved byAbstract classes and pure virtual functions.private data + public getter/setter functions.
FocusWhat an object does.How the data is protected.

Extra Exam Terms

छोटा तर सोधिन सक्ने शब्दहरू

1-mark answers

These appear in one-mark or fill-in questions. Learn one line for each — do not go deeper than this.

TermOne-line meaning
InstantiationThe act of creating an object from a class.क्लासबाट अब्जेक्ट बनाउने काम।
Member functionA function declared inside a class; also called a method.क्लास भित्र घोषित फङ्सन — मेथड।
Data memberA variable declared inside a class.क्लास भित्रको भेरिएबल।
Scope resolution operator ::Used to define a member function outside the class, e.g. void Student::show().क्लास बाहिर फङ्सन परिभाषित गर्न प्रयोग हुन्छ।
Dot operator .Used to access a member through an object: s1.show();अब्जेक्ट मार्फत मेम्बर पुग्न।
Arrow operator ->Used to access a member through a pointer: p->show();पोइन्टर मार्फत मेम्बर पुग्न।
this pointerA hidden pointer inside every member function that points to the current object.हरेक मेम्बर फङ्सन भित्र लुकेको पोइन्टर, जसले हालको अब्जेक्ट देखाउँछ।
Friend functionA non-member function that is allowed to access the private members of a class.क्लासको मेम्बर नभई पनि private डाटा छुन पाउने फङ्सन।
Static memberA member shared by all objects of the class — only one copy exists.सबै अब्जेक्टले साझा गर्ने मेम्बर — एउटै मात्र प्रति हुन्छ।
Inline functionA small function whose code the compiler copies at the call place to save call time.बोलाइएकै ठाउँमा कोड सारिने सानो फङ्सन।
Virtual functionA base-class function declared with virtual so the derived version runs through a base pointer.virtual लेखिएको base फङ्सन — base पोइन्टरबाट derived कै संस्करण चल्छ।
Pure virtual functionA virtual function with no body, written = 0. It must be overridden.शरीर नभएको virtual फङ्सन (= 0) — override गर्नै पर्छ।
Abstract classA class containing at least one pure virtual function. No object can be created from it.कम्तीमा एउटा pure virtual फङ्सन भएको क्लास — यसको अब्जेक्ट बन्दैन।
Operator overloadingGiving an extra meaning to an existing operator (like +) for objects.भइरहेको अपरेटरलाई अब्जेक्टका लागि थप अर्थ दिने।
Virtual base classUsed in hybrid inheritance to solve the diamond problem (duplicate copies of a base).hybrid inheritance मा diamond problem हटाउन प्रयोग हुन्छ।
NamespaceA named region that groups names to avoid clashes — e.g. std.नाम नबाझियोस् भनेर नामहरू समूहमा राख्ने ठाउँ।
Header fileA file (like <iostream>) added by #include that holds ready-made declarations.#include ले थप्ने, पहिल्यै बनेका घोषणा भएको फाइल।
Overflow / UnderflowOverflow = pushing into a full stack. Underflow = popping from an empty stack.भरिएको स्ट्याकमा push = overflow; खाली स्ट्याकबाट pop = underflow।
Linear searchChecks elements one by one from the start. Works on unsorted data.सुरुदेखि एक–एक गरी जाँच्ने। नमिलेको डाटामा पनि चल्छ।
Binary searchRepeatedly cuts a sorted list in half. Much faster, but the data must be sorted.मिलेको लिस्टलाई पटक–पटक आधा काट्ने। धेरै छिटो, तर डाटा मिलेको हुनुपर्छ।
