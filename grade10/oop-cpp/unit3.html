Class and Object

क्लास र अब्जेक्ट

7 hrs

By the end of this unit you can…

  1. Define a class and an object, and explain the difference between them.
  2. Explain private, public and protected, and say which is the default.
  3. Declare a class with data members and member functions, and create objects from it.
  4. Define a member function outside the class using the scope resolution operator.
  5. Explain constructors and destructors, and predict the order in which they run.

यो युनिट सकिँदा: क्लास र अब्जेक्टको फरक, तीन access specifier, क्लास घोषणा, :: को प्रयोग, र कन्स्ट्रक्टर–डिस्ट्रक्टरको क्रम भन्न सक्नुहुनेछ।

3.1  Class and Object

Class

A class is a user-defined data type that acts as a blueprint or template. It groups data members (the variables) and member functions (the methods) together into one unit.

A class does not take any memory — it is only a design. Memory is allocated only when an object is created from it.

क्लास

क्लास भनेको प्रयोगकर्ताले बनाएको डाटा टाइप हो, जुन नक्सा (blueprint) जस्तै काम गर्छ। यसले डाटा मेम्बर (भेरिएबल) र मेम्बर फङ्सन (मेथड) लाई एउटै एकाइमा राख्छ।

क्लासले मेमोरी लिँदैन — यो डिजाइन मात्र हो। अब्जेक्ट बनेपछि मात्र मेमोरी छुट्याइन्छ।

Object

An object is a variable of a class — one real copy built from the blueprint. An object does take memory, and each object has its own separate copy of the data members.

The act of creating an object from a class is called instantiation.

अब्जेक्ट

अब्जेक्ट भनेको क्लासको भेरिएबल हो — नक्सा हेरेर बनाइएको वास्तविक प्रति। अब्जेक्टले मेमोरी लिन्छ, र हरेक अब्जेक्टसँग आफ्नै छुट्टै डाटा हुन्छ।

क्लासबाट अब्जेक्ट बनाउने कामलाई instantiation भनिन्छ।

One-line memory hook
A class is the house design on paper. An object is the real house built from it. One design can produce many houses — and you cannot live inside the design. That is exactly why a class takes no memory but an object does.
क्लास = कागजमा कोरेको घरको नक्सा। अब्जेक्ट = त्यसबाट बनेको साँच्चिकै घर। एउटा नक्साबाट धेरै घर बन्छ — र नक्सामा बस्न मिल्दैन। त्यसैले क्लासले मेमोरी लिँदैन, अब्जेक्टले लिन्छ।

3.2  Access Specifiers

This is asked almost every year, usually as "explain the access specifiers in C++" or as a one-mark question on the default.

SpecifierWho can access itNormally used for
private Accessible only inside the same class. Not from outside the class, and not even from a derived class. This is the default for a class. उही क्लास भित्रबाट मात्र। बाहिरबाट वा derived क्लासबाट पनि हुँदैन। क्लासमा यही default हो। Data members
public Accessible from anywhere — inside the class, through an object, and from derived classes. This is the default for a struct. जताबाट पनि — क्लास भित्र, अब्जेक्टबाट, र derived क्लासबाट। Member functions
protected Accessible inside the class and inside its derived classes, but not through an object from outside. क्लास भित्र र त्यसका derived क्लास भित्र मात्र; बाहिरको अब्जेक्टबाट हुँदैन। Members shared with child classes
Common mistake
Thinking protected behaves like public from outside. It does not. From outside the class, protected behaves exactly like private — obj.protectedMember is an error. The only extra thing protected gives you is access from a derived class.
protected लाई बाहिरबाट public जस्तो ठान्नु गलत। बाहिरबाट यो private जस्तै हो। यसले दिने एक मात्र थप सुविधा भनेको derived क्लास बाट पहुँच हो।

From outside, protected behaves like private. Its only gift is to a derived class. बाहिरबाट protected, private जस्तै हो। यसले दिने एक मात्र सुविधा derived कक्षालाई हो।

Predict first · पहिले अनुमान गर्नुहोस्

A class is written with no access specifier at all: class A { int x; };. What is x? कुनै access specifier नलेखी क्लास बनाइयो: class A { int x; };। x के हुन्छ?

Private. In a class the default is private, so x cannot be reached from outside — and this is why a beginner's first program often fails to compile with "member is inaccessible" when they forgot to write public:.

Note the trap: in a struct the default is public instead. Same language, opposite default — and that difference is worth a mark when the question gives you a struct.

Private। class मा default private हुन्छ, त्यसैले x बाहिरबाट पुग्न सकिँदैन — public: लेख्न बिर्सँदा सुरुका प्रोग्राममा "member is inaccessible" आउनुको कारण यही हो। ध्यान दिनुहोस्: struct मा default public हुन्छ। उही भाषा, उल्टो default।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Does this line compile?

What you will learn: to apply the access table instead of reciting it — especially inside a derived class, where private and protected stop behaving the same. तपाईंले के सिक्नुहुन्छ: पहुँच तालिका घोक्नुभन्दा लागू गर्न — विशेष गरी derived क्लासभित्र, जहाँ private र protected फरक हुन्छन्।

What to notice

Cases 2 and 3 are the same code with one word changed — protected becomes private — and the answer flips. That single word is the entire difference between the two specifiers, and it only shows up inside a derived class.

Case 4 is the one that catches people who learned "protected is less strict". From outside the class, protected behaves exactly like private.

केस २ र ३ मा एउटै कोड छ, एउटै शब्द फरक — protected बाट private — र उत्तर उल्टिन्छ। दुई specifier बीचको पूरा फरक त्यही शब्द हो, र त्यो derived क्लासभित्र मात्र देखिन्छ। केस ४ ले "protected कम कडा हो" भन्ने भ्रम भत्काउँछ: क्लासबाहिरबाट protected ठ्याक्कै private जस्तै हुन्छ।

3.3  Declaring a Class and its Objects

Example 1 A complete class with data members and member functions
#include <iostream>
#include <string>
using namespace std;

class Student {           // class = blueprint
private:                  // hidden from outside
    string name;          // data member
    int roll;             // data member

public:                   // usable from outside
    void setData(string n, int r) {    // member function
        name = n;
        roll = r;
    }
    void display() {                   // member function
        cout << name << " - " << roll << endl;
    }
};                        // <-- this semicolon is compulsory

int main() {
    Student s1, s2;               // s1 and s2 are OBJECTS
    s1.setData("Ram", 15);        // dot operator
    s2.setData("Sita", 16);
    s1.display();
    s2.display();
    return 0;
}
Output 
Ram - 15
Sita - 16

Notice that s1 and s2 used the same display() function but printed different values — because each object carries its own copy of name and roll. s1 र s2 ले उही display() प्रयोग गरे तर फरक मान छापे — किनकि हरेक अब्जेक्टसँग आफ्नै name र roll छ।

The single most common error in this unit
Forgetting the semicolon after the closing brace of a class: };  not  }. A class declaration is a statement, so it must end with a semicolon. Leaving it out produces a long, confusing list of compiler errors.
क्लासको बन्द ब्रेस पछि सेमीकोलन बिर्सनु — यो युनिटको सबैभन्दा सामान्य गल्ती हो। }; लेख्नुपर्छ, } मात्र होइन।

Defining a member function outside the class

Example 2 Using the scope resolution operator ::
class Student {
private:
    string name;
    int roll;
public:
    void setData(string n, int r);    // only DECLARED here
    void display();                   // only DECLARED here
};

// DEFINED outside, using ClassName::functionName
void Student::setData(string n, int r) {
    name = n;
    roll = r;
}

void Student::display() {
    cout << name << " - " << roll << endl;
}

The scope resolution operator :: tells the compiler which class the function belongs to. Without Student:: the compiler would treat display() as an ordinary global function that knows nothing about name or roll. Scope resolution operator :: ले फङ्सन कुन क्लासको हो भनेर कम्पाइलरलाई बताउँछ। Student:: नलेखे कम्पाइलरले यसलाई सामान्य global फङ्सन ठान्छ, जसलाई name र roll को केही थाहा हुँदैन।

3.5  Constructor and Destructor

Constructor

A constructor is a special member function that is called automatically when an object is created. Its job is to initialise the object's data.

  • Its name is exactly the same as the class name.
  • It has no return type — not even void.
  • It can take parameters and can be overloaded.

Three types:
Default constructor — takes no arguments.
Parameterized constructor — takes arguments to set the starting values.
Copy constructor — creates a new object as a copy of an existing one, written Student(Student &s).

कन्स्ट्रक्टर

कन्स्ट्रक्टर एउटा विशेष मेम्बर फङ्सन हो, जुन अब्जेक्ट बन्ने बित्तिकै आफैं बोलिन्छ। यसको काम डाटालाई सुरुवाती मान दिनु हो।

  • नाम क्लासकै नामसँग ठ्याक्कै मिल्नुपर्छ।
  • return type हुँदैन — void पनि होइन।
  • प्यारामिटर लिन सक्छ र overload पनि हुन सक्छ।

तीन प्रकार:
Default — कुनै आर्गुमेन्ट नलिने।
Parameterized — सुरुको मान तोक्न आर्गुमेन्ट लिने।
Copy — भइरहेको अब्जेक्टको प्रतिलिपि बनाउने।

Destructor

A destructor is a special member function that is called automatically when an object is destroyed — that is, when it goes out of scope. Its job is to free the memory the object was using.

  • Its name is the class name with a tilde ~ in front.
  • It has no return type and takes no parameters.
  • It cannot be overloaded — a class has exactly one destructor.
  • Objects are destroyed in the reverse order of their creation.
डिस्ट्रक्टर

डिस्ट्रक्टर एउटा विशेष मेम्बर फङ्सन हो, जुन अब्जेक्ट नष्ट हुँदा आफैं बोलिन्छ। यसको काम अब्जेक्टले लिएको मेमोरी खाली गर्नु हो।

  • नाम अगाडि टिल्ड ~ राखेर क्लासकै नाम।
  • return type हुँदैन र प्यारामिटर पनि लिँदैन।
  • overload गर्न मिल्दैन — क्लासमा एउटा मात्र डिस्ट्रक्टर हुन्छ।
  • अब्जेक्टहरू बनेको उल्टो क्रममा नष्ट हुन्छन्।
Example 3 Constructor overloading — three constructors in one class
#include <iostream>
using namespace std;

class Box {
    int len, wid;
public:
    Box() {                          // 1. default constructor
        len = 1; wid = 1;
        cout << "Default called" << endl;
    }
    Box(int l, int w) {              // 2. parameterized constructor
        len = l; wid = w;
        cout << "Parameterized called" << endl;
    }
    Box(Box &b) {                    // 3. copy constructor
        len = b.len; wid = b.wid;
        cout << "Copy called" << endl;
    }
    void area() { cout << "Area = " << len * wid << endl; }
};

int main() {
    Box b1;              // calls the default
    Box b2(4, 6);        // calls the parameterized
    Box b3 = b2;         // calls the copy constructor
    b1.area();
    b2.area();
    b3.area();
    return 0;
}
Output 
Default called
Parameterized called
Copy called
Area = 1
Area = 24
Area = 24

All three constructors have the same name — the compiler picks the right one by counting and checking the arguments. That is constructor overloading, and it is an example of compile-time polymorphism. तीनै कन्स्ट्रक्टरको नाम उही छ — कम्पाइलरले आर्गुमेन्ट हेरेर सही एउटा छान्छ। यसैलाई constructor overloading भनिन्छ, र यो compile-time polymorphism कै उदाहरण हो।

Exam favourite — the automatic call
Constructors and destructors are called automatically. You never write s1.Student(); or s1.~Student(); yourself. And the destruction order is always the reverse of the creation order — like plates on a stack.
दुवै आफैं बोलिन्छन् — हातले बोलाउनु पर्दैन। नष्ट हुने क्रम सधैं बनेको उल्टो हुन्छ, स्ट्याकमा थुपारेको प्लेट जस्तै।

Exam focus — questions asked from this unit

SEE exam connection · परीक्षा जोड

Access specifiers and the constructor/destructor rules are asked as both short questions and output prediction.

Access specifier र constructor/destructor का नियम छोटो प्रश्न र आउटपुट दुवैमा सोधिन्छ।
Q1 · Differentiate between a class and an object. [3 marks]

A class is a blueprint or template that defines the data members and member functions; an object is an instance of that class. A class takes no memory, while an object takes memory when it is created. A class is declared once, but many objects can be created from it. Example: class Student{ }; is the class, Student s1; creates the object.

नक्सा vs घर, मेमोरी लिँदैन vs लिन्छ, एक पटक घोषणा vs धेरै अब्जेक्ट — यी तीन बुँदा लेख्नुहोस्।
Q2 · Explain the three access specifiers in C++. Which is the default? [4 marks]

private — accessible only inside the same class; not from outside and not from a derived class. public — accessible from anywhere, including through an object. protected — accessible inside the class and inside its derived classes, but not through an object from outside.

In a class the default is private. (In a struct the default is public.)

तीनवटैको एक–एक लाइन + default चाहिँ private हो भनेर लेख्न नबिर्सनुहोस्।
Q3 · What is a constructor? Write its characteristics and name its types. [5 marks]

A constructor is a special member function that is automatically invoked when an object of the class is created, and it is used to initialise the object's data members.

Characteristics: its name is the same as the class name; it has no return type, not even void; it is called automatically; it can take parameters; it can be overloaded.

Types: default constructor, parameterized constructor and copy constructor.

परिभाषा + पाँच विशेषता + तीन प्रकार — पूरा अंकका लागि तीनै भाग चाहिन्छ।
Q4 · Differentiate between a constructor and a destructor. [4 marks]

Write it as a table: when called (on creation vs on destruction); name (class name vs class name with ~); parameters (can take them vs cannot); overloading (can be overloaded vs cannot, only one per class); purpose (initialise / allocate memory vs clean up / free memory).

तालिकाको रूपमा पाँच हरफ लेख्नुहोस्।

Key points to revise — दोहोर्‍याउनुपर्ने मुख्य बुँदा

  • Class = blueprint, no memory. Object = instance, takes memory.
  • Default access in a class is private; in a struct it is public.
  • protected = private from outside, but visible to derived classes.
  • A class declaration must end with a semicolon: };
  • Dot operator . for objects; scope resolution :: to define a function outside its class.
  • Constructor: same name as class, no return type, called automatically, can be overloaded.
  • Destructor: ~ClassName(), no parameters, cannot be overloaded, only one per class.
  • Destruction order is always the reverse of creation order.
