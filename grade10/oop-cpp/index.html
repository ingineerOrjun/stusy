Data Structure & OOP using C++

A data structure is a way of organising data in memory so a program can use it quickly. Object-Oriented Programming (OOP) is a way of writing a program by binding data and the functions that work on that data together inside an object.

डाटा स्ट्रक्चर भनेको मेमोरीमा डाटा मिलाएर राख्ने तरिका हो, जसले गर्दा प्रोग्रामले छिटो काम गर्न सक्छ। OOP भनेको डाटा र त्यो डाटामाथि काम गर्ने फङ्सनलाई एउटै अब्जेक्ट भित्र बाँधेर प्रोग्राम लेख्ने तरिका हो।

How to use this page

Read the solid box first — that is the exact English wording the exam uses. Then read the dashed yellow box — that is the same idea in Nepali. Both are always on screen together, so you can match the Nepali meaning to the English exam word.

The most important part is ▶ Trace a Program. Exams ask "what is the output of this program?" — that section teaches you to walk a program line by line.

यो पेज कसरी प्रयोग गर्ने

पहिले सलिड बाकस पढ्नुहोस् — त्यही अंग्रेजी शब्द नै परीक्षामा आउँछ। त्यसपछि पहेँलो डटेड बाकस पढ्नुहोस् — त्यहाँ त्यही कुरा नेपालीमा छ। दुवै सँगै देखिन्छन्, ताकि नेपाली अर्थलाई अंग्रेजी शब्दसँग जोड्न सकियोस्।

सबैभन्दा महत्त्वपूर्ण भाग ▶ Trace a Program हो। परीक्षामा "यो प्रोग्रामको आउटपुट के हो?" भनेर सोधिन्छ — त्यो सेक्सनले लाइन–लाइन पढ्न सिकाउँछ।
