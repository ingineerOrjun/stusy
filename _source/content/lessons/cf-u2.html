2.1  The components of a computer system — कम्प्युटर प्रणालीका भागहरू

One machine, five jobs

Unit 1 said a computer accepts data, processes it, gives information and stores both. Those are not four descriptions of one box — they are four different parts, and a fifth part tells the others what to do.

The input unit brings data in. The memory unit holds it. The ALU — Arithmetic and Logic Unit — does every calculation and every comparison. The control unit decides what happens next and in what order. The output unit sends the result out to you.

The ALU and the control unit together are called the CPU, the Central Processing Unit. That is why the CPU is called the brain: not because it stores things, but because it is where deciding and calculating both happen.

एउटै मेसिन, पाँच काम

युनिट १ मा भनियो — कम्प्युटरले data लिन्छ, प्रशोधन गर्छ, information दिन्छ र दुवै राख्छ। यी एउटै बाकसका चार वर्णन होइनन् — यी चार फरक भाग हुन्, र पाँचौं भागले अरूलाई के गर्ने भन्छ।

Input unit ले data भित्र ल्याउँछ। Memory unit ले राख्छ। ALU — Arithmetic and Logic Unit — ले हरेक गणना र हरेक तुलना गर्छ। Control unit ले अब के हुने र कुन क्रममा हुने तय गर्छ। Output unit ले नतिजा तपाईंसम्म पठाउँछ।

ALU र control unit मिलेर CPU — Central Processing Unit — बन्छ। CPU लाई मस्तिष्क भनिनुको कारण यही हो: यसले राख्छ भनेर होइन, निर्णय र गणना दुवै यहीँ हुन्छन् भनेर।

2.2  The input unit and its devices — Input एकाइ र यसका उपकरण

What an input device really does

An input device takes something that exists in the world — a key press, a shape on paper, a sound, a picture — and turns it into the 0s and 1s the computer can work with. Conversion is the job. A device that does not convert is not an input device.

The curriculum names twelve: keyboard, mouse, joystick, OMR, OCR, BCR, MICR, scanner, touch screen, touchpad, microphone and digital camera. Learn them in groups rather than as a list of twelve.

Typing and pointing: keyboard, mouse, joystick, touchpad, touch screen. Capturing: scanner, digital camera, microphone. Reading marks and codes: OMR, OCR, BCR, MICR — the four that are confused in every examination.

Input device ले साँच्चै के गर्छ

Input device ले संसारमा भएको कुरा — कुञ्जी थिचाइ, कागजको चिन्ह, आवाज, तस्बिर — लिएर कम्प्युटरले चलाउन सक्ने ० र १ मा बदल्छ। बदल्नु नै यसको काम हो। नबदल्ने उपकरण input device होइन।

पाठ्यक्रमले बाह्र वटा नाम लिन्छ: keyboard, mouse, joystick, OMR, OCR, BCR, MICR, scanner, touch screen, touchpad, microphone र digital camera। बाह्रको सूची घोक्नुभन्दा समूहमा सिक्नुहोस्।

टाइप र देखाउने: keyboard, mouse, joystick, touchpad, touch screen। कैद गर्ने: scanner, digital camera, microphone। चिन्ह र कोड पढ्ने: OMR, OCR, BCR, MICR — हरेक परीक्षामा अलमल पार्ने चार।

The four readers, told apart by what they read

All four scan paper. The difference is what is on the paper, and that is the whole answer to the question.

  • OMR — Optical Mark Reader. Reads a pencil mark in a box. It does not read what the mark means, only that the box is filled. Entrance exam answer sheets.
  • OCR — Optical Character Reader. Reads printed or written letters and turns them into editable text. Scanning a page of a book into a document.
  • BCR — Bar Code Reader. Reads the striped code on a product. The stripes are a number, and the number is looked up for the price.
  • MICR — Magnetic Ink Character Reader. Reads characters printed in magnetic ink, used on bank cheques, because magnetic ink cannot be photocopied.
चारैले कागज स्क्यान गर्छन्। फरक कागजमा के छ भन्नेमा हो, र प्रश्नको पूरा उत्तर त्यही हो। OMR — Optical Mark Reader: बाकसमा लगाएको पेन्सिलको चिन्ह पढ्छ; चिन्हको अर्थ होइन, बाकस भरिएको छ कि छैन मात्र। प्रवेश परीक्षाको उत्तरपुस्तिका। OCR — Optical Character Reader: छापिएका वा लेखिएका अक्षर पढेर सम्पादन गर्न मिल्ने पाठ बनाउँछ। BCR — Bar Code Reader: सामानको धर्के कोड पढ्छ; धर्का भनेको संख्या हो, र त्यही संख्याबाट मूल्य खोजिन्छ। MICR — Magnetic Ink Character Reader: चुम्बकीय मसी मा छापिएका अक्षर पढ्छ; बैंक चेकमा चल्छ, किनभने चुम्बकीय मसी फोटोकपी हुँदैन।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

What you will learn: to pick a device from what the job needs rather than from the first name you remember. Two of the six cases differ only in what is printed on the paper. तपाईंले के सिक्नुहुन्छ: पहिलो सम्झिएको नाम होइन, कामको आवश्यकता हेरेर उपकरण छान्न। छ केसमध्ये दुईको फरक कागजमा के छापिएको छ भन्नेमा मात्र छ।

How to use this

Before answering, say what is physically being read: a filled box, a letter shape, a stripe pattern, or magnetic ink. The device follows from that.

उत्तर दिनुअघि के पढिँदै छ भन्नुहोस्: भरिएको बाकस, अक्षरको आकार, धर्काको बान्की, कि चुम्बकीय मसी। उपकरण त्यसैबाट निस्कन्छ।

2.3  The output unit and its devices — Output एकाइ र यसका उपकरण

Two cuts, made in order

Output devices are classified by two different questions, and answering them in order keeps them straight.

First: can you carry the output away? Softcopy output is temporary and on a screen or in sound — monitor, speaker, projector, headphone. Hardcopy output is permanent and on paper or material — printers and the graphic plotter.

Second, for printers only: does it strike the paper? An impact printer presses an inked ribbon against the paper, so it is noisy and can print carbon copies — the dot-matrix printer. A non-impact printer never touches the paper: inkjet sprays, laser fuses powder. Quiet, faster, no carbon copy.

A 3D printer is different again. It builds an object layer by layer out of plastic or resin, so its output is a thing, not a page.

दुई प्रश्न, क्रम मिलाएर

Output device लाई दुई फरक प्रश्न ले वर्गीकरण गरिन्छ, र क्रम मिलाएर सोधे अलमल हुँदैन।

पहिलो: आउटपुट बोकेर लैजान सकिन्छ? Softcopy अस्थायी हुन्छ — पर्दामा वा आवाजमा: monitor, speaker, projector, headphone. Hardcopy स्थायी हुन्छ — कागज वा वस्तुमा: printer र graphic plotter।

दोस्रो, प्रिन्टरका लागि मात्र: कागजमा ठोक्किन्छ? Impact प्रिन्टरले मसी भएको रिबनलाई कागजमा थिच्छ — हल्ला गर्छ र कार्बन कपी निकाल्न सक्छ: dot-matrix। Non-impact प्रिन्टरले कागज छुँदै छुँदैन: inkjet ले छर्छ, laser ले धुलो टाँस्छ। शान्त, छिटो, कार्बन कपी हुँदैन।

3D printer अझ फरक हो। यसले प्लास्टिक वा रेजिनबाट तह–तह गरी वस्तु बनाउँछ, त्यसैले यसको आउटपुट कागज होइन, वस्तु हो।

2.4  The memory unit — Memory एकाइ

The part that holds, while the work happens

The memory unit is where data and instructions sit while the computer is working on them. Input brings data in and then it is finished; the memory unit is what keeps it available for the ALU to use, again and again, until the job is done.

Two facts matter here, and Unit 4 does the rest. One: the program itself lives in memory, not just the data — that is the stored-program idea from Unit 1, and this is where it is stored. Two: memory is measured in bytes. One byte is 8 bits and holds roughly one character; 1024 bytes is a kilobyte, 1024 KB a megabyte, 1024 MB a gigabyte.

Why 1024 and not 1000? Because memory is addressed in binary, and 1024 is 210 — the nearest round number in a system that counts in twos.

काम हुँदासम्म राख्ने भाग

Memory unit त्यो ठाउँ हो जहाँ कम्प्युटरले काम गरिरहँदा data र निर्देशन बस्छन्। Input ले data भित्र ल्याएपछि उसको काम सकियो; ALU ले बारम्बार प्रयोग गर्न सक्ने गरी राख्ने काम memory unit को हो।

यहाँ दुई कुरा महत्त्वपूर्ण छन्, बाँकी युनिट ४ ले हेर्छ। एक: data मात्र होइन, प्रोग्राम आफैं पनि memory मै बस्छ — युनिट १ को stored-program विचार, र भण्डारण हुने ठाउँ यही हो। दुई: memory byte मा नापिन्छ। एक byte = ८ bit, लगभग एक अक्षर; १०२४ byte = kilobyte, १०२४ KB = megabyte, १०२४ MB = gigabyte।

१००० होइन १०२४ किन? किनभने memory को ठेगाना binary मा हुन्छ, र १०२४ भनेको २१० हो — दुईमा गन्ने प्रणालीको नजिकको पूरा संख्या।

2.5  The processing unit — the microprocessor — प्रशोधन एकाइ — microprocessor

One chip, and the two numbers printed on it

A microprocessor is the whole CPU built onto a single silicon chip: the ALU, the control unit, and a small set of fast holding places called registers. When an advertisement says "Intel Core i5, 3.2 GHz, 64-bit", it is naming the chip and then the two numbers that describe how it works.

Clock speed is how many cycles the chip performs each second, measured in hertz. 3.2 GHz is 3.2 billion cycles per second. More cycles per second means more instructions per second — the chip works faster.

Word length is how many bits the chip can handle in one cycle — 8, 16, 32 or 64. A 64-bit chip moves eight bytes where an 8-bit chip moves one. More bits per cycle means more work per cycle.

So the two numbers answer different questions: clock speed is how often, word length is how much each time. A student who says "word length makes it faster" without saying per cycle has not answered the question.

एउटै चिप, र त्यसमा लेखिएका दुई संख्या

Microprocessor भनेको पूरै CPU एउटै सिलिकन चिपमा बनेको हो: ALU, control unit, र register भनिने केही छिटो राख्ने ठाउँ। विज्ञापनले "Intel Core i5, 3.2 GHz, 64-bit" भन्दा चिपको नाम र त्यो कसरी चल्छ भन्ने दुई संख्या भनिरहेको हुन्छ।

Clock speed भनेको चिपले सेकेन्डमा कति चक्र चलाउँछ — hertz मा नापिन्छ। 3.2 GHz भनेको सेकेन्डमा ३.२ अर्ब चक्र। बढी चक्र भनेको बढी निर्देशन — चिप छिटो चल्छ।

Word length भनेको चिपले एक चक्रमा कति bit चलाउन सक्छ — ८, १६, ३२ वा ६४। 64-bit चिपले आठ byte सार्छ, 8-bit ले एक। बढी bit भनेको प्रति चक्र बढी काम।

त्यसैले दुई संख्याले फरक प्रश्नको उत्तर दिन्छन्: clock speed — कति पटक, word length — पटकै कति। "word length ले छिटो बनाउँछ" भन्ने तर प्रति चक्र नभन्ने उत्तरले प्रश्नको जवाफ दिएको हुँदैन।

Chip A runs at 2 GHz with a 64-bit word length. Chip B runs at 4 GHz with an 8-bit word length. Both are given the same job: add up eight bytes of data. Which finishes the addition in fewer clock cycles? चिप A: 2 GHz, word length 64-bit। चिप B: 4 GHz, word length 8-bit। दुवैलाई उही काम: आठ byte data जोड्ने। कुनले कम clock cycle मा सक्छ?

Chip A's word length is 64 bits, which is 8 bytes, so all eight arrive in one cycle. Chip B handles 8 bits — one byte — per cycle, so it needs eight cycles. Clock speed was not the question: B does more cycles per second, but it needs eight times as many of them. This is exactly why both numbers are quoted and neither alone tells you how fast a chip is.

चिप A को word length ६४ bit = ८ byte, त्यसैले आठै byte एक चक्रमा पुग्छन्। चिप B ले प्रति चक्र ८ bit — एक byte — चलाउँछ, त्यसैले आठ चक्र चाहिन्छ। प्रश्न clock speed को थिएन: B ले सेकेन्डमा बढी चक्र चलाउँछ, तर उसलाई आठ गुणा बढी चक्र चाहिन्छ। दुवै संख्या किन भनिन्छ र एक्लैले गति बताउँदैन भन्ने कारण यही हो।

Mistakes that cost marks here

  • Calling the CPU "memory". The CPU is ALU plus control unit. Memory is a separate unit. A question that asks "which unit stores data during processing" wants the memory unit, not the CPU.
  • Saying a scanner and an OCR are the same thing. A scanner produces a picture of the page. OCR is what reads letters out of that picture and makes them editable text.
  • Putting the plotter under softcopy. A plotter draws on paper. Paper is hardcopy.
  • Answering "impact or non-impact" for a monitor. That cut applies to printers only. A monitor is softcopy and the question stops there.
  • Writing "1 MB = 1000 KB". It is 1024. The marker is checking whether you know why memory counts in powers of two.
CPU लाई memory भन्नु: CPU = ALU + control unit; memory छुट्टै एकाइ हो। Scanner र OCR उस्तै भन्नु: scanner ले पानाको तस्बिर बनाउँछ; OCR ले त्यही तस्बिरबाट अक्षर पढेर सम्पादनयोग्य पाठ बनाउँछ। Plotter लाई softcopy मा राख्नु: plotter कागजमा कोर्छ, कागज भनेको hardcopy। Monitor लाई impact/non-impact भन्नु: त्यो भाग प्रिन्टरका लागि मात्र हो। "1 MB = 1000 KB" लेख्नु: १०२४ हो।

Memory hook — Mark, Character, Bar, Magnetic. The second letter names what it reads. सम्झने तरिका — Mark, Character, Bar, Magnetic. नामको दोस्रो अक्षरले के पढ्छ भन्छ।

2 marks Practice question

Differentiate between OMR and OCR. OMR र OCR बीचको फरक लेख्नुहोस्।

OMR (Optical Mark Reader) detects the presence of a mark in a fixed position — a filled box on an answer sheet. It does not read what the mark is.

OCR (Optical Character Reader) recognises the shape of printed or handwritten characters and converts them into editable text.

Write both halves. An answer that only says "OMR reads marks, OCR reads characters" earns one mark; the second comes from saying what each produces.

OMR ले तोकिएको ठाउँमा चिन्ह छ कि छैन पत्ता लगाउँछ; चिन्ह के हो पढ्दैन। OCR ले अक्षरको आकार चिन्छ र सम्पादनयोग्य पाठ बनाउँछ। दुवै भाग लेख्नुहोस्।
2 marks Practice question

What is a microprocessor? Write any two of its components. Microprocessor भनेको के हो? यसका कुनै दुई भाग लेख्नुहोस्।

A microprocessor is the central processing unit built on a single integrated-circuit chip. It fetches instructions from memory, decodes them and carries them out.

Components: the ALU, the control unit, and registers. Any two.

Microprocessor भनेको एउटै एकीकृत परिपथ चिपमा बनेको केन्द्रीय प्रशोधन एकाइ हो। भागहरू: ALU, control unit, register — कुनै दुई।
4 marks Practice question

Classify output devices with examples. Output device को वर्गीकरण उदाहरणसहित गर्नुहोस्।

Output devices are classified into two types:

1. Softcopy output devices — the output is temporary and cannot be touched. Examples: monitor (CRT, LCD, LED/Plasma), speaker, projector, headphone.

2. Hardcopy output devices — the output is permanent and on paper or material. Examples: printers and the graphic plotter.

Printers divide further into impact (dot-matrix — strikes the paper, can make carbon copies) and non-impact (inkjet, laser — no contact), and the 3D printer, which builds a solid object layer by layer.

दुई किसिम: Softcopy — आउटपुट अस्थायी, छुन मिल्दैन: monitor (CRT, LCD, LED/Plasma), speaker, projector, headphone। Hardcopy — स्थायी, कागज वा वस्तुमा: printer र graphic plotter। प्रिन्टर फेरि impact (dot-matrix) र non-impact (inkjet, laser) मा, अनि 3D printer छुट्टै।
4 marks Practice question

Explain clock speed and word length. How does each affect the speed of a computer? Clock speed र word length बुझाउनुहोस्। प्रत्येकले कम्प्युटरको गतिमा के असर गर्छ?

Clock speed is the number of cycles a processor completes in one second, measured in hertz (MHz, GHz). A higher clock speed means more instructions are carried out each second, so the computer works faster.

Word length is the number of bits a processor can handle in a single operation — 8, 16, 32 or 64 bits. A longer word length means more data is processed in each cycle, so the computer does more work per cycle.

The two combine: a processor is fast when it performs many cycles per second and moves a lot of data in each one.

Clock speed — प्रोसेसरले एक सेकेन्डमा पूरा गर्ने चक्रको संख्या (MHz, GHz)। बढी clock speed = प्रति सेकेन्ड बढी निर्देशन। Word length — प्रोसेसरले एकै कार्यमा चलाउन सक्ने bit संख्या (८/१६/३२/६४)। लामो word length = प्रति चक्र बढी data। दुवै मिलेर गति बन्छ।

Key points from this unit

  • Five units: input, memory, ALU, control, output. ALU + control unit = CPU.
  • An input device converts a real-world signal into binary. Conversion is the test.
  • OMR reads a mark, OCR a character, BCR a bar code, MICR magnetic ink.
  • Output: softcopy (screen, sound) vs hardcopy (paper). Printers only: impact vs non-impact.
  • Memory holds data and the program while the work is happening; 1 KB = 1024 bytes.
  • Clock speed = how often. Word length = how much per cycle. Both are needed to judge speed.
पाँच एकाइ: input, memory, ALU, control, output; ALU + control = CPU। Input device ले वास्तविक सङ्केतलाई binary मा बदल्छ। OMR — चिन्ह, OCR — अक्षर, BCR — बार कोड, MICR — चुम्बकीय मसी। Output: softcopy र hardcopy; प्रिन्टरमा मात्र impact र non-impact। Memory ले काम हुँदासम्म data र प्रोग्राम दुवै राख्छ; 1 KB = 1024 byte। Clock speed — कति पटक; word length — पटकै कति।
