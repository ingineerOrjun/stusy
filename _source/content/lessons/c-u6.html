Structure and Union

6.1  Introduction to structure — Structure को परिचय

When one thing has several different facts about it

An array holds many values of the same type. A student record is several values of different types about one person: a name (text), a roll number (an integer), a percentage (a float). No array can hold that.

A structure is a user-defined data type that groups variables of different types under one name. Each variable inside it is a member, and every member has its own memory.

Why it matters beyond tidiness: once struct Student exists, you can make an array of structures — struct Student s[50]; — and one declaration holds fifty complete records. That is what every real program storing people, products or marks actually does.

एउटै कुराबारे धेरै फरक तथ्य हुँदा

Array ले एउटै प्रकारका धेरै मान राख्छ। विद्यार्थीको record भनेको एउटै व्यक्तिबारे फरक प्रकारका धेरै मान हो: नाम (पाठ), roll नम्बर (integer), प्रतिशत (float)। त्यो कुनै array ले राख्न सक्दैन।

Structure भनेको प्रयोगकर्ता-परिभाषित data type हो, जसले फरक प्रकारका variable लाई एउटै नाममुनि समूहबद्ध गर्छ। भित्रका हरेक variable लाई member भनिन्छ, र हरेक member को आफ्नै मेमोरी हुन्छ।

सफा देखिनुभन्दा बढी किन महत्त्वपूर्ण छ: struct Student बनेपछि तपाईंले structure को array बनाउन सक्नुहुन्छ — struct Student s[50]; — र एउटै घोषणाले पचास पूरा record राख्छ। मान्छे, सामान वा अंक राख्ने हरेक वास्तविक प्रोग्रामले गर्ने काम त्यही हो।

6.2  Declaring a structure and a structure variable — Structure र त्यसको variable घोषणा

The declaration is a blueprint, not a box

Declaring a structure creates a new data type and reserves no memory at all. It is a description of what such a variable would look like — the worked example below shows one in full.

Memory is reserved when you declare a variable of that type: struct Student s1;. The keyword struct is part of the type name in C and cannot be left out — Student s1; alone will not compile.

The semicolon after the closing brace is compulsory. A structure declaration is a statement, unlike a function definition, and leaving the semicolon out produces an error message that points at the next line and reads as if something else were wrong.

घोषणा नक्सा हो, बाकस होइन

Structure घोषणा गर्दा नयाँ data type बन्छ र मेमोरी बिलकुलै छुट्टिँदैन। यो त्यस्तो variable कस्तो हुन्छ भन्ने वर्णन मात्र हो — तलको worked example मा पूरै देखाइएको छ।

त्यो प्रकारको variable घोषणा गर्दा मात्र मेमोरी छुट्टिन्छ: struct Student s1;। C मा struct keyword प्रकारको नाम कै भाग हो र छाड्न मिल्दैन — Student s1; मात्रले compile हुँदैन।

बन्द गर्ने brace पछि semicolon अनिवार्य छ। Function definition भन्दा फरक, structure को घोषणा statement हो, र semicolon छुटे आउने त्रुटि सन्देशले अर्कै लाइन देखाउँछ र अरू केही बिग्रेजस्तो पढिन्छ।

6.3  Accessing a member — the dot operator — Member मा पुग्ने — dot operator

Example 1 A student record, declared and used

Question: declare a structure for a student with a name, a roll number and a percentage, read one student's details and print them.

Write the scanf lines before opening this. One of the three members takes no ampersand — decide which, and why. खोल्नुअघि scanf का लाइन लेख्नुहोस्। तीनमध्ये एउटा member लाई ampersand चाहिँदैन — कुन र किन, निर्णय गर्नुहोस्।

Working 
#include <stdio.h>

struct Student            /* 1. the blueprint — no memory used yet */
{
    char name[20];
    int roll;
    float percent;
};                        /* the semicolon here is compulsory      */

int main()
{
    struct Student s1;    /* 2. NOW memory is reserved             */

    printf("Name   : ");
    scanf("%s", s1.name);        /* no & — an array name is an address */

    printf("Roll   : ");
    scanf("%d", &s1.roll);       /* & — roll is an ordinary int        */

    printf("Percent: ");
    scanf("%f", &s1.percent);

    printf("\n%s has roll %d and scored %.2f%%",
           s1.name, s1.roll, s1.percent);
    return 0;
}
Output (if the user types Sita, 15 and 82.5) 
Name   : Sita
Roll   : 15
Percent: 82.5

Sita has roll 15 and scored 82.50%

Three things are being marked. The semicolon after the closing brace. The word struct in front of Student s1. And the dot operator: s1.roll means "the roll member of the variable s1", and the dot joins a variable to a member — never a type to a member, because Student.roll names no memory. Note also %% at the end: a single % would be read as the start of a specifier. तीन कुराको अंक छ। बन्द brace पछिको semicolon। Student s1 अगाडिको struct शब्द। अनि dot operator: s1.roll को अर्थ "s1 variable को roll member" हो, र dot ले variable लाई member सँग जोड्छ — प्रकारलाई कहिल्यै होइन, किनभने Student.roll ले कुनै मेमोरी जनाउँदैन। अन्त्यको %% पनि हेर्नुहोस्: एउटै % लाई specifier को सुरु पढिन्थ्यो।

6.4  Introduction to union — Union को परिचय

The same declaration, one shared box

A union is declared exactly like a structure, with the keyword union instead. It groups members of different types under one name — and it gives all of them the same memory.

So a union's size is the size of its largest member, not the total. And only one member holds a meaningful value at a time: writing to one overwrites whatever the others were showing, because there is only one block of bytes and they are all reading it.

Why would anyone want that? To save memory, when a value is sometimes one type and sometimes another but never both at once — a reading that is either a whole count or a decimal measurement, on a device with very little memory. Saving memory is the only reason a union exists, and it is the reason to give in an answer.

उही घोषणा, एउटै साझा बाकस

Union लाई structure कै जस्तो घोषणा गरिन्छ, keyword मात्र union हुन्छ। यसले फरक प्रकारका member लाई एउटै नाममुनि राख्छ — र सबैलाई उही मेमोरी दिन्छ।

त्यसैले union को आकार जोड होइन, सबैभन्दा ठूलो member को आकार हुन्छ। अनि एक पटकमा एउटै member सँग अर्थपूर्ण मान हुन्छ: एउटामा लेख्दा अरूले देखाइरहेको कुरा मेटिन्छ, किनभने byte को एउटै block छ र सबैले त्यही पढिरहेका छन्।

कसैले किन त्यो चाहन्छ? मेमोरी बचाउन — जब कुनै मान कहिले एक प्रकारको र कहिले अर्को हुन्छ तर एकैचोटि दुवै कहिल्यै हुँदैन; जस्तै थोरै मेमोरी भएको यन्त्रमा कि पूर्ण गन्ती कि दशमलव नाप। Union हुनुको एकमात्र कारण मेमोरी बचत हो, र उत्तरमा दिनुपर्ने कारण पनि त्यही।

Step through it · चरणबद्ध हेर्नुहोस्

Writing one member changes the other

What you will learn: that a line naming only b.c changes what b.n reads back. Watch the shared-memory row: it has one value, and both members are simply two ways of reading it. तपाईंले के सिक्नुहुन्छ: b.c को मात्र नाम लिने लाइनले b.n ले पढ्ने कुरा बदल्छ। साझा मेमोरीको पङ्क्ति हेर्नुहोस्: त्यहाँ एउटै मान छ, र दुवै member त्यसलाई पढ्ने दुई तरिका मात्र हुन्।

How to use this

Before the last step, predict what b.n will print. Almost everybody says 65, because that is what was put there — and no line since has mentioned n.

अन्तिम चरणअघि b.n ले के छाप्छ अनुमान गर्नुहोस्। झन्डै सबैले ६५ भन्छन्, किनभने त्यहाँ राखिएको त्यही थियो — र त्यसपछि कुनै लाइनले n को नाम लिएकै छैन।
6.5 and 6.6 — declaring and accessing

Both work exactly as they do for a structure, and that is the point worth stating plainly: union Box b; declares the variable, and b.n reaches a member with the same dot operator.

Nothing in the syntax distinguishes a union from a structure anywhere in a program — not the declaration, not the variable, not the access. The only difference is what the memory does, which is why the diagram above is the whole topic.

One practical rule follows from it: read back the member you wrote last. Writing b.n and then reading b.c is not an error the compiler will stop, and the value you get is the same bytes interpreted as a different type.

६.५ र ६.६ — घोषणा र पहुँच

दुवै structure मा जस्तै ठ्याक्कै उसरी नै चल्छन्, र स्पष्ट भन्नुपर्ने कुरा त्यही हो: union Box b; ले variable घोषणा गर्छ, र b.n ले उही dot operator ले member मा पुग्छ।

प्रोग्रामको कुनै ठाउँमा syntax ले union लाई structure बाट छुट्याउँदैन — न घोषणाले, न variable ले, न पहुँचले। फरक मेमोरीले के गर्छ भन्नेमा मात्र छ, र त्यसैले माथिको चित्र नै पूरै विषय हो।

यसबाट एउटा व्यावहारिक नियम निस्कन्छ: अन्तिम पटक लेखेकै member पढ्नुहोस्। b.n लेखेर b.c पढ्नु compiler ले रोक्ने त्रुटि होइन, र आउने मान उही byte लाई फरक प्रकारका रूपमा पढेको नतिजा हो।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Structure or union?

What you will learn: to choose between them from what the program needs, which is the form the examination question takes. The deciding question is whether more than one member must hold a value at the same time. तपाईंले के सिक्नुहुन्छ: प्रोग्रामलाई के चाहिन्छ हेरेर दुईमध्ये छान्न — परीक्षाको प्रश्न यही रूपमा आउँछ। निर्णय गर्ने प्रश्न यही हो: एकैचोटि एकभन्दा बढी member सँग मान हुनुपर्छ कि पर्दैन?

How to use this

Two clues give a union away every time: a size equal to the largest member rather than the total, and a member going strange after a different member was written.

दुई सुराकले union सधैं चिनाउँछन्: आकार जोड नभई सबैभन्दा ठूलो member बराबर हुनु, र अर्को member लेखेपछि एउटा member अनौठो हुनु।

Predict first · पहिले अनुमान गर्नुहोस्

For { int n; char c; float f; } with int 4 bytes, char 1 and float 4, what is sizeof for the structure and for the union? int ४ byte, char १ र float ४ हुँदा { int n; char c; float f; } को structure र union को sizeof कति हुन्छ?

The structure is at least 9 and the union is 4. A structure gives every member its own memory, so its size is the total: 4 + 1 + 4 = 9. A union gives them one shared block, so its size is the largest member: 4.

"At least" 9 rather than exactly 9, and this is worth knowing. Compilers insert unused bytes called padding so that each member starts at an address its type likes, so a real machine will often report 12 rather than 9. The rule is the total; the measurement may be larger. Saying "the sum of the members" is the expected examination answer, and measuring it yourself with sizeof in the practical is how you meet padding.

Option A is the two answers swapped, which is the usual way this is got wrong.

Structure कम्तीमा ९, union ४। Structure ले हरेक member लाई आफ्नै मेमोरी दिन्छ, त्यसैले आकार जोड हुन्छ: 4 + 1 + 4 = 9। Union ले एउटै साझा block दिन्छ, त्यसैले आकार सबैभन्दा ठूलो member बराबर — ४। ठ्याक्कै ९ नभई "कम्तीमा" ९ भनिनुको कारण पनि जान्नु राम्रो: हरेक member लाई उसको प्रकारले मन पराउने ठेगानाबाट सुरु गराउन compiler ले padding भनिने प्रयोगविहीन byte थप्छ, त्यसैले वास्तविक मेसिनले प्रायः ९ होइन १२ भन्छ। नियम जोड हो; नाप ठूलो हुन सक्छ। परीक्षाले खोज्ने उत्तर "member को जोड" हो, र padding सँग भेट प्रयोगात्मक कक्षामा sizeof आफैं नापेर हुन्छ। विकल्प (क) मा दुई उत्तर साटिएका छन्, र यो प्रायः त्यसरी नै बिग्रन्छ।
Example 2 Five students in one array of structures

Question: hold the records of five students and print them all. This is what the structure was for.

Decide how s[i].roll is read before opening this. Which part is the index and which part is the member? खोल्नुअघि s[i].roll कसरी पढिन्छ निर्णय गर्नुहोस्। कुन भाग index हो र कुन भाग member?

Working 
#include <stdio.h>

struct Student
{
    char name[20];
    int roll;
};

int main()
{
    struct Student s[5];        /* FIVE complete records */
    int i;

    for (i = 0; i < 5; i++)
    {
        printf("Student %d name and roll: ", i + 1);
        scanf("%s %d", s[i].name, &s[i].roll);
    }

    for (i = 0; i < 5; i++)
        printf("%d - %s\n", s[i].roll, s[i].name);

    return 0;
}

s[i].roll reads left to right: take element i of the array, then take its roll member. The index comes first because the array is of structures, not a structure of arrays. Note the two scanf arguments: s[i].name is a char array and takes no ampersand, &s[i].roll is an int and does — the same rule as always, applied inside a structure. Without the structure, five students would need two separate arrays kept in step with each other by hand. s[i].roll बायाँबाट दायाँ पढिन्छ: array को i औं element लिने, अनि त्यसको roll member। Index पहिले आउँछ, किनभने यो structure हरूको array हो, array हरूको structure होइन। scanf का दुई argument हेर्नुहोस्: s[i].name char array हो र ampersand लिँदैन, &s[i].roll int हो र लिन्छ — उही पुरानो नियम, structure भित्र लागू भएको। Structure नभए पाँच विद्यार्थीका लागि दुई छुट्टाछुट्टै array हातैले मिलाएर राख्नुपर्थ्यो।

Mistakes that cost marks here

  • Forgetting the semicolon after the closing brace. A structure declaration is a statement; a function definition is not.
  • Writing Student s1; without struct. In C the keyword is part of the type name.
  • Using the dot on the type instead of a variable. Student.roll names no memory; s1.roll does.
  • Saying a union's size is the total of its members. It is the size of the largest one.
  • Expecting both union members to keep their values. Only the one written last is meaningful.
  • Putting & before a char array member in scanf. s1.name is already an address; &s1.roll is not.
बन्द brace पछि semicolon बिर्सनु: structure को घोषणा statement हो; function definition होइन। struct बिना Student s1; लेख्नु: C मा त्यो keyword प्रकारकै नामको भाग हो। Variable होइन प्रकारमा dot लगाउनु: Student.roll ले कुनै मेमोरी जनाउँदैन, s1.roll ले जनाउँछ। Union को आकार member को जोड भन्नु: त्यो सबैभन्दा ठूलो member को आकार हो। Union का दुवै member ले आफ्नो मान राख्छन् भन्ठान्नु: अन्तिम लेखिएको मात्र अर्थपूर्ण हुन्छ। scanf मा char array member अगाडि & राख्नु: s1.name आफैं ठेगाना हो; &s1.roll होइन।

Memory hook — Structure: everyone gets a room. Union: everyone shares one room. Size is the total, or the largest. सम्झने तरिका — Structure: सबैलाई आ–आफ्नो कोठा। Union: सबैले एउटै कोठा बाँड्ने। आकार जोड, कि सबैभन्दा ठूलो।

Expect that, plus a program using a structure, and short questions on the dot operator and on what sizeof gives for each. यो युनिटले बाह्य ५० मध्ये ५ अंक र ६४ मध्ये ६ घण्टा ओगट्छ। सानो युनिट, र एउटै प्रश्न हावी छ: structure र union को फरक। त्यो, structure प्रयोग गरेको एउटा प्रोग्राम, अनि dot operator र हरेकको sizeof बारे छोटा प्रश्न अपेक्षा गर्नुहोस्।

2 marks Practice question

What is a structure? Write the syntax to declare one with an example. Structure भनेको के हो? उदाहरणसहित यसको घोषणाको syntax लेख्नुहोस्।

A structure is a user-defined data type that groups together variables of different data types under a single name. Each variable inside it is called a member and each member has its own memory.

Syntax: struct structure_name { data_type member1; data_type member2; };

Example: struct Student { char name[20]; int roll; float percent; }; and then struct Student s1; to create a variable.

Structure भनेको प्रयोगकर्ता-परिभाषित data type हो, जसले फरक data type का variable लाई एउटै नाममुनि समूहबद्ध गर्छ। भित्रका हरेक variable लाई member भनिन्छ र हरेकको आफ्नै मेमोरी हुन्छ। Syntax: struct structure_name { data_type member1; data_type member2; }; उदाहरण: struct Student { char name[20]; int roll; float percent; }; अनि variable बनाउन struct Student s1;।
4 marks Practice question

Differentiate between a structure and a union with an example. उदाहरणसहित structure र union को फरक लेख्नुहोस्।

1. Memory. A structure gives every member its own memory. A union gives all members the same memory.

2. Size. A structure's size is the sum of its members' sizes. A union's size is the size of its largest member.

3. Values at one time. In a structure all members hold their values at once. In a union only the member written most recently is meaningful.

4. Keyword. struct and union. Everything else about the syntax is identical, including the dot operator.

5. Use. A structure for a record of several facts about one thing; a union to save memory when only one member is ever in use.

Example: for { int n; char c; } the structure needs 5 bytes and keeps both values, while the union needs 4 and keeps only the last one written.

१. मेमोरी: structure ले हरेक member लाई आफ्नै दिन्छ; union ले सबैलाई उही। २. आकार: structure को आकार सबै member को जोड; union को सबैभन्दा ठूलो member बराबर। ३. एकैचोटि मान: structure मा सबै member का मान सँगै रहन्छन्; union मा अन्तिम लेखिएको मात्र अर्थपूर्ण। ४. Keyword: struct र union; dot operator सहित बाँकी syntax उस्तै। ५. प्रयोग: एउटै कुराबारे धेरै तथ्यको record लाई structure; एउटै member मात्र प्रयोगमा हुँदा मेमोरी बचाउन union। उदाहरण: { int n; char c; } मा structure लाई ५ byte चाहिन्छ र दुवै मान रहन्छन्, union लाई ४ चाहिन्छ र अन्तिम लेखिएको मात्र रहन्छ।

Key points from this unit

  • A structure groups variables of different types under one name; each member has its own memory.
  • Declaring a structure reserves nothing; declaring a variable of it does.
  • The semicolon after the closing brace is compulsory, and struct is part of the type name in C.
  • The dot operator joins a variable to a member: s1.roll.
  • A union is declared the same way and gives every member the same memory.
  • A structure's size is the total; a union's is the largest member.
  • In a union only the member written last holds a meaningful value.
  • Use a structure for a record, a union to save memory.
Structure ले फरक प्रकारका variable लाई एउटै नाममुनि राख्छ; हरेक member को आफ्नै मेमोरी हुन्छ। Structure घोषणा गर्दा केही छुट्टिँदैन; त्यसको variable घोषणा गर्दा छुट्टिन्छ। बन्द brace पछिको semicolon अनिवार्य छ, र C मा struct प्रकारकै नामको भाग हो। Dot operator ले variable लाई member सँग जोड्छ: s1.roll। Union उही तरिकाले घोषणा हुन्छ र हरेक member लाई उही मेमोरी दिन्छ। Structure को आकार जोड; union को सबैभन्दा ठूलो member बराबर। Union मा अन्तिम लेखिएको member सँग मात्र अर्थपूर्ण मान हुन्छ। Record का लागि structure, मेमोरी बचाउन union।
