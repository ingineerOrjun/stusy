2.1  The basic units of a computer system

Definition — learn this wording

Every computer, from a phone to a server, is built from the same five functional units: input, control, arithmetic and logic, memory and output.

The middle three together are the CPU (Central Processing Unit). That grouping is what a question means when it says "the components of the CPU".

The order matters and it is always the same: data comes in, is held in memory, is worked on by the ALU under the direction of the control unit, and the result goes out.

परिभाषा — यही शब्दमा सम्झनुहोस्

फोनदेखि सर्भरसम्म हरेक कम्प्युटर उही पाँच कार्यात्मक एकाइबाट बनेको हुन्छ: input, control, arithmetic and logic, memory र output।

बीचका तीन मिलेर CPU (Central Processing Unit) बन्छ। "CPU का भागहरू" भनेर सोधिँदा यही समूह खोजिएको हुन्छ।

क्रम महत्त्वपूर्ण छ र सधैं उही हुन्छ: data भित्र आउँछ, मेमोरीमा राखिन्छ, control unit को निर्देशनमा ALU ले काम गर्छ, र नतिजा बाहिर जान्छ।

Interactive experiment · अन्तरक्रियात्मक प्रयोग

Find each unit, and see what it is responsible for

What you will learn: where each unit sits in the flow and exactly what it is responsible for — so that when a question asks which unit does the comparing, you can see the answer rather than recall a sentence. तपाईंले के सिक्नुहुन्छ: प्रवाहमा हरेक एकाइ कहाँ पर्छ र ठ्याक्कै कसको के जिम्मेवारी हो — ताकि तुलना कसले गर्छ भन्ने प्रश्न आउँदा वाक्य सम्झनुभन्दा उत्तर देख्न सकियोस्।

Why this matters: "differentiate between the ALU and the control unit" is asked almost every year, and the marks are lost by students who know both words but attach the wrong job to each. Seeing them side by side in the flow fixes which is which.किन महत्त्वपूर्ण छ: "ALU र control unit फरक छुट्याउनुहोस्" झन्डै हरेक वर्ष सोधिन्छ, र अंक ती विद्यार्थीले गुमाउँछन् जसलाई दुवै शब्द थाहा हुन्छ तर काम उल्टो जोडिन्छ। प्रवाहमा सँगै देखेपछि कुन कुन हो पक्का हुन्छ।

2.2  The input unit

Definition — learn this wording

The input unit accepts data and instructions from the outside world and converts them into the binary form the computer can process.

Keyboard — each key press closes a switch; the keyboard controller turns that into a scan code, which becomes a character.

Mouse — a pointing device. An optical mouse photographs the surface many times a second and works out which way it moved.

Scanner — shines light across a document and measures the reflection, producing an image of the page. OCR software is what turns that image into editable text.

Digital camera — a lens focuses light onto an image sensor, which converts the brightness at each point into a number and stores it in memory.

परिभाषा — यही शब्दमा सम्झनुहोस्

Input unit ले बाहिरी संसारबाट data र निर्देशन लिन्छ र कम्प्युटरले प्रशोधन गर्न सक्ने binary रूपमा बदल्छ।

Keyboard — हरेक किथिचाइले एउटा स्विच बन्द गर्छ; keyboard controller ले त्यसलाई scan code बनाउँछ, जुन अक्षर बन्छ।

Mouse — देखाउने उपकरण। Optical mouse ले सेकेन्डमा धेरै पटक सतहको फोटो खिच्छ र कता सर्‍यो पत्ता लगाउँछ।

Scanner — कागजमा बत्ती पार गरेर परावर्तन नाप्छ, र पानाको चित्र बनाउँछ। त्यो चित्रलाई सम्पादन गर्न मिल्ने अक्षरमा बदल्ने काम OCR सफ्टवेयरको हो।

Digital camera — लेन्सले बत्ती image sensor मा केन्द्रित गर्छ, जसले हरेक बिन्दुको उज्यालोलाई सङ्ख्यामा बदलेर मेमोरीमा राख्छ।

Predict first · पहिले अनुमान गर्नुहोस्

You scan a printed page. Straight afterwards, can you edit the words in a word processor? तपाईंले छापिएको पाना स्क्यान गर्नुभयो। लगत्तै word processor मा शब्दहरू सम्पादन गर्न सकिन्छ?

A scanner is a light sensor, not a reader. What it produces is a picture of the page — the letters in it are just dark pixels. OCR (Optical Character Recognition) software has to examine that picture and work out which shapes are which characters before anything becomes editable text.

Scanner बत्ती नाप्ने सेन्सर हो, पढ्ने यन्त्र होइन। यसले पानाको तस्बिर दिन्छ — त्यसका अक्षर केवल कालो पिक्सेल हुन्। OCR (Optical Character Recognition) सफ्टवेयरले त्यो तस्बिर हेरेर कुन आकार कुन अक्षर हो पत्ता लगाएपछि मात्र सम्पादन गर्न मिल्ने अक्षर बन्छ।

2.3  The processing unit — ALU and control unit

Definition — learn this wording

The ALU (Arithmetic and Logic Unit) performs all arithmetic operations (+ − × ÷) and all logical operations (greater than, less than, equal to, AND, OR, NOT). Every calculation and every comparison in the machine happens here and nowhere else.

The control unit (CU) directs the whole system. It fetches each instruction from memory, decodes it to work out what is required, and sends the signals that tell each unit what to do and when. It does not calculate anything itself.

A useful picture: the ALU is the worker, the control unit is the supervisor. The supervisor decides what gets done next; the worker does it.

परिभाषा — यही शब्दमा सम्झनुहोस्

ALU (Arithmetic and Logic Unit) ले सबै अंकगणितीय काम (+ − × ÷) र सबै तार्किक काम (ठूलो, सानो, बराबर, AND, OR, NOT) गर्छ। मेसिनको हरेक गणना र हरेक तुलना यहीँ हुन्छ, अन्त कतै हुँदैन।

Control unit (CU) ले पूरै प्रणाली निर्देशित गर्छ। मेमोरीबाट हरेक निर्देशन ल्याउँछ, के चाहिएको हो बुझ्छ, र कुन एकाइले कहिले के गर्ने भन्ने सङ्केत पठाउँछ। यसले आफैँ केही गणना गर्दैन।

सम्झने तरिका: ALU कामदार हो, control unit सुपरभाइजर। सुपरभाइजरले अब के गर्ने भन्छ; कामदारले गर्छ।

Example 1 Which unit does what, on one instruction

Question: a program contains the instruction IF marks > 40 THEN print "PASS". Which unit does each part of the work?

Before you read on, decide one thing: which unit performs the comparison?पढ्नुअघि एउटा कुरा निर्णय गर्नुहोस्: तुलना कुन एकाइले गर्छ?

Step 1 — the instruction has to be brought in. The control unit fetches it from memory and decodes it.

Step 2 — the value of marks has to be available. It is held in the memory unit.

Step 3 — marks > 40 has to be evaluated. That is a comparison, which is a logical operation, so the ALU does it and reports true or false.

Step 4 — the result decides what happens next. The control unit reads the ALU's answer and directs the machine to the printing instruction.

Step 5 — "PASS" reaches the user. Through the output unit.

Answer
CU fetches and decodes · memory holds the value · ALU compares · CU acts on the result · output unit displays

Notice the control unit appears twice and never calculates. That is the distinction the exam is testing. ध्यान दिनुहोस्, control unit दुई पटक आउँछ र कहिल्यै गणना गर्दैन। परीक्षाले जाँच्ने भिन्नता यही हो।

2.4  The display unit

Definition — learn this wording

Resolution is the number of pixels across by the number down — 1366 × 768. More pixels means a sharper picture and more detail in the same area.

Colour depth is the number of bits used to describe one pixel's colour. 24-bit gives about 16.7 million colours; fewer bits produce visible banding in a gradient.

Refresh rate is how many times per second the screen is redrawn, measured in hertz. 60 Hz means sixty times a second. Too low a rate is visible as flicker and causes eye strain.

CRT fires an electron beam at a phosphor coating — bulky, heavy, hot, most power. LCD uses liquid crystals to block or pass light from a lamp behind them — flat and far cooler. LED is an LCD whose backlight is made of LEDs instead — thinner still, better contrast, least power.

परिभाषा — यही शब्दमा सम्झनुहोस्

Resolution भनेको चौडाइका पिक्सेल × उचाइका पिक्सेल — १३६६ × ७६८। बढी पिक्सेल भनेको उही ठाउँमा तीक्ष्ण तस्बिर र बढी विवरण।

Colour depth भनेको एउटा पिक्सेलको रङ बताउन प्रयोग हुने bit सङ्ख्या। २४-bit ले करिब १ करोड ६७ लाख रङ दिन्छ; कम bit भए रङ बदलिँदा पट्टीहरू देखिन्छन्।

Refresh rate भनेको स्क्रिन सेकेन्डमा कति पटक फेरि कोरिन्छ — hertz मा नापिन्छ। ६० Hz भनेको सेकेन्डमा साठी पटक। धेरै कम भए झिमझिम देखिन्छ र आँखा दुख्छ।

CRT ले phosphor मा electron किरण हान्छ — ठूलो, गह्रौं, तातो, सबैभन्दा बढी बिजुली। LCD ले पछाडिको बत्तीलाई liquid crystal ले छेक्ने वा पास गर्ने गर्छ — पातलो र धेरै चिसो। LED भनेको त्यही LCD हो, तर पछाडिको बत्ती LED को — झन् पातलो, राम्रो contrast, सबैभन्दा कम बिजुली।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Which display property is being described?

What you will learn: to match a symptom or a description to resolution, colour depth or refresh rate — which is how these three are actually asked about, rather than as bare definitions. तपाईंले के सिक्नुहुन्छ: कुनै लक्षण वा विवरणलाई resolution, colour depth वा refresh rate सँग मिलाउन — किनकि यी तीन कुरा खाली परिभाषाका रूपमा होइन, यसरी नै सोधिन्छन्।

Why this matters: a user complaint is never "my refresh rate is low" — it is "the screen flickers and my eyes hurt". Translating the complaint into the property is the actual skill.किन महत्त्वपूर्ण छ: प्रयोगकर्ताले "मेरो refresh rate कम छ" कहिल्यै भन्दैन — "स्क्रिन झिमझिम गर्छ र आँखा दुख्छ" भन्छ। गुनासोलाई गुणमा बदल्नु नै वास्तविक सीप हो।

Example 2 How much memory does one screen of picture need?

Question: a monitor runs at 1366 × 768 with 24-bit colour depth. How much memory does a single frame occupy?

You have every number you need. Work out the two steps before reading on.चाहिने सबै सङ्ख्या तपाईंसँग छन्। पढ्नुअघि दुई चरण आफैँ निकाल्नुहोस्।

Step 1 — how many pixels are on the screen? Resolution is across × down, so 1366 × 768 = 1,049,088 pixels.

Step 2 — how many bytes does each pixel need? Colour depth is bits per pixel, and 8 bits make a byte, so 24-bit = 3 bytes per pixel.

Step 3 — multiply. 1,049,088 × 3 = 3,147,264 bytes, which is about 3 MB.

Answer
About 3 MB for one frame

Now see why refresh rate matters to the hardware: at 60 Hz the graphics card must deliver that 3 MB sixty times every second. Resolution, colour depth and refresh rate are not three unrelated settings — they multiply together into the work the card has to do. अब refresh rate हार्डवेयरका लागि किन महत्त्वपूर्ण छ हेर्नुहोस्: ६० Hz मा ग्राफिक्स कार्डले त्यही ३ MB सेकेन्डमा साठी पटक पुर्‍याउनुपर्छ। Resolution, colour depth र refresh rate तीन असम्बन्धित सेटिङ होइनन् — यी गुणन भएर कार्डले गर्नुपर्ने काम बन्छन्।

Mistakes that cost marks here

  • Saying the control unit performs calculations. It fetches, decodes and directs. Every calculation and comparison is the ALU's. Control unit ले गणना गर्छ भन्नु। यसले ल्याउँछ, बुझ्छ र निर्देशन दिन्छ। हरेक गणना र तुलना ALU को हो।
  • Calling a scanner an output device because it produces a file. Direction is judged by where the data is going: into the computer is input. फाइल बन्छ भन्दैमा scanner लाई output भन्नु। दिशा data कता जान्छ भन्नेले तय हुन्छ: कम्प्युटरभित्र जान्छ भने input हो।
  • Confusing resolution with screen size. A large monitor can have a low resolution and look worse than a small one with a high resolution. Resolution र स्क्रिनको आकार मिसाउनु। ठूलो monitor को resolution कम भए त्यो उच्च resolution भएको सानो भन्दा नराम्रो देखिन्छ।
  • Writing that LED is a completely different technology from LCD. It is an LCD with an LED backlight — the crystals are the same. LED लाई LCD भन्दा पूरै फरक प्रविधि लेख्नु। यो LED backlight भएको LCD हो — crystal उही हुन्।

CU directs, ALU calculates. LED is an LCD with a new lamp. CU ले निर्देशन दिन्छ, ALU ले गणना गर्छ। LED भनेको नयाँ बत्ती भएको LCD हो।

Exam focus — what is asked from this unit

This unit is the vocabulary the rest of the subject is written in, and it carries 8 marks. Expect list questions (name four input devices), differentiate questions (ALU vs control unit, CRT vs LCD vs LED, input vs output device) and define questions (resolution, colour depth, refresh rate). The block diagram of a computer system with its units labelled is the one diagram from this unit you may be asked to draw — and the arrows between the blocks are worth marks, not just the boxes. यो युनिट बाँकी विषय लेखिने शब्दावली हो, र यसले ८ अंक बोक्छ। सूची प्रश्न (चार input उपकरणको नाम), फरक छुट्याउने प्रश्न (ALU र control unit, CRT–LCD–LED, input र output) र परिभाषा प्रश्न (resolution, colour depth, refresh rate) आउँछन्। यस युनिटबाट कोर्न सकिने चित्र एकाइ नामांकित कम्प्युटर प्रणालीको ब्लक डायग्राम हो — र बाकसबीचका तीर पनि अंक बोक्छन्, बाकस मात्र होइन।

Q1 3 marks

Differentiate between the ALU and the control unit, with one example of the work each does. ALU र control unit बीचको फरक छुट्याउनुहोस्, र हरेकले गर्ने कामको एउटा उदाहरण दिनुहोस्।

The ALU performs all arithmetic operations (+ − × ÷) and all logical operations (comparisons, AND, OR, NOT) — for example, evaluating whether marks > 40. The control unit does not calculate at all; it fetches each instruction from memory, decodes it, and generates the signals that tell the other units what to do and when — for example, directing the machine to the next instruction once the ALU reports its result.

ALU ले सबै अंकगणितीय (+ − × ÷) र सबै तार्किक (तुलना, AND, OR, NOT) काम गर्छ — जस्तै, marks > 40 हो कि होइन जाँच्ने। Control unit ले गणना गर्दैनँ; यसले मेमोरीबाट हरेक निर्देशन ल्याउँछ, बुझ्छ, र अरू एकाइलाई कहिले के गर्ने भन्ने सङ्केत बनाउँछ — जस्तै, ALU ले नतिजा दिएपछि मेसिनलाई अर्को निर्देशनतिर लैजाने।

Q2 3 marks

Define resolution and refresh rate. State one problem a user notices when the refresh rate is too low. Resolution र refresh rate को परिभाषा दिनुहोस्। Refresh rate धेरै कम हुँदा प्रयोगकर्ताले देख्ने एउटा समस्या लेख्नुहोस्।

Resolution is the number of pixels displayed across the screen by the number down, for example 1366 × 768; a higher resolution gives a sharper, more detailed picture. Refresh rate is the number of times per second the screen image is redrawn, measured in hertz. When it is too low the user sees visible flicker, which causes eye strain and headaches.

Resolution भनेको स्क्रिनको चौडाइमा देखिने पिक्सेल × उचाइमा देखिने पिक्सेल, जस्तै १३६६ × ७६८; बढी resolution ले तीक्ष्ण र बढी विवरणसहितको तस्बिर दिन्छ। Refresh rate भनेको स्क्रिनको तस्बिर सेकेन्डमा कति पटक फेरि कोरिन्छ, hertz मा नापिने। धेरै कम हुँदा प्रयोगकर्ताले झिमझिम देख्छ, जसले आँखा थकाइ र टाउको दुखाइ ल्याउँछ।

Q3 2 marks

Name any four input devices and state what kind of data each one brings in. कुनै चार input उपकरणको नाम लेख्नुहोस् र हरेकले कस्तो data भित्र ल्याउँछ भन्नुहोस्।

Keyboard — characters and commands typed by the user. Mouse — position and selection. Scanner — an image of a printed document. Digital camera — photographs as image data. (Also acceptable: microphone for sound, joystick for movement, barcode reader for product codes.)

Keyboard — प्रयोगकर्ताले टाइप गरेका अक्षर र आदेश। Mouse — स्थान र छनोट। Scanner — छापिएको कागजको चित्र। Digital camera — तस्बिर, image data का रूपमा। (माइक्रोफोन–आवाज, joystick–चाल, barcode reader–उत्पादन कोड पनि मान्य।)

Key points to revise — दोहोर्‍याउनुपर्ने मुख्य बुँदा

  • Five units: input, control, ALU, memory, output. The middle three are the CPU. पाँच एकाइ: input, control, ALU, memory, output। बीचका तीन मिलेर CPU।
  • ALU does arithmetic and logic. The control unit fetches, decodes and directs — and calculates nothing. ALU ले अंकगणित र तर्क गर्छ। Control unit ले ल्याउँछ, बुझ्छ र निर्देशन दिन्छ — गणना गर्दैन।
  • Input devices: keyboard, mouse, scanner, digital camera. A scanner gives an image; OCR turns it into text. Input उपकरण: keyboard, mouse, scanner, digital camera। Scanner ले चित्र दिन्छ; OCR ले अक्षरमा बदल्छ।
  • Resolution = pixels across × down. Colour depth = bits per pixel. Refresh rate = redraws per second in Hz. Resolution = चौडाइ × उचाइका पिक्सेल। Colour depth = प्रति पिक्सेल bit। Refresh rate = सेकेन्डमा फेरि कोरिने पटक, Hz मा।
  • CRT is bulky and uses most power; LCD is flat and cooler; LED is an LCD with an LED backlight — thinnest and least power. CRT ठूलो र सबैभन्दा बढी बिजुली खान्छ; LCD पातलो र चिसो; LED भनेको LED backlight भएको LCD — सबैभन्दा पातलो र कम बिजुली।
