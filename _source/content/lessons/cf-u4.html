4.1  What computer memory is — कम्प्युटर मेमोरी भनेको के हो

Predict first · पहिले अनुमान गर्नुहोस्

You are typing an essay and the power goes off before you save. The essay is gone. Your photographs from last year are still there. Both were "in the computer". Why did one survive and the other not? तपाईं निबन्ध टाइप गर्दै हुनुहुन्थ्यो, सेभ गर्नुअघि बत्ती गयो। निबन्ध हरायो। गत वर्षका फोटा भने छँदै छन्। दुवै "कम्प्युटरमै" थिए। एउटा किन बाँच्यो र अर्को किन बाँचेन?

Two different kinds of memory. The essay you were typing was in RAM, which stores each bit as a charge that has to be refreshed thousands of times a second. Cut the power and the charge drains — this is called volatile. The photographs were on the hard disk, where each bit is a direction of magnetism, or on an SSD, where it is a trapped charge in an insulated cell. Neither needs power to stay put: non-volatile.

"Save" is exactly the act of copying from the volatile place to the non-volatile one. That is why the instruction to save often is not nagging — it is a statement about physics.

दुई फरक किसिमको मेमोरी। टाइप गरिरहेको निबन्ध RAM मा थियो, जहाँ हरेक bit चार्जका रूपमा रहन्छ र सेकेन्डमा हजारौं पटक ताजा पार्नुपर्छ। बत्ती गए चार्ज रित्तिन्छ — यसलाई volatile भनिन्छ। फोटा hard disk मा थिए, जहाँ हरेक bit चुम्बकत्वको दिशा हो, वा SSD मा, जहाँ इन्सुलेट गरिएको कक्षमा चार्ज थुनिएको हुन्छ। दुवैलाई रहन बिजुली चाहिँदैन: non-volatile। "Save" भनेकै volatile ठाउँबाट non-volatile ठाउँमा सार्ने काम हो।
The definition, with the part students leave out

Memory is the part of a computer that stores data, instructions and results, so that they can be used when needed.

The part usually left out is instructions. Memory does not only hold the numbers you are working on — it holds the program that is working on them. That is the stored-program idea from Unit 1, and memory is where it is stored.

Memory is measured in bits and bytes: 1 byte = 8 bits, 1 KB = 1024 bytes, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB. Each unit is 210 of the one below because memory addresses are binary.

परिभाषा, र विद्यार्थीले छुटाउने भाग

मेमोरी कम्प्युटरको त्यो भाग हो जसले data, निर्देशन र नतिजा राख्छ, ताकि आवश्यक पर्दा प्रयोग गर्न सकियोस्।

प्रायः छुट्ने भाग निर्देशन हो। मेमोरीले तपाईंले चलाइरहेको संख्या मात्र होइन, त्यो चलाउने प्रोग्राम पनि राख्छ। युनिट १ को stored-program विचार यही हो, र भण्डारण हुने ठाउँ मेमोरी।

मेमोरी bit र byte मा नापिन्छ: 1 byte = 8 bit, 1 KB = 1024 byte, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB। हरेक एकाइ तलकोभन्दा २१० गुणा, किनभने मेमोरीका ठेगाना binary मा हुन्छन्।

4.2  Types of memory — मेमोरीका किसिम

A pyramid, not a list

Memory is usually divided into primary (main) memory and secondary (auxiliary) storage, with cache and registers above both. Learn it as a pyramid, because the shape explains the order.

The whole arrangement comes from one trade-off: fast memory is expensive, so there is little of it; cheap memory is slow, so there is a lot of it. Nobody would build four kinds of memory if one kind could be fast, big and cheap at once.

Going up the pyramid: faster, smaller, costlier per byte. Going down: slower, bigger, cheaper per byte. Every fact in this unit follows from those two sentences.

सूची होइन, पिरामिड

मेमोरीलाई सामान्यतया primary (मुख्य) र secondary (सहायक) मा बाँडिन्छ, र दुवैभन्दा माथि cache तथा register हुन्छन्। पिरामिडका रूपमा सिक्नुहोस्, किनभने आकारले नै क्रम बुझाउँछ।

यो पूरै बनावट एउटै सम्झौताबाट आउँछ: छिटो मेमोरी महँगो हुन्छ, त्यसैले थोरै हुन्छ; सस्तो मेमोरी ढिलो हुन्छ, त्यसैले धेरै हुन्छ। एउटै किसिम छिटो, ठूलो र सस्तो हुन सक्थ्यो भने चार किसिम कसैले बनाउने थिएन।

पिरामिडमा माथि जाँदा: छिटो, सानो, प्रति byte महँगो। तल जाँदा: ढिलो, ठूलो, प्रति byte सस्तो। यस युनिटका हरेक तथ्य यिनै दुई वाक्यबाट निस्कन्छन्।

4.3  Cache memory — Cache memory

A small fast shelf between two mismatched speeds

Cache memory is a small amount of very fast memory placed between the CPU and RAM. It holds the data and instructions the CPU has used most recently, on the reasonable bet that it will want them again soon.

It exists because of a mismatch. A modern CPU can carry out an instruction in well under a nanosecond; fetching from RAM takes tens of nanoseconds. Without cache the processor would spend most of its life waiting. Cache is the shelf within arm's reach, while RAM is the cupboard across the room.

When the CPU finds what it wants in cache that is a cache hit; when it does not, a cache miss, and it must go to RAM. More cache means more hits, which is why cache size appears in processor advertisements.

Cache is volatile, like RAM, and it is usually built onto the processor chip itself. You cannot buy it separately or add more to a computer you own.

दुई नमिल्ने गतिबीचको सानो छिटो तखता

Cache memory भनेको CPU र RAM बीचमा राखिएको थोरै तर धेरै छिटो मेमोरी हो। CPU ले भर्खरै चलाएको data र निर्देशन राख्छ, चाँडै फेरि चाहिन्छ भन्ने व्यावहारिक अनुमानमा।

यो हुनुको कारण गतिको बेमेल हो। आजको CPU ले एक निर्देशन नानोसेकेन्डभन्दा कममा सक्छ; RAM बाट ल्याउन दसौं नानोसेकेन्ड लाग्छ। Cache नभए प्रोसेसरको धेरैजसो समय पर्खाइमै जान्थ्यो। Cache हात पुग्ने तखता हो, RAM कोठा पारिको दराज।

CPU ले खोजेको कुरा cache मै भेट्यो भने cache hit; भेटेन भने cache miss र RAM सम्म जानुपर्छ। बढी cache = बढी hit, त्यसैले प्रोसेसरको विज्ञापनमा cache को आकार लेखिन्छ।

Cache RAM जस्तै volatile हो, र प्रायः प्रोसेसर चिपमै बनेको हुन्छ। छुट्टै किन्न वा थप्न मिल्दैन।

4.4  Primary / main memory — Primary / मुख्य मेमोरी

The memory the CPU can reach directly

Primary memory is the memory the CPU can read from and write to directly. Nothing in secondary storage can be worked on until it has been copied here first — which is why a large file takes a moment to open.

Characteristics: directly accessible by the CPU; much faster than secondary storage; limited in capacity; costlier per byte; and semiconductor-based rather than mechanical.

Primary memory is of two kinds, and they differ in a single respect that decides everything else: can the CPU write to it?

CPU ले सिधै पुग्न सक्ने मेमोरी

Primary memory त्यो हो जसमा CPU ले सिधै पढ्न र लेख्न सक्छ। Secondary storage को कुनै पनि कुरा यहाँ नसारेसम्म चलाउनै मिल्दैन — ठूलो फाइल खोल्दा केही क्षण लाग्नुको कारण यही हो।

विशेषता: CPU ले सिधै पुग्न सक्ने; secondary भन्दा धेरै छिटो; क्षमता सीमित; प्रति byte महँगो; र यान्त्रिक होइन, semiconductor मा बनेको।

Primary memory दुई किसिमका छन्, र फरक एउटै कुरामा छ जसले बाँकी सबै तय गर्छ: CPU ले त्यसमा लेख्न सक्छ?

RAM and ROM, and the families inside each

RAM — Random Access Memory. Read and write. Volatile: it empties when the power goes. This is the computer's working space, and "4 GB of memory" in an advertisement means RAM.

  • SRAM (Static RAM) — holds each bit in a flip-flop circuit, needs no refreshing, very fast, expensive. This is what cache is made of.
  • DRAM (Dynamic RAM) — holds each bit as a charge in a tiny capacitor that leaks, so it must be refreshed thousands of times a second. Slower than SRAM, far cheaper, so it is what main memory is made of.

ROM — Read Only Memory. Read only in normal use. Non-volatile: its contents survive the power going off. It holds the instructions the computer needs the moment it starts, before any disk has been read — the BIOS and the startup routine.

  • PROM (Programmable ROM) — blank when made, written once by the buyer, never again.
  • EPROM (Erasable PROM) — can be erased by ultraviolet light and rewritten. The chip has a small quartz window for the light.
  • EEPROM (Electrically Erasable PROM) — erased electrically, with no window and without removing the chip. Flash memory is a development of this, which is why a pen drive can be rewritten in place.
RAM — पढ्न र लेख्न मिल्ने, volatile; कम्प्युटरको काम गर्ने ठाउँ। SRAM: flip-flop मा, refresh नचाहिने, धेरै छिटो, महँगो — cache यही हो। DRAM: साना capacitor मा चार्ज, चुहिने भएकाले सेकेन्डमा हजारौं पटक refresh गर्नुपर्ने; ढिलो तर निकै सस्तो — main memory यही हो। ROM — सामान्य प्रयोगमा पढ्न मात्र, non-volatile; कम्प्युटर सुरु हुने बित्तिकै चाहिने निर्देशन (BIOS) राख्छ। PROM: एक पटक मात्र लेख्न मिल्ने। EPROM: पराबैजनी किरण ले मेटेर फेरि लेख्न मिल्ने; चिपमा सानो क्वार्ज झ्याल हुन्छ। EEPROM: विद्युतीय रूपमा मेटिने, झ्याल नचाहिने, चिप नझिकी — flash memory यसैको विकास हो।

4.5  Secondary memory — Secondary मेमोरी

Where things stay when the power does not

Secondary memory — also called auxiliary or backup storage — holds data and programs permanently, for as long as you want them, whether or not the computer is on.

Characteristics: non-volatile; large capacity; cheap per byte; slower than primary memory; and not directly accessible by the CPU — everything must be copied into RAM before it can be used. That last one is the characteristic worth the mark.

It comes in three families, told apart by how a bit is physically stored:

  • Magnetic — a bit is a direction of magnetism on a coated surface. Hard disk: spinning platters and a moving head, so it has moving parts and can be damaged by a knock. SSD is grouped here by the curriculum, though it is really flash: no moving parts, much faster, costlier per gigabyte.
  • Optical — a bit is a pit or a flat area burned into a surface and read by a laser. CD (about 700 MB), DVD (4.7 GB), Blu-ray (25 GB and up). Cheap, removable, scratch easily.
  • Flash — a bit is a charge trapped in an insulated cell, with no moving parts at all. Pen drive, memory card. Small, sturdy, rewritable, limited in how many times each cell can be rewritten.
बत्ती नभए पनि रहने ठाउँ

Secondary memory — सहायक वा ब्याकअप भण्डारण — ले data र प्रोग्राम स्थायी रूपमा राख्छ, कम्प्युटर खुला होस् या नहोस्।

विशेषता: non-volatile; ठूलो क्षमता; प्रति byte सस्तो; primary भन्दा ढिलो; र CPU ले सिधै पुग्न नसक्ने — प्रयोग गर्नुअघि सबै RAM मा सार्नैपर्छ। अन्तिम विशेषता नै अंक बोक्ने हो।

यसका तीन परिवार छन्, bit भौतिक रूपमा कसरी राखिन्छ भन्ने आधारमा:

  • Magnetic — bit भनेको लेपित सतहमा चुम्बकत्वको दिशा। Hard disk: घुम्ने थाल र चल्ने head, त्यसैले चल्ने भाग हुन्छन् र ठक्कर लाग्दा बिग्रन सक्छ। SSD लाई पाठ्यक्रमले यहीँ राखेको छ, वास्तवमा यो flash हो: चल्ने भाग छैन, धेरै छिटो, प्रति GB महँगो।
  • Optical — bit भनेको सतहमा पोलिएको खाल्डो वा समथर भाग, लेजरले पढ्छ। CD (करिब ७०० MB), DVD (4.7 GB), Blu-ray (25 GB वा बढी)। सस्तो, झिक्न मिल्ने, चाँडै कोतरिने।
  • Flash — bit भनेको इन्सुलेट कक्षमा थुनिएको चार्ज, चल्ने भाग शून्य। Pen drive, memory card। सानो, बलियो, पुनर्लेखनयोग्य, तर हरेक कक्ष कति पटक लेख्न मिल्ने भन्ने सीमा हुन्छ।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Which memory is being described?

What you will learn: to identify a memory from a property rather than from its name — which is how the examination asks it. Two cases are separated only by whether the thing survives a power cut. तपाईंले के सिक्नुहुन्छ: नामबाट होइन, गुणबाट मेमोरी चिन्न — परीक्षाले सोध्ने तरिका यही हो। दुई केसको फरक बत्ती गएपछि बाँच्छ कि बाँच्दैन भन्नेमा मात्र छ।

How to use this

For each case ask two questions in order: does it survive a power cut, and can the CPU reach it directly? Those two answers place almost every memory in the subject.

हरेक केसमा क्रमैसँग दुई प्रश्न सोध्नुहोस्: बत्ती गएपछि बाँच्छ? CPU ले सिधै पुग्छ? यी दुई उत्तरले यस विषयका झन्डै सबै मेमोरी ठाउँमा राख्छन्।
Example 1 Why opening a large file takes a moment

Question: a student double-clicks a 200 MB video on the hard disk. Trace what has to happen before the first frame appears, and explain the pause.

Before opening: which of the memories above can the CPU read from directly, and where is the video right now? खोल्नुअघि: माथिका मेमोरीमध्ये CPU ले कुनबाट सिधै पढ्न सक्छ, र भिडियो अहिले कहाँ छ?

Working
1 the video is on the HARD DISK — secondary storage 2 the CPU cannot read secondary storage directly 3 so the OS copies part of the file from disk into RAM 4 the disk is mechanical and slow; RAM is electronic and fast 5 the CPU reads the copy in RAM and decodes the first frame 6 the frame is sent to the output unit and appears The pause is step 3 — the slowest link in the chain. It is the disk being read, not the CPU being slow.

This is why installing an SSD makes an old computer feel new while a faster processor often does not: the wait was never the CPU. पुरानो कम्प्युटरमा SSD हाल्दा नयाँ जस्तो हुनुको र छिटो प्रोसेसरले प्रायः फरक नपर्नुको कारण यही हो: पर्खाइ CPU को कहिल्यै थिएन।

Example 2 How much is 2 GB, in characters?

Question: a pen drive holds 2 GB. Roughly how many characters of plain text is that, and why is the answer not simply 2,000,000,000?

Two facts are needed: how many bytes are in a gigabyte, and how many bytes one character takes. Work it out before opening this. दुई तथ्य चाहिन्छ: एक gigabyte मा कति byte, र एक अक्षरले कति byte लिन्छ। खोल्नुअघि निकाल्नुहोस्।

Working
1 character = 1 byte (8 bits) 1 KB = 1024 bytes 1 MB = 1024 × 1024 = 1,048,576 bytes 1 GB = 1024 × 1,048,576 = 1,073,741,824 bytes 2 GB = 2,147,483,648 bytes So about 2.1 BILLION characters, not 2.0 billion. The difference is over 147 million characters — more than a hundred full-length books. Why not 2,000,000,000: memory is addressed in binary, so each step up is 2^10 = 1024, not 1000.

This is why a "2 GB" pen drive and a "2 GB" advertisement can disagree: some manufacturers count in thousands and the computer counts in 1024s. "2 GB" को पेन ड्राइभ र "2 GB" को विज्ञापन किन मिल्दैनन् भन्ने कारण यही हो: कतिपय उत्पादकले हजारमा गन्छन्, कम्प्युटरले १०२४ मा।

Mistakes that cost marks here

  • Saying RAM is "Random Access Memory, which is temporary" and stopping. The mark is for volatile and for read and write. Temporary alone is vague.
  • Calling ROM "memory you cannot write to". PROM, EPROM and EEPROM can all be written — once, with UV light, or electrically. ROM is read-only in normal use.
  • Putting cache below RAM. Cache is faster than RAM and sits between RAM and the CPU.
  • Saying the CPU reads a file from the hard disk. It cannot. The file is copied into RAM first, every time.
  • Confusing SRAM and DRAM by speed alone. The real difference is refreshing: DRAM leaks and must be refreshed, SRAM does not.
RAM लाई "अस्थायी" मात्र भन्नु: अंक volatile र पढ्न–लेख्न मिल्ने भन्नुमा छ। ROM लाई "लेख्नै नमिल्ने" भन्नु: PROM, EPROM, EEPROM मा लेख्न मिल्छ — एक पटक, UV ले, वा विद्युतीय रूपमा। Cache लाई RAM भन्दा तल राख्नु: cache RAM भन्दा छिटो छ र CPU सँग नजिक। CPU ले hard disk बाट फाइल पढ्छ भन्नु: सक्दैन — हरेक पटक RAM मा सारिन्छ। SRAM/DRAM लाई गतिले मात्र छुट्याउनु: साँचो फरक refresh मा छ।

Memory hook — RAM forgets, ROM remembers. Cache is close, disk is far. सम्झने तरिका — RAM बिर्सन्छ, ROM सम्झन्छ। Cache नजिक, disk टाढा।

4 marks Practice question

Differentiate between RAM and ROM. RAM र ROM बीचको फरक लेख्नुहोस्।

RAM (Random Access Memory) — data can be both read and written; it is volatile, so its contents are lost when power is switched off; it holds the programs and data currently in use; its types are SRAM and DRAM.

ROM (Read Only Memory) — in normal use data can only be read; it is non-volatile, so contents remain without power; it holds the startup instructions such as the BIOS; its types are PROM, EPROM and EEPROM.

Write them as matched pairs. Four marks is normally four differences, one mark each.

RAM — पढ्न र लेख्न दुवै मिल्ने; volatile; अहिले चलिरहेका प्रोग्राम र data राख्ने; किसिम SRAM र DRAM। ROM — सामान्य प्रयोगमा पढ्न मात्र; non-volatile; BIOS जस्ता सुरुवाती निर्देशन राख्ने; किसिम PROM, EPROM, EEPROM। जोडी मिलाएर लेख्नुहोस्।
2 marks Practice question

What is cache memory? Why is it used? Cache memory भनेको के हो? किन प्रयोग गरिन्छ?

Cache memory is a small, very fast memory placed between the CPU and main memory that stores the data and instructions most recently used by the CPU.

It is used because the CPU is much faster than RAM. Keeping recently used items close by means the processor spends less time waiting for RAM, so the computer runs faster.

Cache memory भनेको CPU र main memory बीचमा राखिएको सानो तर धेरै छिटो मेमोरी हो, जसले CPU ले भर्खरै चलाएका data र निर्देशन राख्छ। CPU, RAM भन्दा धेरै छिटो भएकाले यो चाहिन्छ: नजिकै राखेपछि प्रोसेसरले RAM कुर्नुपर्ने समय घट्छ।
4 marks Practice question

What is secondary memory? Explain its types with examples. Secondary memory भनेको के हो? यसका किसिम उदाहरणसहित बुझाउनुहोस्।

Secondary memory is non-volatile storage used to keep data and programs permanently. It has a large capacity, is cheaper per byte than primary memory, and cannot be accessed directly by the CPU — its contents must be copied into RAM first.

1. Magnetic storage — stores bits as magnetism. Examples: hard disk, SSD (as grouped by the curriculum).
2. Optical storage — stores bits as pits read by a laser. Examples: CD, DVD, Blu-ray disc.
3. Flash memory — stores bits as trapped charge, no moving parts. Example: pen drive.

Secondary memory भनेको data र प्रोग्राम स्थायी रूपमा राख्ने non-volatile भण्डारण हो; ठूलो क्षमता, प्रति byte सस्तो, र CPU ले सिधै पुग्न नसक्ने। किसिम: Magnetic (hard disk, SSD), Optical (CD, DVD, Blu-ray), Flash (pen drive)।
2 marks Practice question

Write the full forms: RAM, ROM, PROM, EPROM, EEPROM, SRAM, DRAM. पूरा रूप लेख्नुहोस्: RAM, ROM, PROM, EPROM, EEPROM, SRAM, DRAM।

RAM — Random Access Memory
ROM — Read Only Memory
PROM — Programmable Read Only Memory
EPROM — Erasable Programmable Read Only Memory
EEPROM — Electrically Erasable Programmable Read Only Memory
SRAM — Static Random Access Memory
DRAM — Dynamic Random Access Memory

Notice the pattern: each longer name adds one word to the front of the shorter one. Learn PROM first and the other two follow.

बान्की हेर्नुहोस्: हरेक लामो नामले छोटोको अगाडि एउटा शब्द थप्छ। पहिले PROM सिक्नुहोस्, अरू दुई आफैं आउँछन्।

Key points from this unit

  • Memory holds data and instructions. 1 KB = 1024 bytes, and the 1024 is because addresses are binary.
  • The hierarchy is a trade-off: up is faster, smaller, costlier per byte; down is the opposite.
  • Cache exists because the CPU is far faster than RAM.
  • RAM: read/write, volatile — SRAM (cache) and DRAM (main memory, needs refreshing).
  • ROM: read-only in use, non-volatile — PROM (once), EPROM (UV), EEPROM (electrical).
  • Secondary storage is non-volatile and not directly reachable by the CPU: magnetic, optical, flash.
मेमोरीले data र निर्देशन दुवै राख्छ; 1 KB = 1024 byte। तह एउटै सम्झौता हो: माथि छिटो–सानो–महँगो, तल उल्टो। CPU, RAM भन्दा धेरै छिटो भएकाले cache चाहिन्छ। RAM: पढ्न–लेख्न, volatile — SRAM (cache) र DRAM (main, refresh चाहिने)। ROM: पढ्न मात्र, non-volatile — PROM, EPROM (UV), EEPROM (विद्युतीय)। Secondary: non-volatile र CPU ले सिधै नपुग्ने — magnetic, optical, flash।
