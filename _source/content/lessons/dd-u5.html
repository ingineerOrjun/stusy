5.1 & 5.2  What a microprocessor is

Definition — learn this wording

A microprocessor is a single integrated circuit that contains the arithmetic logic unit, the control unit and the registers of a computer — that is, the whole central processing unit on one chip.

It fetches instructions from memory, decodes them and executes them. On its own it does nothing useful: it needs memory and input/output devices around it to become a working system.

Applications: computers and laptops, mobile phones, washing machines, traffic lights, calculators, cars, medical instruments — anything that follows a stored set of instructions.

परिभाषा — यही शब्दमा सम्झनुहोस्

माइक्रोप्रोसेसर भनेको एउटै एकीकृत सर्किट (IC) हो, जसभित्र कम्प्युटरको arithmetic logic unit, control unit र register हुन्छन् — अर्थात् पूरै केन्द्रीय प्रोसेसिङ इकाई एउटै चिपमा।

यसले मेमोरीबाट निर्देशन झिक्छ, बुझ्छ र चलाउँछ। एक्लै यसले केही गर्न सक्दैन: काम गर्ने प्रणाली बन्न वरिपरि मेमोरी र इनपुट/आउटपुट यन्त्र चाहिन्छ।

प्रयोग: कम्प्युटर र ल्यापटप, मोबाइल फोन, वासिङ मेसिन, ट्राफिक बत्ती, क्याल्कुलेटर, कार, चिकित्सा उपकरण — भण्डारण गरिएका निर्देशन पछ्याउने जुनसुकै यन्त्र।

5.3 – 5.6  The blocks of a microprocessor system

What each block does

ALU — performs all arithmetic (add, subtract) and all logic (AND, OR, NOT, compare). It is the only part that calculates.

Control Unit — decodes the instruction and tells every other block what to do and when. It calculates nothing itself; it directs.

Registers — very fast storage inside the CPU. The accumulator (A) holds one operand and receives the result; B, C, D, E, H, L are general purpose; the Program Counter (PC) holds the address of the next instruction; the Instruction Register (IR) holds the instruction being carried out; the Stack Pointer (SP) holds the top of the stack.

Memory — holds the program and the data, one byte per address. Input/output — everything outside: keyboard, display, ports.

हरेक ब्लकको काम

ALU — सबै गणित (जोड, घटाउ) र सबै तर्क (AND, OR, NOT, तुलना) गर्छ। गणना गर्ने एउटै भाग यही हो।

Control Unit — निर्देशन बुझेर अरू हरेक ब्लकलाई कहिले के गर्ने भन्छ। यसले आफैं गणना गर्दैन; निर्देशन दिन्छ।

Registers — CPU भित्रकै अति छिटो भण्डारण। accumulator (A) ले एउटा operand राख्छ र नतिजा पाउँछ; B, C, D, E, H, L सामान्य प्रयोजनका; Program Counter (PC) ले अर्को निर्देशनको ठेगाना राख्छ; Instruction Register (IR) ले चलिरहेको निर्देशन; Stack Pointer (SP) ले stack को टुप्पो।

Memory — प्रोग्राम र डाटा, प्रति ठेगाना एक बाइट। Input/output — बाहिरका सबै यन्त्र।

The three buses in one line each. The address bus says WHERE — 16 bits, one way, CPU to memory. The data bus carries WHAT — 8 bits, both ways. The control bus says WHEN and WHICH WAY — read, write, timing. तीन bus, एक–एक वाक्यमा: address bus ले कहाँ भन्छ — १६ बिट, एकतर्फी; data bus ले के बोक्छ — ८ बिट, दुवैतर्फ; control bus ले कहिले र कुन दिशामा भन्छ।

5.7  The instruction cycle

Why this comes first

The blocks above only make sense once you have watched them work. Every instruction a processor ever runs goes through the same cycle:

FETCH — the PC's address goes onto the address bus, and memory returns the instruction on the data bus into the IR.
DECODE — the control unit works out what the instruction means.
EXECUTE — the ALU or the registers do the work.
STORE — if there is a result to keep, it is written back.

Then the cycle repeats, for as long as the processor is powered.

यो पहिले किन

माथिका ब्लक काम गरेको हेरेपछि मात्र बुझिन्छन्। प्रोसेसरले चलाउने हरेक निर्देशन उही चक्रबाट जान्छ:

FETCH — PC को ठेगाना address bus मा जान्छ, मेमोरीले निर्देशन data bus बाट IR मा फर्काउँछ।
DECODE — control unit ले निर्देशनको अर्थ निकाल्छ।
EXECUTE — ALU वा register ले काम गर्छ।
STORE — राख्नुपर्ने नतिजा भए फेरि लेखिन्छ।

अनि प्रोसेसरमा बिजुली भएसम्म यही चक्र दोहोरिन्छ।

Predict first · पहिले अनुमान गर्नुहोस्

Which register holds the address of the next instruction to be fetched? झिक्नुपर्ने अर्को निर्देशनको ठेगाना कुन रजिस्टरमा हुन्छ?

The PC holds the address of the next instruction; the IR holds the instruction itself once it has arrived. Watch the simulation below — the PC moves on during FETCH, before the instruction has even been decoded.

PC ले अर्को निर्देशनको ठेगाना राख्छ; IR ले आइसकेको निर्देशन आफैं। तलको सिमुलेसनमा हेर्नुहोस् — निर्देशन decode हुनुअघि नै FETCH मा PC अगाडि सर्छ।

Step-by-step simulation · पाइला–पाइला सिमुलेसन

Run three instructions through the 8085

What you will learn: which block is working at each stage, what the buses are carrying, and when the flags change. तपाईंले के सिक्नुहुन्छ: हरेक चरणमा कुन ब्लकले काम गर्छ, bus ले के बोकिरहेको छ, र flag कहिले बदलिन्छ।

What to watch for

The PC moves during FETCH, not at the end. By the time the instruction is being decoded, the processor already knows where the next one lives.

The ALU lights up only during EXECUTE of ADD B. MVI and STA never touch it — moving data is not arithmetic, and this is why the ALU is drawn as one block among several rather than as the whole processor.

The flags change only when the ALU produces a result. After ADD B the answer is 08H: not zero, not negative, no carry out — so all three flags read 0.

PC FETCH मै सर्छ, अन्त्यमा होइन। ALU ADD B को EXECUTE मा मात्र बल्छ — MVI र STA ले छुँदैनन्, किनभने डाटा सार्नु गणित होइन। ALU ले नतिजा दिँदा मात्र flag बदलिन्छन्।

One simplification, so you are not caught out: the first instruction's FETCH is shown as two steps — the address going out, then the instruction coming back — because that is the part worth seeing once. For the second and third instructions both halves are shown as a single FETCH step. Nothing else is compressed.

एउटा सरलीकरण, अन्योल नहोस् भनेर: पहिलो निर्देशनको FETCH लाई दुई चरणमा देखाइएको छ — ठेगाना बाहिर जाने, अनि निर्देशन फर्केर आउने — किनभने एक पटक हेर्न लायक कुरा त्यही हो। दोस्रो र तेस्रो निर्देशनमा दुवै भाग एउटै FETCH चरणमा देखाइएको छ।

5.9  Flags and interrupts

The flag register

A flag is a single bit that records something about the last ALU result. The 8085 has five:

  • S — Sign: 1 if the result is negative.
  • Z — Zero: 1 if the result is exactly zero.
  • CY — Carry: 1 if the result produced a carry out.
  • AC — Auxiliary Carry: a carry from bit 3 to bit 4, used in BCD arithmetic.
  • P — Parity: 1 if the result has an even number of 1s.

Flags exist so the program can make decisions: "jump if zero" reads Z.

Flag रजिस्टर

Flag भनेको एउटा बिट हो, जसले पछिल्लो ALU नतिजाबारे केही कुरा टिपेर राख्छ। 8085 मा पाँच छन्:

  • S — Sign: नतिजा ऋणात्मक भए 1।
  • Z — Zero: नतिजा ठ्याक्कै शून्य भए 1।
  • CY — Carry: क्यारी बाहिर निस्किए 1।
  • AC — Auxiliary Carry: बिट ३ बाट ४ मा गएको क्यारी, BCD गणितमा प्रयोग हुन्छ।
  • P — Parity: नतिजामा 1 को सङ्ख्या जोर भए 1।

Flag हुनुको कारण: प्रोग्रामले निर्णय गर्न सकोस् — "शून्य भए जम्प गर" ले Z पढ्छ।

Interrupts

An interrupt is a signal that asks the processor to stop what it is doing, attend to something urgent, and then return to exactly where it left off.

The 8085 has five: TRAP (highest priority, cannot be disabled), RST 7.5, RST 6.5, RST 5.5 and INTR (lowest priority).

Learn the priority order — it is the part that gets asked.

Interrupt

Interrupt भनेको त्यस्तो सङ्केत हो, जसले प्रोसेसरलाई गरिरहेको काम रोकेर जरुरी कामतिर ध्यान दिन र त्यसपछि ठ्याक्कै जहाँ छाडेको थियो त्यहीँ फर्कन भन्छ।

8085 मा पाँच छन्: TRAP (सर्वोच्च प्राथमिकता, बन्द गर्न मिल्दैन), RST 7.5, RST 6.5, RST 5.5 र INTR (सबैभन्दा कम)।

प्राथमिकताको क्रम सम्झनुहोस् — सोधिने भाग त्यही हो।

5.8  Pin configuration of the 8085

Why AD0–AD7 are shared. A 16-bit address and an 8-bit data value would need 24 pins. The 8085 saves eight of them by sending the lower address byte and the data over the same eight lines at different moments. The ALE pin goes high to say "these lines are carrying an address right now" — that is the whole meaning of the word multiplexed in the phrase "multiplexed address/data bus". AD0–AD7 किन साझा: १६-बिट ठेगाना र ८-बिट डाटालाई २४ pin चाहिन्थ्यो। 8085 ले तल्लो ठेगाना बाइट र डाटा उही आठ लाइनबाट फरक–फरक क्षणमा पठाएर आठ pin बचाउँछ। ALE pin ले "अहिले यी लाइनमा ठेगाना छ" भन्छ — "multiplexed" शब्दको अर्थ यही हो।

5.10  Addressing modes

Example 1 Identify the addressing mode of each instruction
Working
MVI B, 20H → Immediate. 20H is written inside the instruction. LDA 2050H → Direct. the address 2050H is given in full. MOV A, C → Register. both operands are named registers. MOV A, M → Register indirect. M means "the memory location whose address is in the HL pair". CMA → Implicit. the operand (the accumulator) is understood without being written.

The trick for telling direct from register indirect: direct writes the address in the instruction; indirect keeps it in a register pair, so you have to look there first. Direct र register indirect छुट्याउने तरिका: direct ले ठेगाना निर्देशनमै लेख्छ; indirect ले register pair मा राख्छ, त्यसैले पहिले त्यहाँ हेर्नुपर्छ।

Mistakes that cost marks here

  • Saying the PC holds the current instruction. It holds the address of the next one. The IR holds the instruction. PC ले चलिरहेको निर्देशन राख्छ भन्नु। यसले अर्कोको ठेगाना राख्छ; निर्देशन IR मा हुन्छ।
  • Drawing the address bus as two-way. It is one way only — the CPU always chooses the address. Address bus लाई दुईतर्फी कोर्नु। यो एकतर्फी मात्र हो।
  • Confusing the 8-bit data bus with the 16-bit address bus. 8 bits of data make the 8085 an 8-bit processor; 16 address lines give it 64 KB of memory. ८-बिट data bus र १६-बिट address bus मिसाउनु। ८ बिट डाटाले 8085 लाई ८-बिट प्रोसेसर बनाउँछ; १६ ठेगाना लाइनले ६४ KB मेमोरी दिन्छ।
  • Putting TRAP anywhere but first. TRAP has the highest priority and cannot be masked. TRAP लाई पहिलो बाहेक अन्त राख्नु। TRAP कै प्राथमिकता सर्वोच्च हो र यसलाई बन्द गर्न मिल्दैन।

Draw the block diagram of a microprocessor system and explain the function of each block. माइक्रोप्रोसेसर प्रणालीको ब्लक डायग्राम कोर्नुहोस् र हरेक ब्लकको काम व्याख्या गर्नुहोस्।

Draw the CPU as one box containing three blocks — ALU, Control Unit and Registers — with Memory and Input/Output outside it, joined by three buses.

ALU: performs all arithmetic and logical operations.
Control Unit: decodes instructions and directs every other block.
Registers: fast internal storage — accumulator, general purpose registers, PC, IR, SP and the flag register.

Input/Output: connects the system to the outside world.
Buses: address (16-bit, one way), data (8-bit, both ways), control (timing and read/write signals).

4 marks Practice question

Explain the instruction cycle of a microprocessor. माइक्रोप्रोसेसरको निर्देशन चक्र व्याख्या गर्नुहोस्।

Fetch: the Program Counter puts the address of the next instruction on the address bus; memory returns the instruction on the data bus into the Instruction Register, and the PC is incremented.

Decode: the control unit reads the Instruction Register and determines what operation is required and which operands it needs.

Execute: the ALU or the registers carry out the operation, and the flags are updated from the result.

Store: if the instruction produces a result to be kept, it is written back to a register or to memory. The cycle then repeats for the next instruction.

Fetch → Decode → Execute → Store, अनि यही क्रम अर्को निर्देशनका लागि दोहोरिन्छ। हरेक चरणमा कुन भागले काम गर्छ लेख्नुहोस्।
4 marks Practice question

Flag: S, Z, CY, AC, P। Interrupt प्राथमिकताक्रममा: TRAP, RST 7.5, RST 6.5, RST 5.5, INTR। TRAP लाई सफ्टवेयरले बन्द गर्न सक्दैन।

  • A microprocessor is the whole CPU — ALU, control unit and registers — on one chip. माइक्रोप्रोसेसर भनेको पूरै CPU — ALU, control unit र register — एउटै चिपमा।
  • Address bus 16-bit one way; data bus 8-bit both ways; control bus for timing. Address bus १६-बिट एकतर्फी; data bus ८-बिट दुवैतर्फ; control bus समयका लागि।
  • PC holds the address of the next instruction; IR holds the current one. PC ले अर्को निर्देशनको ठेगाना; IR ले चलिरहेको निर्देशन।
  • FETCH → DECODE → EXECUTE → STORE, repeating for every instruction. FETCH → DECODE → EXECUTE → STORE, हरेक निर्देशनका लागि दोहोरिन्छ।
  • Five flags: S, Z, CY, AC, P — all set by the ALU from its last result. पाँच flag: S, Z, CY, AC, P — सबै ALU ले पछिल्लो नतिजाबाट सेट गर्छ।
  • Interrupts by priority: TRAP, RST 7.5, RST 6.5, RST 5.5, INTR. Interrupt प्राथमिकताक्रम: TRAP, RST 7.5, RST 6.5, RST 5.5, INTR।
  • The addressing mode says where the operand is, not what the instruction does. Addressing mode ले operand कहाँ छ भन्छ, निर्देशनले के गर्छ भन्ने होइन।
