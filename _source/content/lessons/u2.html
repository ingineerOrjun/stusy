2.1  What is Object Oriented Programming?

Definition — learn this wording

Object Oriented Programming (OOP) is a programming method that solves a big problem by breaking it into small parts called objects. Each object keeps its own data and the functions that work on that data bound together, so that no other part of the program can access that data directly.

The key phrase examiners look for is "binds together data and the functions that operate on that data".

परिभाषा — यही शब्द कण्ठ पार्नुहोस्

OOP भनेको ठूलो समस्यालाई अब्जेक्ट भनिने साना–साना भागमा बाँडेर समाधान गर्ने प्रोग्रामिङ तरिका हो। हरेक अब्जेक्टले आफ्नो डाटा र त्यही डाटामाथि काम गर्ने फङ्सन लाई सँगै बाँधेर राख्छ, ताकि प्रोग्रामको अरू भागले त्यो डाटा सिधै छुन नसकोस्।

परीक्षकले खोज्ने मुख्य वाक्यांश: "डाटा र त्यसमाथि काम गर्ने फङ्सनलाई सँगै बाँध्छ"।

Why OOP was invented — the problem it solves

Real-world analogy — a TV remote

You press a button and the channel changes. You do not know what circuit is inside, and you cannot reach in and touch it. The remote keeps its parts (the data) hidden and gives you only buttons (the functions).

That is exactly what an object does — and it is why an object is safer than a global variable that any function can change.

उदाहरण — TV को रिमोट। बटन थिच्दा च्यानल फेरिन्छ। भित्रको सर्किट थाहा हुँदैन र छुन पनि पाइँदैन। रिमोटले भित्री भाग (डाटा) लुकाएर बटन (फङ्सन) मात्र दिन्छ। अब्जेक्ट ले पनि ठ्याक्कै यही गर्छ।

2.2  Features of OOP

These are the standard exam-listed features. Learn all seven English names — a question often just says "explain any four features of OOP".

1. Object

A real-world entity that has data (its state) and functions (its behaviour). An object is an instance of a class and it takes memory.

डाटा र व्यवहार भएको वास्तविक वस्तु। क्लासको एउटा instance, जसले मेमोरी लिन्छ।

2. Class

A blueprint or template that describes what data and functions its objects will have. A class takes no memory by itself.

अब्जेक्ट बनाउने नक्सा वा टेम्प्लेट। यसले आफैंले मेमोरी लिँदैन।

3. Encapsulation

Binding data and functions together in one unit and hiding the data from outside access by marking it private.

डाटा र फङ्सनलाई एउटै एकाइमा बाँध्ने र डाटालाई बाहिरबाट लुकाउने।

4. Abstraction

Showing only the necessary features to the user and hiding the internal details of how the work is actually done.

आवश्यक कुरा मात्र देखाउने र भित्री जटिलता लुकाउने।

5. Inheritance

One class acquires the properties and functions of another class, so that code can be reused instead of rewritten.

एउटा क्लासले अर्को क्लासका गुण र फङ्सन प्राप्त गर्ने — कोड पुनः प्रयोग हुन्छ।

6. Polymorphism

One name, many forms. The same function name or operator behaves differently in different situations.

एउटै नाम, धेरै रूप। उही फङ्सनको नामले फरक अवस्थामा फरक काम गर्छ।

7. Message Passing

Objects communicate with each other by calling one another's member functions — this is called sending a message.

अब्जेक्टहरूले एकअर्काको फङ्सन बोलाएर सञ्चार गर्ने।

+ Dynamic Binding

The code that will run for a function call is decided at run time, not while compiling. This is what makes virtual functions work.

कुन कोड चल्ने हो भन्ने कुरा कम्पाइल गर्दा होइन, चल्दै गर्दा निर्णय हुने।

2.4  Structured vs Object-Oriented Programming

This comparison is one of the most frequently asked long questions in the whole subject. Learn at least six rows.

BasisStructured / Procedural (POP)Object-Oriented (OOP)
Basic unitThe function is the basic unit.The object is the basic unit.
ApproachTop-down — the big problem is broken into functions.Bottom-up — objects are built first, then combined.
FocusFocus is on the procedure — how to do it.Focus is on the data and the object.
Data securityData is mostly global, so any function can change it — less secure.Data is private and hidden inside the object — more secure.

छोटो सार

POP मा फङ्सन मुख्य हुन्छ, डाटा प्रायः global हुने भएकाले कम सुरक्षित हुन्छ, र यसले माथिबाट तल (top-down) सोच्छ। OOP मा अब्जेक्ट मुख्य हुन्छ, डाटा private राखेर लुकाइन्छ, र तलबाट माथि (bottom-up) सोच्छ। ठूलो प्रोग्रामका लागि OOP राम्रो।

Predict first · पहिले अनुमान गर्नुहोस्

A driver uses a steering wheel without knowing how the engine works. Which feature of OOP does that describe? चालकले इन्जिन कसरी चल्छ नजानीकनै स्टेयरिङ चलाउँछन्। यसले OOP को कुन विशेषता जनाउँछ?

Abstraction. Complexity is hidden and only what you need is shown. The test that separates the two: abstraction hides COMPLEXITY, encapsulation hides DATA. A private variable with a getter is encapsulation; a dashboard that shows speed without the mechanism is abstraction. Unit 4 spends a whole section on this pair — it is asked most years.

Abstraction। जटिलता लुकाइएको छ र चाहिने कुरा मात्र देखाइएको छ। छुट्याउने जाँच: abstraction ले जटिलता लुकाउँछ, encapsulation ले डाटा। Getter सहितको private चल encapsulation हो; संयन्त्र नदेखाई गति देखाउने ड्यासबोर्ड abstraction हो।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Name the feature from what the program does

What you will learn: to name an OOP feature from a described situation, which is how this unit is actually examined — not by reciting the list. तपाईंले के सिक्नुहुन्छ: वर्णन गरिएको परिस्थितिबाट OOP विशेषताको नाम दिन — यो युनिट यसरी नै जाँचिन्छ, सूची घोकेर होइन।

How to use this

For each case ask one question before you answer: what is being hidden? Data hidden behind functions is encapsulation. Complexity hidden behind a simple interface is abstraction. A class taking members from another is inheritance. One name behaving in more than one form is polymorphism.

Two cases are both polymorphism — one decided by the compiler, one decided while the program runs. Read the reasons: the exam asks you to name which kind.

उत्तर दिनुअघि एउटै प्रश्न सोध्नुहोस्: के लुकाइँदै छ? फङ्सनपछाडि लुकेको डाटा = encapsulation। सरल अन्तरमुखपछाडि लुकेको जटिलता = abstraction। अर्कोका मेम्बर लिने क्लास = inheritance। एउटै नाम धेरै रूपमा = polymorphism। दुई केस polymorphism कै हुन् — एउटा compiler ले, अर्को चल्दै गर्दा तय हुन्छ।

2.5  Tokens and Character Set

Token

A token is the smallest individual unit of a C++ program that has meaning to the compiler. When the compiler reads your program it first breaks it into tokens.

The character set is every character C++ understands: letters A–Z and a–z, digits 0–9, special symbols such as + - * / = < > ( ) { } ; ,, and white space (space, tab, newline).

टोकन

टोकन भनेको C++ प्रोग्रामको सबैभन्दा सानो अर्थपूर्ण एकाइ हो, जुन कम्पाइलरले बुझ्छ। कम्पाइलरले प्रोग्राम पढ्दा पहिले यसलाई टोकनमा टुक्र्याउँछ।

Character set भनेको C++ ले बुझ्ने सबै अक्षर हो: A–Z, a–z, ०–९, विशेष चिन्ह + - * / = ( ) { } ;, र खाली ठाउँ।

This single line contains eight tokens: int (keyword), sum (identifier), = (operator), a (identifier), + (operator), 25 (constant), ; (punctuator). Questions like "identify the tokens in the given statement" are common — count carefully. यो एउटै लाइनमा आठ टोकन छन्। "दिइएको कथनमा token पहिचान गर्नुहोस्" भन्ने प्रश्न बारम्बार आउँछ — ध्यान दिएर गन्नुहोस्।

2.7  Basic Input and Output

cout and cin

cout << sends data out to the screen. << is called the insertion operator.

cin >> takes data in from the keyboard. >> is called the extraction operator.

Both are objects defined in the header file <iostream> and both live inside the namespace std. endl moves the cursor to a new line.

Memory trick: the arrows point in the direction the data travels. cout << x — data flows out of x into cout. cin >> x — data flows from cin into x.

cout र cin

cout << ले डाटा स्क्रिनमा बाहिर पठाउँछ। << लाई insertion operator भनिन्छ।

cin >> ले किबोर्डबाट डाटा भित्र लिन्छ। >> लाई extraction operator भनिन्छ।

दुवै <iostream> हेडर फाइलमा भएका अब्जेक्ट हुन् र std नेमस्पेस भित्र बस्छन्। endl ले नयाँ लाइनमा लैजान्छ।

सम्झने तरिका: तीर जता फर्किएको छ, डाटा त्यतै जान्छ।

2.8  Basic Program Structure

Example 2 A complete program that reads input
#include <iostream>
using namespace std;

int main() {
    int a, b, sum;

    cout << "Enter two numbers: ";
    cin >> a >> b;              // read both values

    sum = a + b;
    cout << "Sum = " << sum << endl;
    return 0;
}
Output (if the user types 12 and 8) 
Enter two numbers: 12 8
Sum = 20
Common mistakes in program structure
  • Forgetting using namespace std; — then cout is undefined and you must write std::cout.
  • Writing cin << a; instead of cin >> a; — the arrows are the wrong way round.
  • Missing the semicolon ; at the end of a statement.
  • Writing Main() or MAIN() — C++ is case sensitive, it must be main().
यी चार गल्ती सबैभन्दा बढी हुन्छन्: namespace बिर्सने, cin मा तीर उल्टो लेख्ने, सेमीकोलन छुटाउने, र main लाई ठूलो अक्षरमा लेख्ने। C++ मा सानो–ठूलो अक्षरले फरक पार्छ।

Example 3 if…else ladder — printing a grade
#include <iostream>
using namespace std;

int main() {
    int marks = 78;

    if (marks >= 90)
        cout << "Grade A+";
    else if (marks >= 75)
        cout << "Grade A";
    else if (marks >= 60)
        cout << "Grade B";
    else
        cout << "Grade C";

    return 0;
}
Output 
Grade A

The ladder is checked from the top. 78 fails the first test (78 >= 90 is false) but passes the second (78 >= 75 is true), so it prints Grade A and stops — the remaining conditions are never checked. माथिबाट क्रमशः जाँचिन्छ। ७८ पहिलो सर्तमा असफल भयो तर दोस्रोमा सफल भयो, त्यसैले "Grade A" छापेर रोकियो — बाँकी सर्त जाँचिँदैनन्।

Example 4 while vs do…while — the difference that gets tested
int i = 10;
while (i < 5) {          // condition is FALSE at the start
    cout << "while runs";
}                        // body runs ZERO times

int j = 10;
do {
    cout << "do-while runs";   // body runs ONCE first
} while (j < 5);               // then the condition fails
Output 
do-while runs

Same condition, same starting value — but while printed nothing and do…while printed once. That is the whole difference: while checks first, do…while acts first. उही सर्त, उही सुरुको मान — तर while ले केही छापेन र do…while ले एक पटक छाप्यो। फरक यही हो: while ले पहिले जाँच्छ, do…while ले पहिले काम गर्छ।

Structured vs object-oriented programming, and the features of OOP, are the two most repeated questions from this unit.

Q1 · Define OOP. Explain any four features of OOP. [6 marks]

OOP is a programming method that solves a big problem by breaking it into small parts called objects, binding together the data and the functions that operate on that data so that no other part of the code can access the data directly.

Any four of: Object — a real-world entity with data and behaviour; Class — a blueprint from which objects are created; Encapsulation — binding data and functions in one unit and hiding the data; Abstraction — showing only essential features and hiding internal details; Inheritance — one class acquiring the properties of another; Polymorphism — one name behaving in many forms.

परिभाषा + कुनै चार विशेषताको एक–एक लाइन व्याख्या लेख्नुहोस्।
Q2 · Differentiate between procedural and object-oriented programming. [5 marks]

Write it as a table with at least five rows: basic unit (function vs object), approach (top-down vs bottom-up), focus (procedure vs data), data security (global and less secure vs private and more secure), reusability (difficult vs easy through inheritance), and examples (C vs C++).

तालिकाको रूपमा कम्तीमा पाँच हरफ लेख्नुहोस् — तालिकाले पूरा अंक ल्याउँछ।
Q3 · What is a token? Name the six types of tokens in C++ with one example each. [4 marks]

A token is the smallest individual unit of a C++ program that has meaning to the compiler.

The six types are: keywords (int), identifiers (sum), constants (25), operators (+), punctuators (;) and strings ("Ram").

परिभाषा + छवटै प्रकार + एक–एक उदाहरण दिनुहोस्।
Q4 · Differentiate between while and do…while loops. [3 marks]

while is entry controlled — the condition is tested before the body runs, so the body may run zero times. do…while is exit controlled — the body runs first and the condition is tested afterwards, so the body always runs at least once. Also, do…while ends with a semicolon after the condition.

entry vs exit controlled, ० पटक vs कम्तीमा एक पटक, र अन्त्यको सेमीकोलन — यी तीन बुँदा लेखे पुग्छ।

Key points to revise — दोहोर्‍याउनुपर्ने मुख्य बुँदा

  • OOP definition must contain the phrase "binds data and functions together".
  • Seven features: object, class, encapsulation, abstraction, inheritance, polymorphism, message passing.
  • POP = function-based, global data, top-down. OOP = object-based, private data, bottom-up.
  • Six tokens: keyword, identifier, constant, operator, punctuator, string.
  • cout << is insertion (out); cin >> is extraction (in). Both are in <iostream>.
  • Program structure: header → namespace → main() → statements → return 0.
  • while = entry controlled (may run 0 times); do…while = exit controlled (runs at least once).
  • C++ is case sensitive, and every statement ends with a semicolon.
