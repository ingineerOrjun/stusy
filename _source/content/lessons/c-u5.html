5.1  What arrays and strings are — Array र string भनेको के हुन्

One name, many boxes

An array is a collection of elements of the same data type, stored in continuous memory locations, under one name, reached by an index.

Each of those four parts earns its place. Same type, so the compiler knows how far apart the boxes are. Continuous, so the address of element i can be worked out by arithmetic rather than looked up. One name, so fifty marks need one declaration. An index, so a loop can reach every element — which is the whole reason arrays exist.

Without an array, storing fifty students' marks needs fifty variables, fifty scanf lines, and no way to write "add them all up" in fewer than fifty additions. With one, it is a loop of three lines.

A string in C is not a separate type. It is an array of char that ends with the null character \0. Everything true of arrays is true of strings, plus that one extra rule.

एउटै नाम, धेरै बाकस

Array भनेको एउटै data type का element को समूह हो, जुन लगातार मेमोरी स्थान मा, एउटै नाम मुनि राखिन्छ र index ले पुगिन्छ।

यी चारै भागको आफ्नै काम छ। एउटै प्रकार, ताकि बाकसहरू कति टाढा छन् compiler लाई थाहा होस्। लगातार, ताकि i औं element को ठेगाना खोज्नु नपरी गणनाले निस्कियोस्। एउटै नाम, ताकि पचास अंकलाई एउटै घोषणा पुगोस्। Index, ताकि loop ले हरेक element मा पुग्न सकोस् — array हुनुको पूरै कारण त्यही हो।

Array नभए पचास विद्यार्थीको अंक राख्न पचास variable, पचास scanf लाइन, र "सबै जोड्नुहोस्" भन्ने कुरा पचास जोडभन्दा कममा लेख्ने उपाय नै हुँदैन। Array भए तीन लाइनको loop पुग्छ।

C मा string छुट्टै प्रकार होइन। यो char को array हो, जुन null अक्षर \0 ले सकिन्छ। Array का सबै कुरा string मा पनि लागू हुन्छन्, माथि यो एउटा थप नियम।

5.2  Declaration and initialisation of an array — Array को घोषणा र initialisation

Four ways to start one

Declaration — int marks[5]; reserves five integer boxes. The number in the brackets is the size, and in standard C before C99 it has to be a constant: int a[n]; with a variable n is not something to rely on in an examination answer.

Initialisation — four forms, all legal:

  • int marks[5] = {70, 85, 60, 90, 45}; — size and values both given.
  • int marks[] = {70, 85, 60, 90, 45}; — the compiler counts five for you.
  • int marks[5] = {70, 85}; — the rest become zero, not garbage.
  • int marks[5] = {0}; — a common idiom for "all zero".

Indexing starts at 0. An array of size 5 has indices 0, 1, 2, 3, 4, so the last index is size − 1. There is no marks[5], and C will not stop you from writing one — it has no bounds checking at all. Reading past the end gives whatever happens to be in that memory; writing past the end damages something else.

सुरु गर्ने चार तरिका

घोषणा — int marks[5]; ले पाँच integer बाकस छुट्याउँछ। कोष्ठकभित्रको सङ्ख्या आकार हो, र C99 भन्दा अघिको मानक C मा यो constant नै हुनुपर्छ: variable n सहितको int a[n]; परीक्षाको उत्तरमा भर पर्ने कुरा होइन।

Initialisation — चार रूप, सबै मान्य:

  • int marks[5] = {70, 85, 60, 90, 45}; — आकार र मान दुवै दिइएको।
  • int marks[] = {70, 85, 60, 90, 45}; — compiler ले आफैं पाँच गन्छ।
  • int marks[5] = {70, 85}; — बाँकी शून्य हुन्छन्, garbage होइन।
  • int marks[5] = {0}; — "सबै शून्य" भन्ने चलनचल्तीको तरिका।

Index ० बाट सुरु हुन्छ। पाँच आकारको array का index ०, १, २, ३, ४ हुन्छन्, त्यसैले अन्तिम index आकार − १ हो। marks[5] भन्ने छैन, र C ले तपाईंलाई त्यो लेख्नबाट रोक्दैन — यसमा bound जाँच्ने व्यवस्थै छैन। अन्त्यभन्दा पर पढ्दा त्यो मेमोरीमा जे छ त्यही आउँछ; पर लेख्दा अरू केही बिग्रन्छ।

5.3  One-dimensional arrays in use — एक-आयामिक array को प्रयोग

An array and a loop are one idea

The index in marks[i] is a variable, and that is the hinge of the whole unit: one line of code inside a loop reaches a different element each turn.

The three things always written together:

  • Reading — for (i = 0; i < 5; i++) scanf("%d", &marks[i]); Note &marks[i]: one element is an ordinary int, so scanf still needs its address.
  • Printing — the same loop with printf("%d ", marks[i]);
  • Totalling — total = total + marks[i]; with total set to 0 before the loop.

The condition is i < 5 and not i <= 5. Both compile. One of them reads a box that is not part of the array, and nothing warns you — this is the off-by-one error, and it is the most common bug in this unit by a wide margin.

Array र loop एउटै विचार हुन्

marks[i] को index variable हो, र पूरै युनिटको कब्जा त्यही हो: loop भित्रको एउटै लाइनले हरेक पटक फरक element मा पुग्छ।

सधैं सँगै लेखिने तीन कुरा:

  • पढ्ने — for (i = 0; i < 5; i++) scanf("%d", &marks[i]); &marks[i] हेर्नुहोस्: एउटा element सामान्य int हो, त्यसैले scanf लाई यसको ठेगाना चाहिन्छ।
  • छाप्ने — उही loop, printf("%d ", marks[i]); सहित।
  • जोड्ने — loop अघि total लाई ० राखेर total = total + marks[i];

सर्त i <= 5 होइन i < 5 हो। दुवै compile हुन्छन्। एउटाले array को भाग नभएको बाकस पढ्छ, र कसैले चेतावनी दिँदैन — यही off-by-one त्रुटि हो, र यस युनिटको सबैभन्दा धेरै हुने गल्ती निकै फरकसहित यही हो।

Step through it · चरणबद्ध हेर्नुहोस्

An array, an index, and a running total

What you will learn: which element marks[i] is on each turn, and what happens at the end when i reaches 5. The last two steps are the ones worth the attention — they are the off-by-one error, shown rather than described. तपाईंले के सिक्नुहुन्छ: हरेक पटक marks[i] कुन element हो, र अन्त्यमा i ५ पुग्दा के हुन्छ। अन्तिम दुई चरण नै ध्यान दिनुपर्ने ठाउँ हुन् — off-by-one त्रुटि वर्णन होइन, देखाइएको छ।

How to use this

Keep asking "which box is this?" rather than "what number is this?". The index row and the element row are deliberately separate, because confusing them is the error.

"यो कुन बाकस हो?" सोध्नुहोस्, "यो कुन सङ्ख्या हो?" होइन। Index को पङ्क्ति र element को पङ्क्ति जानीजानी छुट्याइएका छन्, किनभने तिनलाई मिसाउनु नै गल्ती हो।

Predict first · पहिले अनुमान गर्नुहोस्

A program declares int a[5]; and then writes to a[5]. What does the compiler do? प्रोग्रामले int a[5]; घोषणा गरेर a[5] मा लेख्छ। Compiler ले के गर्छ?

It compiles. C performs no bounds checking — not at compile time and not at run time. a[5] is simply "the memory five boxes past the start of a", and the compiler works out that address and uses it.

What is at that address is whatever came next in memory: another variable, part of the function's bookkeeping, or nothing in particular. The program may print a strange number, may quietly corrupt a different variable, or may crash — and it may do a different one of those on each run.

This is the price C pays for speed: no check means no cost, and the responsibility moves to you. It is also why i < size rather than i <= size is worth checking every single time you write a loop over an array.

Compile हुन्छ। C ले bound जाँच्दैन — न compile गर्दा, न चल्दा। a[5] भनेको "a को सुरुदेखि पाँच बाकस पर भएको मेमोरी" मात्र हो, र compiler ले त्यही ठेगाना निकालेर चलाउँछ। त्यहाँ के छ भन्ने मेमोरीमा पछि जे आयो त्यही हो: अर्को variable, function को आफ्नै हिसाब, वा केही पनि होइन। प्रोग्रामले अनौठो सङ्ख्या छाप्न सक्छ, अर्कै variable चुपचाप बिगार्न सक्छ, वा crash हुन सक्छ — र हरेक पटक फरक नतिजा दिन सक्छ। गतिका लागि C ले तिरेको मूल्य यही हो: जाँच छैन भने लागत पनि छैन, र जिम्मेवारी तपाईंमा सर्छ। Array मा loop लेख्दा हरेक पटक i <= size होइन i < size हो कि भनेर जाँच्नुपर्ने कारण पनि त्यही।

5.4  Declaration of a string — String को घोषणा

A char array with one hidden rule

Three ways to declare one, and they are not all the same:

  • char name[10] = "NEPAL"; — the compiler stores N, E, P, A, L and then \0, and leaves four boxes unused.
  • char name[] = "NEPAL"; — the compiler counts six, not five, because it has to make room for the null.
  • char name[6] = {'N','E','P','A','L','\0'}; — the long way, and the one that shows what the other two are doing.

The null character is the string's end marker. Nothing in C records a string's length anywhere; every function that handles one walks forward until it meets \0. That is why char name[5] = "NEPAL"; is a real bug: there is no room for the terminator, so nothing marks the end, and printf carries on printing whatever is next in memory until it happens to meet a zero byte.

Reading one with scanf("%s", name) takes no ampersand, because an array name is already an address. It also stops at the first space, so "Ram Bahadur" arrives as "Ram".

एउटा लुकेको नियम भएको char array

घोषणा गर्ने तीन तरिका, र तीनै उस्तै होइनन्:

  • char name[10] = "NEPAL"; — compiler ले N, E, P, A, L अनि \0 राख्छ, र चार बाकस खाली छाड्छ।
  • char name[] = "NEPAL"; — compiler ले पाँच होइन छ गन्छ, किनभने null का लागि ठाउँ चाहिन्छ।
  • char name[6] = {'N','E','P','A','L','\0'}; — लामो तरिका, र अरू दुईले के गरिरहेका छन् देखाउने तरिका पनि।

Null अक्षर नै string को अन्त्यको चिन्ह हो। C मा string को लम्बाइ कतै लेखिँदैन; string चलाउने हरेक function \0 नभेटेसम्म अगाडि बढ्छ। त्यसैले char name[5] = "NEPAL"; साँच्चैको bug हो: terminator का लागि ठाउँ छैन, अन्त्य केहीले जनाउँदैन, र printf ले मेमोरीमा पछि जे छ त्यही छाप्दै जान्छ — कतै शून्य byte नभेटेसम्म।

scanf("%s", name) ले पढ्दा ampersand चाहिँदैन, किनभने array को नाम आफैं ठेगाना हो। यसले पहिलो खाली ठाउँमै रोकिन्छ, त्यसैले "Ram Bahadur" लेख्दा "Ram" मात्र आउँछ।

Step through it · चरणबद्ध हेर्नुहोस्

Where the sixth character came from

What you will learn: that storing a five-letter word writes six characters, that strlen reports five, and that the two numbers are both right. Watch the name[5] row appear without any line having put something there. तपाईंले के सिक्नुहुन्छ: पाँच अक्षरको शब्द राख्दा छ अक्षर लेखिन्छ, strlen ले पाँच भन्छ, र दुवै सङ्ख्या ठिक छन्। कुनै लाइनले केही नराखी name[5] को पङ्क्ति देखिएको हेर्नुहोस्।

How to use this

Before the strlen step, predict the number. Then ask why it is not six, and why the array was declared as ten.

strlen को चरणअघि सङ्ख्या अनुमान गर्नुहोस्। अनि सोध्नुहोस् — यो छ किन भएन, र array दस किन घोषणा गरियो?

5.5  String functions — String function

Seven in the syllabus, four of them standard

All of them need #include <string.h>.

  • strlen(s) — returns the number of characters before the null. strlen("NEPAL") is 5.
  • strcpy(dest, src) — copies src into dest, null included. Needed because dest = src does not work on arrays.
  • strcat(dest, src) — joins src onto the end of dest. dest must be large enough for both.
  • strcmp(s1, s2) — compares them and returns 0 when they are equal, a negative number if s1 comes first alphabetically, a positive number if it comes after. Zero meaning equal is the opposite of what everyone expects.

The other three — strrev, strlwr, strupr — reverse a string, lower-case it and upper-case it. Learn them: they are on the syllabus and they are examined.

पाठ्यक्रममा सात, तीमध्ये चार मानक

सबैलाई #include <string.h> चाहिन्छ।

  • strlen(s) — null भन्दा अघिका अक्षरको सङ्ख्या फर्काउँछ। strlen("NEPAL") को ५।
  • strcpy(dest, src) — src लाई null सहित dest मा सार्छ। चाहिनुको कारण — array मा dest = src चल्दैन।
  • strcat(dest, src) — src लाई dest को अन्त्यमा जोड्छ। dest दुवै अट्ने ठूलो हुनुपर्छ।
  • strcmp(s1, s2) — तुलना गरेर बराबर भए ० फर्काउँछ, s1 वर्णक्रममा पहिले भए ऋणात्मक, पछि भए धनात्मक। शून्यको अर्थ बराबर हुनु सबैको अपेक्षाविपरीत छ।

अरू तीन — strrev, strlwr, strupr — ले string उल्टाउँछ, सानो अक्षर बनाउँछ र ठूलो अक्षर बनाउँछ। सिक्नुहोस्: यी पाठ्यक्रममा छन् र सोधिन्छन्।

strrev, strlwr and strupr are not standard C. They exist in Turbo C and in some Microsoft compilers and are absent from the C standard library, so a program using them compiles on DEV C++ on a Windows machine and fails on a Linux one with "undefined reference". They are on the syllabus and they are examinable, so write them in an examination answer; but if you are writing a program that has to run anywhere, reverse a string with a loop and swap case with a loop. Knowing which of the seven your program can rely on is worth more than knowing all seven. strrev, strlwr र strupr मानक C मा छैनन्। यी Turbo C र केही Microsoft compiler मा छन् तर C मानक library मा छैनन्, त्यसैले यी चलाएको प्रोग्राम Windows को DEV C++ मा compile भएर Linux मा "undefined reference" भन्दै असफल हुन्छ। यी पाठ्यक्रममा छन् र सोधिन्छन्, त्यसैले परीक्षाको उत्तरमा लेख्नुहोस्; तर जहाँ पनि चल्नुपर्ने प्रोग्राम लेख्दै हुनुहुन्छ भने string loop ले उल्टाउनुहोस् र अक्षरको case loop ले बदल्नुहोस्। सातै जान्नुभन्दा आफ्नो प्रोग्रामले कुनमा भर पर्न सक्छ भन्ने जान्नु बढी काम लाग्छ।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Which string function does this job?

What you will learn: to pick the function from what has to come back — a number, a changed string, or a comparison result. That is how the one-mark questions on this topic are framed. तपाईंले के सिक्नुहुन्छ: के फर्कनुपर्छ हेरेर function छान्न — सङ्ख्या, बदलिएको string, कि तुलनाको नतिजा। यस विषयका एक अंकका प्रश्न यसरी नै सोधिन्छन्।

How to use this

Watch for the strcmp case. It returns 0 for a match, so the condition that means "the passwords are the same" is == 0, which reads backwards and is right.

strcmp को केस ध्यान दिनुहोस्। मिल्दा ० फर्काउने भएकाले "password मिल्यो" भन्ने सर्त == 0 हुन्छ — उल्टो पढिन्छ, र ठिक छ।
Example 1 Reading five marks and finding the largest

Question: write a program that reads five marks into an array and prints the largest one.

Decide what the "largest so far" variable should start at. Zero is the obvious choice and it is wrong for one kind of input — work out which. "अहिलेसम्मको ठूलो" variable कहाँबाट सुरु गर्ने निर्णय गर्नुहोस्। शून्य स्वाभाविक लाग्छ तर एक किसिमको input मा गलत हुन्छ — कुनमा, पत्ता लगाउनुहोस्।

Working 
#include <stdio.h>

int main()
{
    int marks[5], i, max;

    printf("Enter five marks: ");
    for (i = 0; i < 5; i++)
        scanf("%d", &marks[i]);      /* & needed: one element is an int */

    max = marks[0];                  /* start from a REAL element       */

    for (i = 1; i < 5; i++)          /* start at 1: 0 is already in max */
    {
        if (marks[i] > max)
            max = marks[i];
    }

    printf("Largest = %d", max);
    return 0;
}
Output (if the user types 70 85 60 90 45) 
Enter five marks: 70 85 60 90 45
Largest = 90

Starting max at marks[0] rather than at 0 is the detail worth the mark. If every value entered were negative — a temperature program, a profit-and-loss program — then max = 0 would report 0, a number that was never entered. Starting from a real element cannot be wrong whatever the data is. Note too that the second loop starts at 1, because element 0 is already the answer so far. अंक बोक्ने कुरा max लाई ० होइन marks[0] बाट सुरु गर्नु हो। सबै मान ऋणात्मक भए — तापक्रमको वा नाफा–नोक्सानको प्रोग्राममा — max = 0 ले कहिल्यै नहालिएको ० लाई उत्तर भन्थ्यो। साँच्चैको element बाट सुरु गरे data जस्तोसुकै भए पनि गलत हुँदैन। अर्को कुरा — दोस्रो loop १ बाट सुरु हुन्छ, किनभने element ० अहिलेसम्मको उत्तर भइसक्यो।

Example 2 Sorting a list into ascending order

Question: sort five numbers using two nested loops, and say what the outer loop is counting.

Work out how many comparisons are needed for five numbers before opening this. If your answer is five, trace the first pass on paper instead. खोल्नुअघि पाँच सङ्ख्याका लागि कति तुलना चाहिन्छ निकाल्नुहोस्। उत्तर पाँच आयो भने बरु कागजमा पहिलो पटक ट्रेस गर्नुहोस्।

Working 
#include <stdio.h>

int main()
{
    int a[5] = {40, 10, 50, 20, 30};
    int i, j, t;

    for (i = 0; i < 4; i++)              /* 4 passes over the list   */
    {
        for (j = 0; j < 4 - i; j++)      /* each pass is one shorter */
        {
            if (a[j] > a[j + 1])         /* neighbours out of order? */
            {
                t = a[j];                /* the three-line swap      */
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }

    for (i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}
The list after each pass of the outer loop
start 40 10 50 20 30 pass 1 10 40 20 30 50 50 has travelled to the end pass 2 10 20 30 40 50 40 is now in place pass 3 10 20 30 40 50 nothing left to move pass 4 10 20 30 40 50
Output 
10 20 30 40 50

The outer loop counts passes, not elements: five numbers need four passes, because once four are in place the fifth has nowhere else to be. The inner condition is j < 4 - i rather than j < 4 because the end of the list is already sorted after each pass and comparing it again wastes time. And a[j + 1] is why the inner loop must stop at 4 - i and not 5 - i: at j = 4 it would reach a[5], which is outside the array. बाहिरी loop ले element होइन पटक गन्छ: पाँच सङ्ख्यालाई चार पटक चाहिन्छ, किनभने चार ठाउँमा पुगेपछि पाँचौंको अर्को ठाउँ नै हुँदैन। भित्री सर्त j < 4 होइन j < 4 - i हुनुको कारण हरेक पटकपछि सूचीको अन्त्य मिलिसकेको हुन्छ र फेरि तुलना गर्नु समय खेर फाल्नु हो। अनि a[j + 1] नै भित्री loop 5 - i होइन 4 - i मा रोकिनुपर्ने कारण हो: j = 4 मा यो a[5] सम्म पुग्थ्यो, जुन array बाहिर छ।

Practise it — the help comes away · अभ्यास गर्नुहोस् — सहयोग घट्दै जान्छ

Mistakes that cost marks here

  • Starting the index at 1. The first element is a[0] and the last is a[size - 1].
  • Writing i <= size in the loop. It reads one box past the end, and nothing warns you.
  • Declaring char name[5] for a five-letter word. The null needs a sixth box.
  • Using == to compare two strings. It compares addresses, not text. Use strcmp, and remember it returns 0 for equal.
  • Using = to copy a string. Arrays cannot be assigned; use strcpy.
  • Writing &name in scanf("%s", name). The array name is already an address.
  • Calling strrev and expecting it everywhere. It is not standard C.
Index १ बाट सुरु गर्नु: पहिलो element a[0], अन्तिम a[size - 1]। Loop मा i <= size लेख्नु: अन्त्यभन्दा एक बाकस पर पढिन्छ र चेतावनी आउँदैन। पाँच अक्षरका लागि char name[5]: null लाई छैटौं बाकस चाहिन्छ। दुई string तुलना गर्न ==: यसले ठेगाना तुलना गर्छ, पाठ होइन; strcmp चलाउनुहोस् र बराबर भए ० फर्काउँछ सम्झनुहोस्। String सार्न =: array मा assignment चल्दैन; strcpy चलाउनुहोस्। scanf("%s", name) मा &name लेख्नु: array को नाम आफैं ठेगाना हो। strrev जताततै चल्छ भन्ठान्नु: यो मानक C मा छैन।

Memory hook — Index from zero, last is size minus one; a string is one box longer than it looks. सम्झने तरिका — Index शून्यबाट, अन्तिम आकार घटाउ एक; string देखिनेभन्दा एक बाकस लामो।

2 marks Practice question

What is an array? Write the syntax for declaring a one-dimensional array with an example. Array भनेको के हो? एक-आयामिक array घोषणा गर्ने syntax उदाहरणसहित लेख्नुहोस्।

An array is a collection of elements of the same data type stored in continuous memory locations under a single name, where each element is reached by an index starting from 0.

Syntax: data_type array_name[size];

Example: int marks[5]; declares an array of five integers with indices marks[0] to marks[4].

Array भनेको एउटै data type का element लाई एउटै नाममुनि लगातार मेमोरी स्थानमा राखेको समूह हो, जहाँ हरेक element ० बाट सुरु हुने index ले पुगिन्छ। Syntax: data_type array_name[size]; उदाहरण: int marks[5]; ले पाँच integer को array घोषणा गर्छ, जसका index marks[0] देखि marks[4] सम्म हुन्छन्।
2 marks Practice question

What is the null character? Why is char name[5] = "NEPAL"; a mistake? Null अक्षर भनेको के हो? char name[5] = "NEPAL"; किन गल्ती हो?

The null character \0 is a character with the value zero that is stored automatically at the end of every string in C. It marks where the string stops; no length is recorded anywhere else, so every string function walks forward until it finds this character.

char name[5] = "NEPAL"; is a mistake because NEPAL is five characters and needs a sixth position for the null. With only five boxes there is no terminator, so nothing marks the end of the string, and functions such as printf and strlen read past the array into whatever memory follows. Compiled and run to check this: sizeof(name) gave 5 as it must, and strlen(name) gave 10 — it had walked five characters past the end of the array before it happened to meet a zero byte.

Null अक्षर \0 शून्य मान भएको अक्षर हो, जुन C मा हरेक string को अन्त्यमा आफैं राखिन्छ। यसले string कहाँ सकिन्छ जनाउँछ; लम्बाइ अन्त कतै लेखिँदैन, त्यसैले हरेक string function यही अक्षर नभेटेसम्म अगाडि बढ्छ। char name[5] = "NEPAL"; गल्ती हो किनभने NEPAL पाँच अक्षर हो र null का लागि छैटौं ठाउँ चाहिन्छ। पाँच बाकस मात्र भए terminator नै हुँदैन, string को अन्त्य केहीले जनाउँदैन, र printf अनि strlen जस्ता function array नाघेर पछाडिको मेमोरी पढ्छन्। यो जाँच्न compile गरेर चलाइयो: sizeof(name) ले हुनुपर्ने ५ दियो, र strlen(name) ले १० — array को अन्त्यभन्दा पाँच अक्षर पर पुगेपछि संयोगले शून्य byte भेटेको थियो।
4 marks Practice question

Write a C program to read ten numbers into an array and print their sum and average. दस सङ्ख्या array मा पढेर तिनको जोड र औसत छाप्ने C प्रोग्राम लेख्नुहोस्।

#include <stdio.h>

int main()
{
    int a[10], i, sum = 0;
    float avg;

    printf("Enter ten numbers: ");
    for (i = 0; i < 10; i++)
        scanf("%d", &a[i]);

    for (i = 0; i < 10; i++)
        sum = sum + a[i];

    avg = sum / 10.0;              /* 10.0, not 10 — see the note */

    printf("Sum = %d\n", sum);
    printf("Average = %.2f\n", avg);
    return 0;
}

Two details carry marks beyond the loop itself. sum is set to 0 before any addition. And the average is divided by 10.0 and not 10: two integers would give integer division and an average of 85.7 would print as 85.00, which is the Unit 2 trap arriving in a Unit 5 program.

Loop बाहेक दुई कुराले अंक बोक्छन्। कुनै जोड हुनुअघि sum लाई ० राखिएको छ। अनि औसत 10 होइन 10.0 ले भाग गरिएको छ: दुई integer भए integer division हुन्थ्यो र ८५.७ को औसत ८५.०० छापिन्थ्यो — युनिट २ को पासो युनिट ५ को प्रोग्राममा आइपुगेको।

Key points from this unit

  • An array holds elements of one type in continuous memory under one name, reached by an index.
  • Indexing starts at 0; the last index is size − 1; C checks no bounds at all.
  • int a[5] = {70, 85}; fills the remaining three with zero.
  • A string is a char array ending in \0, so it needs one box more than its letters.
  • scanf("%s", name) takes no ampersand and stops at the first space.
  • strlen counts before the null; strcpy copies; strcat joins; strcmp returns 0 when equal.
  • All string functions need string.h.
  • strrev, strlwr and strupr are on the syllabus and are not standard C.
Array ले एउटै प्रकारका element लाई एउटै नाममुनि लगातार मेमोरीमा राख्छ र index ले पुगिन्छ। Index ० बाट सुरु; अन्तिम index आकार − १; C ले bound जाँच्दै जाँच्दैन। int a[5] = {70, 85}; ले बाँकी तीनलाई शून्य बनाउँछ। String भनेको \0 ले सकिने char array हो, त्यसैले अक्षरभन्दा एक बाकस बढी चाहिन्छ। scanf("%s", name) लाई ampersand चाहिँदैन र पहिलो खाली ठाउँमा रोकिन्छ। strlen ले null अघिका गन्छ; strcpy सार्छ; strcat जोड्छ; strcmp बराबर भए ० फर्काउँछ। सबै string function लाई string.h चाहिन्छ। strrev, strlwr र strupr पाठ्यक्रममा छन् तर मानक C मा छैनन्।
