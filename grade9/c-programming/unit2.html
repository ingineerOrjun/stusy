2.1  Introduction to C programming — C प्रोग्रामिङको परिचय

An old language that nothing has replaced

C is a general-purpose high level programming language developed by Dennis Ritchie at Bell Laboratories in 1972, to write the UNIX operating system. It is still in use for the same reason it was written: it is small, fast, and it lets a programmer reach the memory directly.

Features worth remembering, because this is a standard question:

  • Simple and small — only 32 keywords to learn, against hundreds of library functions.
  • Fast — compiled straight to machine code with very little added on top.
  • Portable — the same source file compiles on different machines.
  • Structured — a program is built from functions, each doing one job.
  • Rich set of operators — including bitwise operators most high level languages hide.
  • Extensible — a programmer can add their own functions to the library.
  • Middle level — high level readability with low level access to memory.

C is case sensitive. Sum, sum and SUM are three different names, and every keyword is lower case. This single rule causes more beginner errors than any other.

पुरानो भाषा, जसलाई कसैले विस्थापित गरेन

C सामान्य प्रयोजनको high level प्रोग्रामिङ भाषा हो, जसलाई Dennis Ritchie ले Bell Laboratories मा १९७२ मा UNIX operating system लेख्न बनाएका थिए। जुन कारणले बनाइएको थियो, त्यही कारणले अहिले पनि चलिरहेको छ: सानो, छिटो, र प्रोग्रामरलाई मेमोरीसम्म सिधै पुग्न दिन्छ।

सम्झनुपर्ने विशेषता, किनभने यो मानक प्रश्न हो:

  • सरल र सानो — सिक्नुपर्ने keyword ३२ मात्र, जबकि library function सयौं।
  • छिटो — सिधै मेसिन कोडमा compile हुन्छ, माथि थपिने कुरा थोरै।
  • Portable — उही source फाइल फरक मेसिनमा compile हुन्छ।
  • Structured — प्रोग्राम function हरूबाट बन्छ, हरेकले एउटा काम गर्ने।
  • धेरै operator — धेरै high level भाषाले लुकाउने bitwise operator सहित।
  • Extensible — प्रोग्रामरले आफ्नै function library मा थप्न सक्छ।
  • Middle level — high level जस्तो पढ्न सजिलो, low level जस्तो मेमोरी पहुँच।

C case sensitive छ। Sum, sum र SUM तीन फरक नाम हुन्, र हरेक keyword सानो अक्षरमै लेखिन्छ। सुरुआतीले गर्ने सबैभन्दा धेरै गल्ती यही एउटा नियमले निम्त्याउँछ।

2.2  Basic program structure — प्रोग्रामको आधारभूत संरचना

Every C program has the same skeleton

Learn this shape once and every program in the subject fits inside it.

  • Preprocessor directive — a line beginning with #. It is handled before compiling. #include is the one you will use most.
  • Header file — the file a directive pulls in. stdio.h holds the declarations of printf and scanf; string.h holds the string functions; math.h holds sqrt and friends. The .h stands for header.
  • main() — execution starts here, always, wherever it is written in the file. A program with no main compiles and then fails to link, because nothing knows where to begin.
  • Tokens — the smallest meaningful pieces the compiler reads. C has six kinds: keywords, identifiers, constants, strings, operators and special symbols.
  • Semicolon — a statement terminator, not a separator. Every statement ends with one; #include, a function heading and a closing brace do not, because none of them is a statement.
  • Comments — /* … */ spans lines; // runs to the end of the line. The compiler removes them, so they cost nothing to run and a great deal to omit.
  • Whitespace — spaces, tabs and blank lines. C ignores them, which is why indentation is for the reader rather than the compiler.
  • Escape sequence — a backslash and a letter that stand for one character that cannot be typed: \n newline, \t tab, \\ a real backslash, \" a quote inside a string, \0 the null character.
हरेक C प्रोग्रामको ढाँचा एउटै हुन्छ

यो आकार एक पटक सिकेपछि विषयका सबै प्रोग्राम यसैभित्र अट्छन्।

  • Preprocessor directive — # बाट सुरु हुने लाइन। यो compile गर्नुअघि नै चल्छ। सबैभन्दा धेरै चलाइने #include हो।
  • Header file — directive ले भित्र्याउने फाइल। stdio.h मा printf र scanf का घोषणा हुन्छन्; string.h मा string function; math.h मा sqrt आदि। .h को अर्थ header हो।
  • main() — फाइलमा जहाँ लेखिए पनि चल्न सधैं यहीँबाट सुरु हुन्छ। main नभएको प्रोग्राम compile त हुन्छ, तर link हुँदैन — कहाँबाट सुरु गर्ने कसैलाई थाहा हुँदैन।
  • Tokens — compiler ले पढ्ने सबैभन्दा सानो अर्थपूर्ण टुक्रा। C मा छ किसिम छन्: keyword, identifier, constant, string, operator र special symbol।
  • Semicolon — यो statement terminator हो, separator होइन। हरेक statement यसैले सकिन्छ; #include, function को शीर्षक र बन्द गर्ने brace लाई चाहिँदैन, किनभने ती statement होइनन्।
  • Comments — /* … */ धेरै लाइनसम्म; // लाइनको अन्त्यसम्म। Compiler ले हटाइदिन्छ, त्यसैले लेख्दा केही लागत छैन र नलेख्दा धेरै।
  • Whitespace — खाली ठाउँ, tab, खाली लाइन। C ले वास्ता गर्दैन — त्यसैले indentation compiler का लागि होइन, पाठकका लागि हो।
  • Escape sequence — backslash र एउटा अक्षर मिलेर टाइप गर्न नमिल्ने एउटा अक्षर जनाउँछ: \n नयाँ लाइन, \t tab, \\ साँच्चैको backslash, \" string भित्रको उद्धरण, \0 null अक्षर।

Press Next and watch where execution goes; it is not simply top to bottom. तपाईंले के सिक्नुहुन्छ: प्रोग्रामका भाग साँच्चै कुन क्रममा चल्छन् — पहिले preprocessor, अनि main, अनि एक–एक statement। Next थिचेर नियन्त्रण कता जान्छ हेर्नुहोस्; यो सिधा माथिबाट तल मात्र होइन।

2.3  Variables and keywords — Variable र keyword

A name you choose, and 32 you cannot

A variable is a named box in memory whose value can change while the program runs. Declaring one reserves the space and fixes the type: int age; gives you a box that holds a whole number and nothing else.

The name is an identifier, and the rules for one are examined directly:

  • The first character must be a letter or an underscore, never a digit.
  • After that, letters, digits and underscores only — no spaces and no other symbol.
  • It must not be a keyword.
  • It is case sensitive: total and Total are two variables.

A keyword is a word the language has already given a meaning: int, float, if, else, for, while, return, break and 24 more. There are 32 in standard C, all lower case, and you may not use one as a name — not because it is forbidden on principle, but because the compiler would have no way to tell which meaning you intended.

तपाईंले छान्ने नाम, र ३२ वटा नछान्न पाइने

Variable भनेको मेमोरीमा नाम भएको बाकस हो, जसको मान प्रोग्राम चल्दै गर्दा बदलिन सक्छ। घोषणा गर्दा ठाउँ छुट्टिन्छ र प्रकार तय हुन्छ: int age; ले पूर्ण सङ्ख्या मात्र राख्ने बाकस दिन्छ।

नाम भनेको identifier हो, र यसका नियम सिधै सोधिन्छन्:

  • पहिलो अक्षर अक्षर वा underscore हुनुपर्छ, अङ्क कहिल्यै होइन।
  • त्यसपछि अक्षर, अङ्क र underscore मात्र — खाली ठाउँ हुँदैन, अरू चिन्ह पनि हुँदैन।
  • यो keyword हुनु हुँदैन।
  • यो case sensitive हुन्छ: total र Total दुई फरक variable हुन्।

Keyword भनेको भाषाले पहिल्यै अर्थ दिइसकेको शब्द हो: int, float, if, else, for, while, return, break र अरू २४। मानक C मा ३२ वटा छन्, सबै सानो अक्षरमा, र तीमध्ये कुनैलाई नाम बनाउन मिल्दैन — सिद्धान्ततः निषेध भएर होइन, तपाईंले कुन अर्थ चाहनुभयो compiler ले छुट्याउनै नसक्ने भएर।

Legal or not? Check the four rules in order. 2marks starts with a digit — illegal. total marks has a space — illegal. float is a keyword — illegal. roll-no contains a hyphen, which C reads as minus — illegal. _total, total2, Total_Marks and a are all legal. A legal name can still be a bad one: a tells a reader nothing. मान्य हो कि होइन? चारै नियम क्रमैसँग जाँच्नुहोस्। 2marks अङ्कबाट सुरु — अमान्य। total marks मा खाली ठाउँ — अमान्य। float keyword — अमान्य। roll-no मा hyphen छ, जसलाई C ले घटाउ पढ्छ — अमान्य। _total, total2, Total_Marks र a सबै मान्य। मान्य नाम पनि नराम्रो हुन सक्छ: a ले पाठकलाई केही भन्दैन।

2.4  Character set, constants and variables — Character set, constant र variable

What you may type, and what cannot change

The character set is everything C accepts in a source file: the letters A-Z and a-z, the digits 0-9, special characters such as + - * / % = < > ( ) { } [ ] ; , . # & |, and whitespace.

A constant is a value that cannot change while the program runs. The kinds you need:

  • Integer constant — 25, -7, 0
  • Real (floating) constant — 3.14, -0.5
  • Character constant — one character in single quotes: 'A', '7', '\n'
  • String constant — characters in double quotes: "Nepal", "A"

Two ways to make your own: #define PI 3.1416, which the preprocessor substitutes before compiling, and const float pi = 3.1416;, which is a real variable the compiler refuses to let you change.

'A' and "A" are not the same thing. The first is one character and occupies one byte. The second is a string: the letter A and a hidden \0 after it, so two bytes. That difference becomes Unit 5.

के टाइप गर्न पाइन्छ, र के बदलिँदैन

Character set भनेको C ले source फाइलमा स्वीकार गर्ने सबै कुरा हो: अक्षर A-Z र a-z, अङ्क 0-9, विशेष चिन्ह जस्तै + - * / % = < > ( ) { } [ ] ; , . # & |, र खाली ठाउँ।

Constant भनेको प्रोग्राम चल्दै गर्दा नबदलिने मान हो। चाहिने किसिमहरू:

  • Integer constant — 25, -7, 0
  • Real (floating) constant — 3.14, -0.5
  • Character constant — एकल उद्धरणभित्र एउटा अक्षर: 'A', '7', '\n'
  • String constant — दोहोरो उद्धरणभित्रका अक्षर: "Nepal", "A"

आफ्नै बनाउने दुई तरिका: #define PI 3.1416, जसलाई preprocessor ले compile गर्नुअघि नै साट्छ, र const float pi = 3.1416;, जुन साँच्चैको variable हो तर compiler ले बदल्न दिँदैन।

'A' र "A" एउटै होइनन्। पहिलो एउटा अक्षर हो र एक byte ओगट्छ। दोस्रो string हो: A अक्षर र पछाडि लुकेको \0, जम्मा दुई byte। यही फरक युनिट ५ बन्छ।

2.5  Data types and format specifiers — Data type र format specifier

Four basic types and the code that prints each

The sizes are not fixed by the language. int is 2 bytes on an old 16-bit Turbo C setup and 4 bytes on everything modern. Write "2 or 4" in an answer, or use sizeof(int) to ask the compiler, which is the only reliable way to know.

Modifiers stretch a type: short, long, signed, unsigned. unsigned int gives up negative numbers to double the positive range.

The format specifier is a promise you make to printf, and printf believes it without checking. Pass an int and claim %f and the output is nonsense, with no error at all.

चार आधारभूत प्रकार, र हरेकलाई छाप्ने सङ्केत

आकार भाषाले तय गरेको होइन। पुरानो १६-bit Turbo C मा int २ byte हुन्छ र आजका सबैमा ४। उत्तरमा "२ वा ४" लेख्नुहोस्, वा sizeof(int) ले compiler लाई सोध्नुहोस् — पक्का थाहा पाउने एकमात्र भरपर्दो तरिका त्यही हो।

Modifier ले प्रकार तन्काउँछ: short, long, signed, unsigned। unsigned int ले ऋणात्मक छाडेर धनात्मक दायरा दोब्बर बनाउँछ।

Format specifier भनेको तपाईंले printf सँग गरेको वाचा हो, र printf ले नजाँची पत्याउँछ। int पठाएर %f भन्नुभयो भने कुनै त्रुटिविनै बेकारको output आउँछ।

Which format specifier does this need? — यसलाई कुन format specifier चाहिन्छ?

What you will learn: to match a specifier to a type quickly, which is the single commonest one-mark question from this unit and the commonest silent bug in a practical program. तपाईंले के सिक्नुहुन्छ: specifier लाई प्रकारसँग छिटो मिलाउन — यस युनिटबाट सोधिने सबैभन्दा सामान्य एक अंकको प्रश्न र प्रयोगात्मक प्रोग्रामको सबैभन्दा सामान्य चुपचाप रहने गल्ती यही हो।

How to use this

Look at the declaration, not at the value. A variable declared float takes %f even when it happens to hold a whole number.

मान होइन, घोषणा हेर्नुहोस्। float घोषित variable ले पूर्ण सङ्ख्या राखेको भए पनि %f नै लिन्छ।

2.6  Input and output statements — Input र output का statement

Two library functions, and one ampersand

printf() sends formatted text to the screen. Everything between the quotes is printed literally except a % specifier, which is replaced by the next argument, and an escape sequence, which becomes its character.

scanf() reads formatted input from the keyboard. It uses the same specifiers — and it needs the address of each variable, written with &, because a function that is given a value cannot change the caller's variable. Unit 4 explains why in full; for now, scanf takes & and printf does not.

Two more you will see: getchar() reads one character and putchar() writes one. Learning outcome 5.4 also mentions gets() and puts() for whole lines; they are not on the official topic list and gets() has been removed from the C standard because it cannot be used safely. Use fgets() if you need a whole line.

दुई library function, र एउटा ampersand

2.7  Operators in C — C का operator

Five families the syllabus names
  • Arithmetic — + - * / %. The modulus % gives the remainder and works on integers only.
  • Relational — < > <= >= == !=. Each answers true or false. In C there is no separate true/false type: zero is false and anything else is true.
  • Logical — && and, || or, ! not. They combine conditions that are already true or false.
  • Bitwise — & and, | or, ^ xor, ~ not, << left shift, >> right shift. These work on the individual bits of a number.
  • Assignment — = and its compound forms += -= *= /= %=. x += 5 is exactly x = x + 5.

Two more you will use constantly: increment ++ and decrement --. In i++ the old value is used and then i grows; in ++i i grows first. Alone on a line they are identical.

Precedence, highest first: (), then * / %, then + -, then relational, then &&, then ||, then = last. When in doubt, use brackets — they cost nothing and they are never wrong.

पाठ्यक्रमले नाम लिएका पाँच परिवार
  • Arithmetic — + - * / %। Modulus % ले शेष दिन्छ र पूर्णाङ्कमा मात्र चल्छ।
  • Relational — < > <= >= == !=। हरेकले सत्य वा असत्य दिन्छ। C मा छुट्टै true/false प्रकार छैन: शून्य असत्य, अरू जे भए पनि सत्य।
  • Logical — && and, || or, ! not। यिनले सत्य–असत्य भइसकेका सर्त जोड्छन्।
  • Bitwise — & and, | or, ^ xor, ~ not, << बायाँ सार्ने, >> दायाँ सार्ने। यिनले सङ्ख्याका छुट्टाछुट्टै bit मा काम गर्छन्।
  • Assignment — = र यसका मिश्रित रूप += -= *= /= %=। x += 5 ठ्याक्कै x = x + 5 हो।

अरू दुई सधैं चलाइन्छन्: increment ++ र decrement --। i++ मा पुरानै मान प्रयोग भएर अनि i बढ्छ; ++i मा पहिले i बढ्छ। एक्लै लाइनमा भए दुवै उस्तै।

Precedence, माथिल्लोदेखि: (), अनि * / %, अनि + -, अनि relational, अनि &&, अनि ||, अन्त्यमा =। अलमल भए कोष्ठक लगाउनुहोस् — यसको कुनै लागत छैन र यो कहिल्यै गलत हुँदैन।

What does a = 10 + 4 * 2 % 3; store in a? a = 10 + 4 * 2 % 3; ले a मा के राख्छ?

12. * and % have the same precedence, higher than +, and they associate left to right. So 4 * 2 is 8, then 8 % 3 is 2, then 10 + 2 is 12.

Option A is what left-to-right evaluation would give: 10 + 4 = 14, times 2 = 28, modulus 3 = 1 — not 0, and not the answer either. C does not read expressions the way a person reads a sentence.

The lesson is not to memorise a table. It is that a = 10 + ((4 * 2) % 3); says the same thing and cannot be misread, by the compiler or by you in six months.

१२। * र % को precedence उस्तै छ, + भन्दा माथि, र बायाँबाट दायाँ जान्छन्। त्यसैले 4 * 2 = 8, अनि 8 % 3 = 2, अनि 10 + 2 = 12। विकल्प (क) ले बायाँबाट दायाँ गणना गरेको नतिजा जनाउँछ, र C ले वाक्य पढेजस्तै expression पढ्दैन। सिकाइ तालिका कण्ठ गर्नु होइन — a = 10 + ((4 * 2) % 3); ले उही कुरा भन्छ र यसलाई compiler ले पनि, छ महिनापछि तपाईंले पनि गलत पढ्नै सक्नुहुन्न।

Example 1 A complete program, part by part

Question: write a C program that reads the radius of a circle and prints its area, and name each part of the program.

Decide the data type for the radius before you open this. If you choose int, work out what the program prints for a radius of 2.5. खोल्नुअघि radius को data type निर्णय गर्नुहोस्। int छान्नुभयो भने २.५ को radius मा प्रोग्रामले के छाप्छ निकाल्नुहोस्।

Working 
#include <stdio.h>          /* preprocessor directive + header file */

#define PI 3.1416           /* a symbolic constant */

int main()                  /* execution starts here */
{
    float r, area;          /* declaration: two float variables */

    printf("Enter the radius: ");
    scanf("%f", &r);         /* & gives scanf the ADDRESS of r */

    area = PI * r * r;      /* assignment; PI is replaced before compiling */

    printf("Area = %.2f\n", area);   /* %.2f = two decimal places */
    return 0;               /* 0 means the program succeeded */
}
Output (if the user types 7) 
Enter the radius: 7
Area = 153.94

float, not int: with int r a radius of 2.5 would be stored as 2 and the area would be wrong with no warning. Note also that r is multiplied by itself rather than written r^2 — ^ is the bitwise XOR operator in C, not a power, and r^2 compiles and gives a completely different number. int होइन float: int r भए २.५ को radius २ मा भण्डारण हुन्थ्यो र क्षेत्रफल कुनै चेतावनीविनै गलत हुन्थ्यो। अर्को कुरा — r लाई आफैंले गुणन गरिएको छ, r^2 लेखिएको छैन; C मा ^ घात होइन bitwise XOR हो, र r^2 compile भएर बिलकुलै फरक सङ्ख्या दिन्छ।

Example 2 Finding the errors in a short program

Question: this program will not compile, and when it is made to compile it still prints the wrong thing. Find every fault.

#include <stdio.h>;

int main()
{
    int a, b
    float avg;

    printf("Enter two numbers: ");
    scanf("%d %d", a, b);

    avg = (a + b) / 2;
    printf("Average = %d", avg);
    return 0;
}

Find at least four faults before opening this. Only one of them stops the compiler — and the ones that do not are the expensive ones. खोल्नुअघि कम्तीमा चार गल्ती भेट्नुहोस्। त्यसमध्ये एउटैले मात्र compiler रोक्छ — र नरोक्नेहरू नै महँगा हुन्।

Working
LINE 1 #include <stdio.h>; A directive is not a statement. The compiler says "extra tokens at end of '#include' directive" and carries on. WARNING LINE 5 int a, b The declaration has no semicolon. The error is reported on the NEXT line. COMPILE ERROR LINE 8 scanf("%d %d", a, b); scanf needs the ADDRESS of each variable: &a and &b. This compiles with no message unless you ask for warnings, and then the program misbehaves unpredictably. RUN-TIME LINE 10 avg = (a + b) / 2; a and b are int, so this is integer division and the .5 is discarded before avg sees it. No warning level mentions it. WRONG ANSWER LINE 11 printf("Average = %d", avg); avg is a float and %d claims an int. printf believes the specifier, so this prints nonsense. It should be %.2f. WRONG OUTPUT

Only one of the five stops the build — the missing semicolon. That one is free, because the compiler tells you where it is. The other four are what this subject is really about, and the compiler's silence about them is the whole point: ask for warnings (gcc -Wall) and it will mention line 8 and line 11; nothing at any warning level mentions line 10. A program that compiles is a program whose grammar is right, and nothing more. पाँचमध्ये एउटैले मात्र build रोक्छ — छुटेको semicolon। त्यो सस्तो छ, किनभने compiler ले कहाँ छ भनिदिन्छ। बाँकी चार नै यो विषयको साँचो कुरा हुन्, र त्यसबारे compiler को चुप्पी नै मुख्य पाठ हो: चेतावनी मागे (gcc -Wall) लाइन ८ र लाइन ११ को कुरा आउँछ; लाइन १० को कुरा कुनै पनि स्तरमा आउँदैन। compile भएको प्रोग्राम भनेको व्याकरण ठिक भएको प्रोग्राम हो, त्योभन्दा बढी होइन।

Mistakes that cost marks here — यहाँ अङ्क गुमाउने गल्तीहरू

  • Forgetting the ampersand in scanf. scanf("%d", n) compiles and then behaves unpredictably. It is &n.
  • Putting a semicolon after #include or after a function heading. Neither is a statement.
  • Expecting 7 / 2 to be 3.5. Two integers give integer division. Write 7.0 / 2 if you want 3.5.
  • Using = where == is meant. if (a = 5) assigns 5 and is always true. It is legal C, so nothing warns you.
  • Mixing up 'A' and "A". Single quotes for one character, double quotes for a string.
  • Claiming int is always 2 bytes. Say "2 or 4, depending on the compiler".
scanf मा ampersand बिर्सनु: scanf("%d", n) compile भएर अनिश्चित व्यवहार गर्छ; &n लेख्नुहोस्। #include वा function को शीर्षकपछि semicolon राख्नु: ती statement होइनन्। 7 / 2 लाई ३.५ ठान्नु: दुई पूर्णाङ्कको भाग पूर्णाङ्कमै हुन्छ; ३.५ चाहिए 7.0 / 2 लेख्नुहोस्। == को ठाउँमा = लेख्नु: if (a = 5) ले ५ राख्छ र सधैं सत्य हुन्छ — मान्य C भएकाले चेतावनी पनि आउँदैन। 'A' र "A" मिसाउनु: एउटा अक्षरलाई एकल उद्धरण, string लाई दोहोरो। int सधैं २ byte भन्नु: "compiler अनुसार २ वा ४" लेख्नुहोस्।

Memory hook — scanf takes the address, printf takes the value. One ampersand, one whole category of bug. सम्झने तरिका — scanf ले ठेगाना लिन्छ, printf ले मान। एउटा ampersand, एउटा पूरै किसिमको bug।

What is an identifier? Write any three rules for writing a valid identifier in C. Identifier भनेको के हो? C मा मान्य identifier लेख्ने कुनै तीन नियम लेख्नुहोस्।

An identifier is the name given by the programmer to a variable, a function, an array or any other user-defined item in a program.

Rules (any three):

1. It must begin with a letter or an underscore, not a digit.
2. It may contain only letters, digits and underscores — no spaces or other special characters.
3. It cannot be a keyword.
4. It is case sensitive, so sum and Sum are different.

Identifier भनेको प्रोग्राममा variable, function, array वा अन्य प्रयोगकर्ता-परिभाषित वस्तुलाई प्रोग्रामरले दिएको नाम हो। नियम (कुनै तीन): १. अङ्कबाट होइन, अक्षर वा underscore बाट सुरु हुनुपर्छ। २. अक्षर, अङ्क र underscore मात्र — खाली ठाउँ वा अरू विशेष चिन्ह हुँदैन। ३. keyword हुन सक्दैन। ४. case sensitive हुन्छ, त्यसैले sum र Sum फरक हुन्।
4 marks Practice question

Explain any four data types of C with their format specifiers and one example each. C का कुनै चार data type, तिनका format specifier र हरेकको एउटा उदाहरणसहित बुझाउनुहोस्।

    printf("Sum        = %d\n", a + b);
    printf("Difference = %d\n", a - b);
    printf("Product    = %d\n", a * b);
    printf("Remainder  = %d\n", a % b);
    return 0;
}

Marks are for the header, main with its braces, the declaration, the two ampersands in scanf, correct specifiers, and return 0;. Note that % is used rather than / for the remainder, and that the program would fail at run time if the user entered 0 for b.

अंक header, brace सहितको main, घोषणा, scanf का दुई ampersand, सही specifier र return 0; का लागि हुन्। शेषका लागि / होइन % प्रयोग भएको ध्यान दिनुहोस्, र प्रयोगकर्ताले b मा ० हाले प्रोग्राम चल्दै गर्दा असफल हुन्थ्यो।

Key points from this unit

  • C was written by Dennis Ritchie in 1972 at Bell Labs, for UNIX. It is case sensitive and has 32 keywords.
  • Every program: #include, then int main(), then statements each ending in a semicolon, then return 0;.
  • Six kinds of token: keywords, identifiers, constants, strings, operators, special symbols.
  • An identifier starts with a letter or underscore, holds no spaces, and is not a keyword.
  • Types and specifiers: int %d, float %f, double %lf, char %c, string %s.
  • scanf needs &; printf does not.
  • Five operator families: arithmetic, relational, logical, bitwise, assignment.
  • Integer division discards the remainder; % returns it.
C लाई Dennis Ritchie ले १९७२ मा Bell Labs मा UNIX का लागि लेखे। यो case sensitive छ र ३२ keyword छन्। हरेक प्रोग्राम: #include, अनि int main(), अनि semicolon ले सकिने statement, अनि return 0;। छ किसिमका token: keyword, identifier, constant, string, operator, special symbol। Identifier अक्षर वा underscore बाट सुरु हुन्छ, खाली ठाउँ हुँदैन, keyword हुँदैन। प्रकार र specifier: int %d, float %f, double %lf, char %c, string %s। scanf लाई & चाहिन्छ; printf लाई चाहिँदैन। पाँच operator परिवार: arithmetic, relational, logical, bitwise, assignment। Integer division ले शेष फाल्छ; % ले त्यही फर्काउँछ।
