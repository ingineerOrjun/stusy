Grade 9 · Subject 1 · CDC Nepal 2078

Programming Principles in C Language

The subject where you stop using computers and start instructing them. It begins before any code — what a program is, and how to plan one with an algorithm and a flowchart — then builds C from its smallest parts: variables, operators, the three ways to choose, the three ways to repeat, functions, arrays, strings, structures and pointers. Every program on these pages is stepped through line by line, with the value of every variable shown as it changes.

कम्प्युटर चलाउन छाडेर कम्प्युटरलाई निर्देशन दिन सुरु गर्ने विषय। कोड लेख्नुअघि नै सुरु हुन्छ — प्रोग्राम भनेको के हो, र algorithm अनि flowchart ले त्यसको योजना कसरी बनाइन्छ — अनि C लाई सानैदेखि बनाउँदै जान्छ: variable, operator, छान्ने तीन तरिका, दोहोर्‍याउने तीन तरिका, function, array, string, structure र pointer। यहाँका हरेक प्रोग्राम लाइन–लाइन चलाएर देखाइएका छन्, हरेक variable को मान बदलिँदै गएको सहित।
