3.1  Decision making — if, if…else, switch — निर्णय — if, if…else, switch

Four shapes, in the order you meet them

1. Simple if — do something only when a condition is true.

2. if…else — two paths, exactly one of which runs.

3. if…else if…else (the ladder) — several conditions tested in order. The first true one wins and the rest are never tested. Order matters: if you test marks >= 40 before marks >= 80, nobody ever gets a distinction.

4. switch — one value compared against a list of exact constants.

A condition is any expression. In C zero is false and anything that is not zero is true, which is why if (n) means "if n is not zero" and is perfectly legal.

Without braces, an if controls exactly one statement. Two indented lines under an if look like a block and are not one — the second runs every time. Use braces always; the compiler does not care and the next reader does.

चार आकार, भेटिने क्रममा

१. साधारण if — सर्त सत्य भएमा मात्र केही गर्ने।

२. if…else — दुई बाटो, जसमध्ये ठ्याक्कै एउटा चल्छ।

३. if…else if…else (शृंखला) — धेरै सर्त क्रमैसँग जाँचिन्छन्। पहिलो सत्य जित्छ र बाँकी कहिल्यै जाँचिँदैनन्। क्रम महत्त्वपूर्ण छ: marks >= 80 भन्दा अघि marks >= 40 जाँच्नुभयो भने कसैले पनि distinction पाउँदैन।

४. switch — एउटा मानलाई ठ्याक्कै मिल्ने constant को सूचीसँग तुलना गर्ने।

सर्त भनेको जुनसुकै expression हो। C मा शून्य असत्य र शून्य नभएको जे पनि सत्य हो — त्यसैले if (n) को अर्थ "n शून्य होइन भने" हुन्छ र यो पूरै मान्य छ।

Brace नभए if ले ठ्याक्कै एउटा statement मात्र नियन्त्रण गर्छ। if मुनि indent गरेका दुई लाइन block जस्तो देखिन्छन् तर होइनन् — दोस्रो सधैं चल्छ। सधैं brace लगाउनुहोस्; compiler लाई फरक पर्दैन, पछि पढ्नेलाई पर्छ।

Example 1 The same decision, written four ways

Question: print the division a student gets from their marks, using a ladder and then using switch. Which is right for this problem?

Decide, before opening this, whether switch can test a RANGE of marks. The answer decides the whole question. खोल्नुअघि निर्णय गर्नुहोस्: switch ले अंकको दायरा जाँच्न सक्छ कि सक्दैन? त्यही उत्तरले पूरै प्रश्न टुङ्ग्याउँछ।

Working 
/* (a) the ladder — the right tool here */
if (marks >= 80)
    printf("Distinction");
else if (marks >= 60)
    printf("First division");
else if (marks >= 40)
    printf("Second division");
else
    printf("Fail");

/* (b) switch — the wrong tool here */
switch (marks)
{
    case 80: printf("Distinction"); break;
    case 79: printf("First division"); break;
    /* ...and 99 more cases. This cannot work. */
    default: printf("Fail");
}

switch compares a value against exact constants, so it cannot test a range. Grading by marks needs the ladder. switch is right when the value is a small set of exact choices — a menu option, a grade letter, a day number. Note also the descending order in the ladder: with 40 first, a student scoring 95 would be told "second division", because the first true test wins. switch ले मानलाई ठ्याक्कै मिल्ने constant सँग तुलना गर्छ, त्यसैले दायरा जाँच्न सक्दैन। अंकबाट श्रेणी निकाल्न शृंखला नै चाहिन्छ। मान सानो र ठ्याक्कै मिल्ने छनोटको समूह भएमा switch ठिक हुन्छ — menu विकल्प, grade अक्षर, बारको नम्बर। शृंखलाको घट्दो क्रम पनि हेर्नुहोस्: ४० पहिले राखे ९५ ल्याउने विद्यार्थीलाई "second division" भनिन्थ्यो, किनभने पहिलो सत्य जाँच नै जित्छ।

Step through it · चरणबद्ध हेर्नुहोस्

Only one branch of a ladder ever runs — शृंखलाको एउटै शाखा मात्र चल्छ

What you will learn: where control actually goes after a branch succeeds. It does not fall into the else, and it does not test anything further — watch the line marker jump past both. तपाईंले के सिक्नुहुन्छ: शाखा सफल भएपछि नियन्त्रण साँच्चै कता जान्छ। यो else मा झर्दैन र थप केही जाँच्दैन — लाइनको चिन्ह दुवै नाघेर जाँदा हेर्नुहोस्।

How to use this

Before stepping, say which line will run and which lines will be skipped. Then check whether the else was tested at all.

चरण सुरु गर्नुअघि कुन लाइन चल्छ र कुन छुट्छ भन्नुहोस्। अनि else जाँचियो कि जाँचिएन हेर्नुहोस्।
switch has three rules that are all examinable. The expression must be an int or a char — never a float and never a string. Each case label must be a constant, not a variable. And without break, control falls through into the next case and keeps going — which is occasionally useful and usually a bug. default is optional and runs when nothing matched. switch का तीन नियम सबै परीक्षामा सोधिन्छन्। Expression int वा char हुनुपर्छ — float कहिल्यै होइन, string पनि होइन। हरेक case को label constant हुनुपर्छ, variable होइन। अनि break नभए नियन्त्रण अर्को case मा झरेर चलिरहन्छ — कहिलेकाहीं काम लाग्ने, प्रायः गल्ती। default ऐच्छिक हो र केही नमिले चल्छ।

3.2  Loop statements — for, while, do-while, nested — Loop — for, while, do-while, nested

Three loops, one question that chooses between them

Every loop needs the same three things, and the difference between the loops is only where those three are written:

  • Initialisation — the counter gets a starting value.
  • Condition — tested each time; the loop continues while it is true.
  • Update — the counter changes, or the condition never becomes false.

for puts all three on one line: for (i = 1; i <= 10; i++). Use it when the number of repetitions is known before the loop starts.

while puts only the condition in the brackets; the other two are yours to place. Use it when you do not know how many times — "keep reading until the user types 0".

do…while runs the body first and tests afterwards, so it always runs at least once. Use it when the body has to happen before anyone can judge the condition — a menu, a password prompt. It is the only loop that ends with a semicolon after the while.

Nested loops are a loop inside a loop. The inner one completes all of its turns for each single turn of the outer one. In a pattern, the outer loop is rows and the inner loop is columns.

तीन loop, र तिनलाई छुट्याउने एउटै प्रश्न

हरेक loop लाई उही तीन कुरा चाहिन्छ, र loop बीचको फरक ती तीन कहाँ लेखिन्छन् भन्ने मात्र हो:

  • Initialisation — counter ले सुरुको मान पाउँछ।
  • Condition — हरेक पटक जाँचिन्छ; सत्य रहेसम्म loop चल्छ।
  • Update — counter बदलिन्छ, नत्र सर्त कहिल्यै असत्य हुँदैन।

for ले तीनै कुरा एउटै लाइनमा राख्छ: for (i = 1; i <= 10; i++)। दोहोरिने सङ्ख्या loop सुरु हुनुअघि नै थाहा भएमा यसलाई प्रयोग गर्नुहोस्।

while ले कोष्ठकमा सर्त मात्र राख्छ; अरू दुई तपाईंले राख्नुपर्छ। कति पटक भन्ने थाहा नभएमा प्रयोग गर्नुहोस् — "प्रयोगकर्ताले ० नटाइपेसम्म पढिरहनुहोस्"।

do…while ले पहिले body चलाएर पछि जाँच्छ, त्यसैले यो सधैं कम्तीमा एक पटक चल्छ। सर्त जाँच्नुअघि नै body हुनैपर्ने भए प्रयोग गर्नुहोस् — menu, password। while पछि semicolon चाहिने एकमात्र loop यही हो।

Nested loop भनेको loop भित्रको loop हो। बाहिरी loop को एक पटक का लागि भित्री loop ले आफ्ना सबै पटक पूरा गर्छ। ढाँचामा बाहिरी loop पङ्क्ति र भित्री loop स्तम्भ हो।

Step through it · चरणबद्ध हेर्नुहोस्

A for loop, one turn at a time — For loop, एक–एक पटक

What you will learn: the order the three parts of a for line actually run in — initialise once, then test, body, update, test, body, update — and what i holds when the loop finally stops. That last value is what output questions are built on. तपाईंले के सिक्नुहुन्छ: for लाइनका तीन भाग साँच्चै कुन क्रममा चल्छन् — एक पटक initialise, अनि जाँच, body, update, जाँच, body, update — र loop अन्ततः रोकिँदा i मा के हुन्छ। Output का प्रश्न त्यही अन्तिम मानमा बनेका हुन्छन्।

How to use this

Write the two columns — i and sum — on paper and fill them in before each press. That is exactly what "trace the following program" asks you to do in an examination.

कागजमा i र sum का दुई स्तम्भ बनाएर हरेक पटक थिच्नुअघि भर्नुहोस्। परीक्षामा "तलको प्रोग्राम ट्रेस गर्नुहोस्" भन्दा ठ्याक्कै त्यही खोजिएको हुन्छ।

Step through it · चरणबद्ध हेर्नुहोस्

Why do-while always runs at least once — do-while किन कम्तीमा एक पटक सधैं चल्छ

What you will learn: the single difference between while and do-while, shown by giving both the same false condition. One prints nothing and the other prints a line, from the same starting state. तपाईंले के सिक्नुहुन्छ: while र do-while बीचको एउटै फरक — दुवैलाई उही असत्य सर्त दिएर देखाइएको। उही सुरुवातबाट एउटाले केही छाप्दैन, अर्कोले एक लाइन छाप्छ।

How to use this

Both loops are given n < 5 with n already 10. Predict how many lines the program prints in total before you step. Most people say zero.

दुवै loop लाई n पहिल्यै १० हुँदा n < 5 दिइएको छ। चरण सुरु गर्नुअघि प्रोग्रामले जम्मा कति लाइन छाप्छ अनुमान गर्नुहोस्। धेरैले शून्य भन्छन्।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Which loop fits this job best? — यो कामलाई कुन loop ठिक हुन्छ?

What you will learn: to choose a loop from the problem rather than from habit. The deciding fact is always whether the number of repetitions is known before the loop starts. तपाईंले के सिक्नुहुन्छ: बानीले होइन, समस्या हेरेर loop छान्न। निर्णय गर्ने कुरा सधैं loop सुरु हुनुअघि दोहोरिने सङ्ख्या थाहा छ कि छैन भन्ने हो।

How to use this

Ask two questions in order. Do I know the count in advance? If yes, for. If no, must the body happen at least once? If yes, do-while; if no, while.

क्रमैसँग दुई प्रश्न सोध्नुहोस्। गन्ती पहिल्यै थाहा छ? छ भने for। छैन भने — body कम्तीमा एक पटक हुनैपर्छ? पर्छ भने do-while; पर्दैन भने while।

Predict first · पहिले अनुमान गर्नुहोस्

How many times does the body run?
for (i = 1; i <= 5; i++);
    printf("Hello"); body कति पटक चल्छ? माथिको for लाइनको अन्त्यमा semicolon छ।

Once. The semicolon at the end of the for line is a complete, empty statement, and that empty statement is the loop's body. The loop faithfully does nothing five times. The printf is simply the next statement after the loop, so it runs once.

The program compiles without a single warning, which is exactly what makes this mistake expensive: nothing tells you, and the output is one line where you expected five.

The same trap exists on if: if (x > 5); tests x, does nothing, and then runs the next line unconditionally. Be suspicious of a semicolon directly after a closing bracket.

एक पटक। for लाइनको अन्त्यको semicolon पूरै खाली statement हो, र त्यही खाली statement loop को body हो। Loop ले इमानदारीपूर्वक पाँच पटक केही गर्दैन। printf loop पछिको अर्को statement मात्र हो, त्यसैले एक पटक चल्छ। प्रोग्राम एउटै चेतावनीविना compile हुन्छ, र यही गल्ती महँगो हुनुको कारण त्यही हो: कसैले भन्दैन, र पाँच लाइनको ठाउँमा एक लाइन आउँछ। if मा पनि उही पासो छ: if (x > 5); ले x जाँच्छ, केही गर्दैन, अनि अर्को लाइन सर्तविनै चलाउँछ। कोष्ठक बन्द भएपछि सिधै आउने semicolon देखे शंका गर्नुहोस्।
Example 2 Nested loops — printing a triangle

Question: write a program that prints this pattern, and say which loop controls what.

Count the stars on each row before opening this. Row 1 has one, row 4 has four — so what must the inner loop's condition depend on? खोल्नुअघि हरेक पङ्क्तिका तारा गन्नुहोस्। पहिलो पङ्क्तिमा एउटा, चौथोमा चार — त्यसो भए भित्री loop को सर्त केमा भर पर्नुपर्छ?

Working 
#include <stdio.h>

int main()
{
    int i, j;

    for (i = 1; i <= 4; i++)        /* OUTER: one turn per ROW */
    {
        for (j = 1; j <= i; j++)    /* INNER: j goes up to i   */
        {
            printf("* ");
        }
        printf("\n");               /* end of the row          */
    }
    return 0;
}
Output 
*
* *
* * *
* * * *

Every row really ends with a space you cannot see here, because printf("* ") prints a space after each star — the first row is "* " and the last is "* * * * ". Nothing in the pattern depends on it, but it is the kind of thing that makes an automatic checker disagree with you. हरेक पङ्क्ति वास्तवमा यहाँ नदेखिने एउटा खाली ठाउँमा सकिन्छ, किनभने printf("* ") ले हरेक तारापछि एक खाली ठाउँ छाप्छ — पहिलो पङ्क्ति "* " र अन्तिम "* * * * "। नमुनाको कुनै कुरा त्यसमा अडिँदैन, तर स्वचालित जाँचकर्ता तपाईंसँग बाझ्ने ठाउँ यही हो।

Two details carry the marks. The inner condition is j <= i and not j <= 4: the number of stars has to grow with the row, and i is the row number. And the printf("\n") sits inside the outer loop but outside the inner one — move it inside the inner loop and every star lands on its own line; move it outside both and the whole pattern becomes one long row. अंक दुई कुराले बोक्छन्। भित्री सर्त j <= 4 होइन j <= i हो: ताराको सङ्ख्या पङ्क्तिसँगै बढ्नुपर्छ, र i नै पङ्क्ति नम्बर हो। अनि printf("\n") बाहिरी loop भित्र तर भित्री loop बाहिर छ — भित्री loop भित्र सारे हरेक तारा आफ्नै लाइनमा जान्छ; दुवैभन्दा बाहिर सारे पूरै ढाँचा एउटै लामो पङ्क्ति बन्छ।

3.3  Jump statements — break, continue, goto, return — Jump statement — break, continue, goto, return

Four ways to leave somewhere early
  • break — leaves the whole loop immediately and continues after it. Inside a switch it stops the fall-through into the next case.
  • continue — abandons the rest of this turn only and goes straight to the next one. The loop is not left.
  • goto — jumps to a labelled line elsewhere in the same function: goto end; with end: somewhere below. It is examinable, and almost every real program is clearer without it, because a reader can no longer tell what reaches a line by reading downwards.
  • return — ends the whole function and hands a value back. Inside a loop it leaves the loop too, because the function it belonged to has finished.

In a nested loop, break leaves only the inner loop. This is asked often and answered wrongly often: one break does not escape two loops.

समयअघि बाहिरिने चार तरिका
  • break — पूरै loop तुरुन्तै छाडेर त्यसपछिबाट अघि बढ्छ। switch भित्र यसले अर्को case मा झर्न रोक्छ।
  • continue — यस पटकको बाँकी मात्र छाडेर सिधै अर्को पटकमा जान्छ। Loop छाडिँदैन।
  • goto — उही function भित्र label लेखिएको लाइनमा हाम फाल्छ: goto end; र तल कतै end:। परीक्षामा सोधिन्छ, तर झन्डै हरेक वास्तविक प्रोग्राम यसविना स्पष्ट हुन्छ — किनभने कुन लाइनमा के पुग्छ भन्ने कुरा तलतिर पढेर थाहा पाउन सकिँदैन।
  • return — पूरै function सिध्याएर मान फर्काउँछ। Loop भित्र भए loop पनि छुट्छ, किनभने त्यो भएको function नै सकियो।

Nested loop मा break ले भित्री loop मात्र छाड्छ। यो धेरै सोधिन्छ र धेरै गलत उत्तर आउँछ: एउटा break ले दुई loop उम्कँदैन।

Step through it · चरणबद्ध हेर्नुहोस्

break and continue in one loop — एउटै loop मा break र continue

What you will learn: why the output skips a number in the middle and stops early at the end, from one loop containing both statements. Watch where control jumps on the continue and where it jumps on the break. तपाईंले के सिक्नुहुन्छ: दुवै statement भएको एउटै loop ले बीचमा एउटा सङ्ख्या किन छाड्छ र अन्त्यमा किन चाँडै रोकिन्छ। continue मा नियन्त्रण कता हाम फाल्छ र break मा कता, हेर्नुहोस्।

How to use this

Predict the complete output before you start. Then check two things: is 3 missing, and does the output stop before 5?

सुरु गर्नुअघि पूरै output अनुमान गर्नुहोस्। अनि दुई कुरा जाँच्नुहोस्: ३ छुटेको छ? र output ५ भन्दा अगाडि रोकिएको छ?

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

Which jump statement does this describe? — यो वर्णन कुन jump statement को हो?

What you will learn: to tell the four apart by effect rather than by definition, which is how the examination asks about them. तपाईंले के सिक्नुहुन्छ: परिभाषाले होइन असरले चारैलाई छुट्याउन — परीक्षाले सोध्ने तरिका त्यही हो।

How to use this

For each case ask what is abandoned: this turn, this loop, or this function. Those three answers separate continue, break and return, and only goto names a destination.

हरेक केसमा के छाडिन्छ सोध्नुहोस्: यस पटक, यो loop, कि यो function। यी तीन उत्तरले continue, break र return छुट्याउँछन्, र गन्तव्यको नाम goto ले मात्र लिन्छ।

Practise it — the help comes away · अभ्यास गर्नुहोस् — सहयोग घट्दै जान्छ

Mistakes that cost marks here — यहाँ अङ्क गुमाउने गल्तीहरू

  • A semicolon after for, while or if. It makes an empty body, compiles cleanly, and silently changes the program.
  • Forgetting break in a switch. Every case below the matching one runs as well.
  • Using switch for a range of values. It compares exact constants only.
  • Forgetting the update inside a while. The condition never becomes false and the loop never ends.
  • Thinking one break leaves two nested loops. It leaves the inner one only.
  • Writing = instead of == in a condition. if (a = 0) is always false and if (a = 5) is always true.
  • Omitting braces around two statements. Only the first belongs to the if or the loop.
for, while वा if पछि semicolon: खाली body बन्छ, सफा compile हुन्छ, र प्रोग्राम चुपचाप बदलिन्छ। switch मा break बिर्सनु: मिलेको case मुनिका सबै पनि चल्छन्। दायराका लागि switch चलाउनु: यसले ठ्याक्कै मिल्ने constant मात्र तुलना गर्छ। while भित्र update बिर्सनु: सर्त कहिल्यै असत्य हुँदैन र loop रोकिँदैन। एउटा break ले दुई nested loop छाड्छ भन्ठान्नु: भित्री मात्र छाड्छ। सर्तमा == को ठाउँमा = लेख्नु: if (a = 0) सधैं असत्य, if (a = 5) सधैं सत्य। दुई statement वरिपरि brace नलगाउनु: if वा loop को भाग पहिलो मात्र हुन्छ।

Memory hook — continue skips a turn; break ends the game; return leaves the ground. सम्झने तरिका — continue ले एक पटक छाड्छ; break ले खेल सिध्याउँछ; return ले मैदानै छाड्छ।

2 marks Practice question

Differentiate between break and continue with an example of each. break र continue को फरक हरेकको उदाहरणसहित लेख्नुहोस्।

break terminates the loop completely. Control passes to the first statement after the loop, and no further turn happens. Example: in for (i=1; i<=5; i++) { if (i==3) break; printf("%d", i); } the output is 12.

continue skips only the remaining statements of the current turn and goes on to the next turn. The loop itself continues. Example: in for (i=1; i<=5; i++) { if (i==3) continue; printf("%d", i); } the output is 1245.

The difference in one line: break ends the loop, continue ends only that pass.

break ले loop पूरै सिध्याउँछ; नियन्त्रण loop पछिको पहिलो statement मा जान्छ। उदाहरणको output 12 हुन्छ। continue ले यस पटकका बाँकी statement मात्र छाडेर अर्को पटकमा जान्छ; loop चलिरहन्छ। उदाहरणको output 1245 हुन्छ। एक लाइनमा फरक: break ले loop सिध्याउँछ, continue ले त्यो एक पटक मात्र।
4 marks Practice question

Write a C program to print the multiplication table of a number entered by the user, from 1 to 10. प्रयोगकर्ताले दिएको सङ्ख्याको १ देखि १० सम्मको गुणन तालिका छाप्ने C प्रोग्राम लेख्नुहोस्।

#include <stdio.h>

int main()
{
    int n, i;

    printf("Enter a number: ");
    scanf("%d", &n);

    for (i = 1; i <= 10; i++)
    {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}

Marks: a for loop is correct here because ten turns are known in advance. Note that i is used inside the printf as well as in the condition — a counter is a variable, not just a tally.

अंक: दस पटक पहिल्यै थाहा भएकाले यहाँ for ठिक छ। i सर्तमा मात्र होइन printf भित्र पनि प्रयोग भएको ध्यान दिनुहोस् — counter गन्ती मात्र होइन, variable हो।
8 marks Practice question

Explain the three looping statements of C with syntax and one example each. State clearly when each should be used. C का तीन looping statement लाई syntax र हरेकको एउटा उदाहरणसहित बुझाउनुहोस्। हरेक कहिले प्रयोग गर्ने स्पष्ट लेख्नुहोस्।

1. for loop — all three control parts on one line.

for (initialisation; condition; update)
{
    statements;
}

Example: for (i = 1; i <= 5; i++) printf("%d ", i); prints 1 2 3 4 5. Use it when the number of repetitions is known before the loop starts.

2. while loop — only the condition is in the brackets; the condition is tested before every turn, so the body may run zero times.

initialisation;
while (condition)
{
    statements;
    update;
}

Example: i = 1; while (i <= 5) { printf("%d ", i); i++; } prints the same. Use it when the number of repetitions is not known in advance — reading until the user types a sentinel value.

3. do-while loop — the body runs first and the condition is tested afterwards, so the body always runs at least once. It is the only loop with a semicolon after the condition.

do
{
    statements;
    update;
} while (condition);

Example: i = 1; do { printf("%d ", i); i++; } while (i <= 5); prints the same. Use it when the body must happen at least once — showing a menu, or asking for a password before it can be judged wrong.

All three can solve the same problem; the choice states the intention, which is what the marks are for.

१. for — नियन्त्रणका तीनै भाग एउटै लाइनमा; दोहोरिने सङ्ख्या पहिल्यै थाहा भएमा। २. while — कोष्ठकमा सर्त मात्र; हरेक पटकअघि जाँचिने भएकाले body शून्य पटक पनि चल्न सक्छ; सङ्ख्या पहिल्यै थाहा नभएमा। ३. do-while — पहिले body, पछि जाँच; त्यसैले कम्तीमा एक पटक सधैं चल्छ; सर्तपछि semicolon चाहिने एकमात्र loop यही; body कम्तीमा एक पटक हुनैपर्ने भएमा। तीनैले उही समस्या समाधान गर्न सक्छन्; छनोटले नियत देखाउँछ, र अंक त्यसैको हो।

Key points from this unit

  • An if…else if ladder runs exactly one branch — the first true one.
  • switch compares exact constants, works on int or char, and needs break after each case.
  • Every loop needs initialisation, a condition and an update. for puts all three on one line.
  • while may run zero times; do-while always runs at least once.
  • In nested loops the inner loop completes fully for each single turn of the outer one; outer is rows, inner is columns.
  • break leaves the loop, continue skips a turn, return leaves the function, goto jumps to a label.
  • A semicolon straight after for, while or if creates an empty body and compiles without warning.
  • After for (i = 1; i <= 5; i++) ends, i holds 6.
if…else if शृंखलाले ठ्याक्कै एउटा शाखा चलाउँछ — पहिलो सत्य भएको। switch ले ठ्याक्कै मिल्ने constant तुलना गर्छ, int वा char मा चल्छ, र हरेक case पछि break चाहिन्छ। हरेक loop लाई initialisation, सर्त र update चाहिन्छ; for ले तीनै एउटै लाइनमा राख्छ। while शून्य पटक पनि चल्न सक्छ; do-while कम्तीमा एक पटक सधैं चल्छ। Nested loop मा बाहिरीको एक पटकका लागि भित्री पूरै चल्छ; बाहिरी पङ्क्ति, भित्री स्तम्भ। break ले loop छाड्छ, continue ले एक पटक, return ले function, goto ले label मा हाम फाल्छ। for, while वा if पछि सिधै semicolon राखे खाली body बन्छ र चेतावनीविनै compile हुन्छ। for (i = 1; i <= 5; i++) सकिएपछि i मा ६ हुन्छ।
