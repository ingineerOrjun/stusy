Computer Software

कम्प्युटर सफ्टवेयर

10 hrs · 9 marks · 8 practical hrs

By the end of this unit you can… — यो युनिट सकिँदा तपाईं यी कुरा गर्न सक्नुहुनेछ

  1. Say what software is and why hardware cannot work without it.
  2. Separate system software from application software, and place utility software.
  3. Define an operating system by the job it does, not by naming Windows.
  4. List the functions of an operating system and give one example of each.
  5. Name the types of operating system and say which situation each suits.
  6. Compare CUI and GUI, with an advantage of each — including an advantage of CUI.
  7. Explain what makes software open source, and what it does not mean.
यो युनिट सकिँदा: सफ्टवेयर के हो र हार्डवेयर यसविना किन चल्दैन भन्न, system र application software छुट्याउन अनि utility software कहाँ पर्छ भन्न, operating system लाई Windows को नाम लिएर होइन कामले परिभाषित गर्न, OS का कार्य उदाहरणसहित लेख्न, OS का किसिम र कुन अवस्थामा कुन सुहाउँछ भन्न, CUI र GUI तुलना गर्न — CUI को पनि एउटा फाइदासहित — र open source सफ्टवेयर के हो अनि के होइन बुझाउन सक्नुहुनेछ।

3.1  What software is — सफ्टवेयर भनेको के हो

The part you cannot drop on your foot

Software is the set of instructions that tells the hardware what to do. Hardware is every physical part you can touch; software is everything you cannot.

A computer with no software is a complete and useless machine. The circuits are willing and the screen is lit, and nothing happens, because nothing has told the processor which of its billions of possible operations to perform next. Hardware supplies the ability; software supplies the instructions.

That is also why the same computer can be a typewriter in the morning and a calculator in the afternoon. The hardware did not change. The instructions did.

खुट्टामा खसाल्न नमिल्ने भाग

सफ्टवेयर भनेको हार्डवेयरलाई के गर्ने भन्ने निर्देशनको सेट हो। छुन मिल्ने हरेक भौतिक भाग हार्डवेयर; छुन नमिल्ने सबै सफ्टवेयर।

सफ्टवेयर नभएको कम्प्युटर पूरा तर बेकामको मेसिन हो। सर्किट तयार छ, पर्दा बलेको छ, तर केही हुँदैन — किनभने प्रोसेसरलाई आफ्ना अर्बौं सम्भावित काममध्ये अब कुन गर्ने कसैले भनेको छैन। हार्डवेयरले क्षमता दिन्छ; सफ्टवेयरले निर्देशन।

एउटै कम्प्युटर बिहान टाइपराइटर र दिउँसो क्यालकुलेटर हुन सक्नुको कारण पनि यही हो। हार्डवेयर बदलिएन, निर्देशन बदलियो।

3.2  Types of software and their features — सफ्टवेयरका किसिम र तिनका विशेषता

Ask who the software is working for

Software divides by who it serves. That one question settles almost every case.

System software serves the computer. It runs the machine itself and makes it usable: the operating system, language translators (compiler, interpreter, assembler) and device drivers. It starts without being asked and most of it you never see.

Application software serves the user. It does the job you sat down to do: word processor, spreadsheet, browser, game, a school's result system. You choose to start it, and the computer runs perfectly well without it.

Utility software sits between them. It serves the computer — cleaning, compressing, scanning for viruses, backing up — but you start it yourself, like an application. Most books treat it as a kind of system software, and a few list it separately. Either is accepted if you say what it does.

सफ्टवेयर कसका लागि काम गर्दै छ सोध्नुहोस्

सफ्टवेयरको भाग कसको सेवा गर्छ भन्नेले निर्धारण हुन्छ। यो एउटै प्रश्नले झन्डै हरेक केस टुङ्ग्याउँछ।

System software ले कम्प्युटर को सेवा गर्छ। मेसिन आफैं चलाउँछ र प्रयोगयोग्य बनाउँछ: operating system, भाषा अनुवादक (compiler, interpreter, assembler) र device driver। नभनिकनै सुरु हुन्छ र धेरैजसो तपाईंले देख्नै पर्दैन।

Application software ले प्रयोगकर्ता को सेवा गर्छ। तपाईं जुन काम गर्न बस्नु भयो त्यही गर्छ: word processor, spreadsheet, browser, खेल, विद्यालयको नतिजा प्रणाली। तपाईंले छानेर खोल्नुहुन्छ, र यो नभए पनि कम्प्युटर राम्रै चल्छ।

Utility software बीचमा पर्छ। सेवा कम्प्युटरकै गर्छ — सफा गर्ने, थिच्ने, भाइरस खोज्ने, ब्याकअप लिने — तर application जस्तै तपाईं आफैं खोल्नुहुन्छ। धेरै पुस्तकले यसलाई system software कै किसिम मान्छन्, केहीले छुट्टै लेख्छन्। के गर्छ भन्यौं भने दुवै मान्य हुन्छ।

Practise the judgement · निर्णय अभ्यास गर्नुहोस्

System, application or utility?

What you will learn: to classify software by who it serves rather than by whether you have heard of it. Two of the cases are the ones students reliably get wrong. तपाईंले के सिक्नुहुन्छ: नाम सुनेको छ कि छैन होइन, कसको सेवा गर्छ हेरेर वर्गीकरण गर्न। दुई केस विद्यार्थीले नियमित रूपमा बिगार्ने खालका छन्।

How to use this

For each case ask: would the computer still work without it? If no, it is system software. If yes but it still looks after the machine, it is a utility. If yes and it does a job for you, it is an application.

हरेक केसमा सोध्नुहोस्: यो नभए पनि कम्प्युटर चल्छ? चल्दैन भने system software। चल्छ तर मेसिनकै हेरचाह गर्छ भने utility। चल्छ र तपाईंको काम गर्छ भने application।

3.3  What an operating system is — Operating system भनेको के हो

Defined by its job, not by its name

An operating system is the system software that controls the hardware, manages the computer's resources, and provides an interface between the user and the machine. Windows, Linux, macOS and Android are examples; none of them is the definition.

Two words in that sentence carry the marks. Resources means the processor's time, the memory, the disk and the devices — all limited, all wanted by several programs at once. Interface means you ask for a file by its name and never need to know which part of which disk it is on.

It is also the first software to load. The hardware starts, finds the operating system, and hands control to it; everything else you run is started by the operating system afterwards.

नामले होइन, कामले परिभाषित

Operating system त्यो system software हो जसले हार्डवेयर नियन्त्रण गर्छ, कम्प्युटरका स्रोत व्यवस्थापन गर्छ, र प्रयोगकर्ता तथा मेसिनबीच इन्टरफेस दिन्छ। Windows, Linux, macOS र Android उदाहरण हुन्; तीमध्ये कुनै पनि परिभाषा होइन।

यो वाक्यका दुई शब्दले अंक बोक्छन्। स्रोत भनेको प्रोसेसरको समय, मेमोरी, डिस्क र उपकरण — सबै सीमित, सबै एकैपटक धेरै प्रोग्रामलाई चाहिने। इन्टरफेस भनेको तपाईंले फाइललाई नामले माग्नुहुन्छ र त्यो कुन डिस्कको कुन भागमा छ जान्नै पर्दैन।

यो लोड हुने पहिलो सफ्टवेयर पनि हो। हार्डवेयर सुरु हुन्छ, OS भेट्छ र नियन्त्रण सुम्पिन्छ; त्यसपछि तपाईंले चलाउने सबै OS ले नै सुरु गर्छ।

3.4  Functions and characteristics of an operating system — Operating system का कार्य र विशेषता

Six jobs, each with something you can point at

Examiners want the function named and then shown. Learn each with its example attached.

  • Process management — decides which program gets the processor and for how long. You see it when music keeps playing while you type.
  • Memory management — gives each program its own area of RAM and takes it back when the program closes. You see it when one program crashing does not erase another's work.
  • File management — creates, names, stores, finds and deletes files, and keeps the folder tree. You see it every time you save by name.
  • Device management — talks to the keyboard, printer and disk through drivers. You see it when a printer works without the program knowing its model.
  • Security — passwords, user accounts, permissions. You see it at the login screen.
  • User interface — the desktop or the command prompt through which you ask for anything at all.

Characteristics are different from functions: an OS is reliable (it must not crash), efficient (it must not waste the resources it is managing), convenient and able to run several programs at once.

छ काम, हरेकसँग देखाउन मिल्ने उदाहरण

परीक्षकले कार्यको नाम र त्यसपछि उदाहरण खोज्छन्। उदाहरण जोडेरै सिक्नुहोस्।

  • Process management — कुन प्रोग्रामले प्रोसेसर कति बेर पाउने तय गर्छ। टाइप गर्दागर्दै गीत बजिरहनुमा यही देखिन्छ।
  • Memory management — हरेक प्रोग्रामलाई RAM को आफ्नै भाग दिन्छ र बन्द भएपछि फिर्ता लिन्छ। एउटा प्रोग्राम क्र्यास हुँदा अर्कोको काम नमेटिनुमा यही देखिन्छ।
  • File management — फाइल बनाउने, नाम राख्ने, राख्ने, खोज्ने, मेट्ने र फोल्डर रुख मिलाउने। नाम दिएर सेभ गर्दा हरेक पटक देखिन्छ।
  • Device management — driver मार्फत keyboard, printer र disk सँग कुरा गर्छ। प्रोग्रामलाई प्रिन्टरको मोडेल थाहै नभई छापिनुमा देखिन्छ।
  • Security — पासवर्ड, प्रयोगकर्ता खाता, अनुमति। लगइन पर्दामा देखिन्छ।
  • User interface — डेस्कटप वा command prompt, जसमार्फत तपाईं केही पनि माग्न सक्नुहुन्छ।

विशेषता कार्यभन्दा फरक हो: OS भरपर्दो हुनुपर्छ (क्र्यास नहुने), दक्ष (आफैंले व्यवस्थापन गरेको स्रोत नखेर फाल्ने), सुविधाजनक, र एकैपटक धेरै प्रोग्राम चलाउन सक्ने।

Predict first · पहिले अनुमान गर्नुहोस्

You open a document, a browser and a music player at the same time on a computer with one processor. Which operating system function makes it look as if all three are running at once? एउटै प्रोसेसर भएको कम्प्युटरमा तपाईंले एकैपटक document, browser र music player खोल्नुभयो। तीनै एकैचोटि चलिरहेको देखिनु कुन OS कार्यले बनाउँछ?

Process management. One processor can run exactly one instruction at a time. The operating system gives each program a slice of processor time — a few milliseconds each — and switches between them so quickly that all three appear continuous to you. Memory management is also happening, and it is what keeps the three programs from overwriting each other, but it is not what creates the appearance of simultaneity. The word for this is multitasking, and it is a scheduling job.

Process management। एउटा प्रोसेसरले एकैपटक एउटै निर्देशन चलाउन सक्छ। OS ले हरेक प्रोग्रामलाई प्रोसेसरको समयको टुक्रा — केही मिलिसेकेन्ड — दिन्छ र यति छिटो फेरिदिन्छ कि तीनै निरन्तर देखिन्छन्। Memory management पनि भइरहेको हुन्छ र त्यसैले तीन प्रोग्रामले एकअर्काको ठाउँ बिगार्दैनन्, तर एकैचोटि चलेको देखावट त्यसले बनाउँदैन। यसको नाम multitasking हो, र यो समय बाँड्ने काम हो।

3.5  Types of operating system — Operating system का किसिम

Each type answers a different pressure

Operating systems are grouped by how many users, how many jobs, and how urgently a job must finish.

  • Single-user, single-tasking — one person, one job at a time. MS-DOS. Simple, and it wastes the processor whenever the user is thinking.
  • Single-user, multi-tasking — one person, several jobs at once. Windows on your own laptop. This is the ordinary case today.
  • Multi-user — several people use one computer at the same time, through terminals or over a network. Unix and Linux servers.
  • Real-time — a job must finish inside a guaranteed time, every time. The computer in an ambulance monitor or an aircraft. Being late is the same as being wrong.
  • Batch — jobs are collected and run together with no user waiting. Payroll and electricity-bill printing, run overnight.
  • Distributed — several computers work together and appear as one system to the user.
हरेक किसिमले फरक दबाबको जवाफ दिन्छ

OS लाई कति प्रयोगकर्ता, कति काम र कति हतारो भन्ने आधारमा समूह बनाइन्छ।

  • Single-user, single-tasking — एक जना, एकैपटक एउटा काम। MS-DOS। सरल, तर प्रयोगकर्ता सोचिरहेको बेला प्रोसेसर खेर जान्छ।
  • Single-user, multi-tasking — एक जना, एकैपटक धेरै काम। आफ्नै ल्यापटपको Windows। आजको सामान्य अवस्था यही हो।
  • Multi-user — धेरै जनाले एउटै कम्प्युटर एकैपटक चलाउँछन्, terminal वा नेटवर्क मार्फत। Unix र Linux सर्भर।
  • Real-time — काम तोकिएकै समयभित्र, हरेक पटक सकिनैपर्छ। एम्बुलेन्सको मोनिटर वा विमानको कम्प्युटर। ढिलो हुनु र गलत हुनु उस्तै हो।
  • Batch — कामहरू जम्मा गरेर सँगै चलाइन्छ, कोही पर्खेर बस्दैन। तलब र बिजुलीको बिल, रातभरि चल्ने।
  • Distributed — धेरै कम्प्युटर मिलेर काम गर्छन् र प्रयोगकर्तालाई एउटै प्रणाली जस्तो देखिन्छ।

3.6  User interface — CUI and GUI — प्रयोगकर्ता इन्टरफेस — CUI र GUI

Typing a command, or pointing at a picture

The user interface is how you tell the computer what you want.

In a CUI — Character User Interface, also called a command-line interface — you type a command and press Enter. dir lists a folder. You must know the command exists and how to spell it; the screen offers no clue.

In a GUI — Graphical User Interface — you point at windows, icons, menus and buttons. Nothing has to be remembered, because everything available is on the screen to be seen.

The examination likes this question because students write only the obvious half: GUI is easier. It is, and it is not the whole answer. CUI is faster for someone who knows the commands, uses far less memory, and — the important one — a typed command can be saved in a file and run again on a thousand computers. You cannot save a sequence of mouse clicks that way. That is why servers are still administered by command line.

आदेश टाइप गर्ने, कि चित्रमा देखाउने

User interface भनेको तपाईंले कम्प्युटरलाई के चाहियो भन्ने तरिका हो।

CUI — Character User Interface, वा command-line interface — मा तपाईं आदेश टाइप गरेर Enter थिच्नुहुन्छ। dir ले फोल्डरको सूची देखाउँछ। आदेश छ भन्ने र कसरी लेख्ने थाहा हुनैपर्छ; पर्दाले केही सुराक दिँदैन।

GUI — Graphical User Interface — मा तपाईं window, icon, menu र button मा देखाउनुहुन्छ। केही सम्झनै पर्दैन, किनभने उपलब्ध सबै कुरा पर्दामै देखिन्छ।

परीक्षालाई यो प्रश्न मन पर्छ किनभने विद्यार्थीले स्पष्ट आधा मात्र लेख्छन्: GUI सजिलो। सजिलो हो, तर पूरा उत्तर होइन। आदेश थाहा भएकालाई CUI छिटो हुन्छ, मेमोरी निकै कम खान्छ, र — मुख्य कुरा — टाइप गरेको आदेश फाइलमा राखेर हजार कम्प्युटरमा फेरि चलाउन सकिन्छ। माउसका क्लिकको शृंखला त्यसरी राख्न मिल्दैन। सर्भर अहिले पनि command line बाटै चलाइनुको कारण यही हो।

Example 1 Rename three hundred files

Question: a school has 300 photographs named IMG_0001.jpg onwards and wants every one renamed to start with Grade9_. Which interface, and why?

Think before opening: how many actions is this in a GUI, and how many in a CUI? Count, do not guess. खोल्नुअघि सोच्नुहोस्: यो काम GUI मा कति कार्य हो, CUI मा कति? अनुमान होइन, गन्नुहोस्।

Working
In a GUI select file, rename, type new name, press Enter = 4 actions × 300 files = about 1200 actions In a CUI one command describing the pattern, run once = 1 action, and it can be saved and reused next year Answer CUI — the work is repetitive and identical, which is exactly what a command describes well Note for renaming ONE file, the GUI wins: you can see the file, and no command has to be remembered

The lesson is not that one interface is better. It is that repetitive work suits a command and one-off work suits a picture — which is why both still exist. पाठ यो होइन कि कुनै एउटा राम्रो हो। दोहोरिने काम आदेशलाई सुहाउँछ, एकपटकको काम चित्रलाई — त्यसैले दुवै अझै छन्।

3.7  Open Source Software (OSS) — खुला स्रोत सफ्टवेयर (OSS)

Open means the source code, not the price

Open source software is software whose source code is published, so that anyone may read it, change it and share their changed version. Linux, LibreOffice, Firefox, GIMP and VLC are examples.

The word that is misread is free. Open source software is usually free of charge, but that is a side effect, not the definition — you may legally sell open source software. What you may not do is take the code away from the people you sell it to. Closed or proprietary software — Windows, MS Office, Photoshop — keeps its source code secret, whether or not you paid for it.

Advantages: usually free, can be studied and modified, faults are found and fixed by many people, and no single company can withdraw it. Disadvantages: no company is obliged to help you, documentation can be thin, and hardware makers may not supply drivers for it.

This matters in Nepal in a specific way: a school that uses open source software is not paying a licence fee for each of its computers, and is not breaking the law to avoid it.

खुला भनेको source code, मूल्य होइन

Open source software त्यो हो जसको source code सार्वजनिक गरिएको हुन्छ — जोसुकैले पढ्न, बदल्न र बदलेको संस्करण बाँड्न पाउँछ। Linux, LibreOffice, Firefox, GIMP र VLC उदाहरण हुन्।

गलत बुझिने शब्द निःशुल्क हो। Open source प्रायः निःशुल्क हुन्छ, तर त्यो परिभाषा होइन, परिणाम हो — open source सफ्टवेयर कानुनी रूपमै बेच्न पाइन्छ। नपाइने कुरा के भने जसलाई बेच्नुभयो उसबाट code लुकाउन मिल्दैन। बन्द वा proprietary सफ्टवेयर — Windows, MS Office, Photoshop — ले पैसा तिरे पनि source code गोप्य राख्छ।

फाइदा: प्रायः निःशुल्क, अध्ययन र परिमार्जन गर्न मिल्ने, धेरैले गल्ती भेट्ने र सच्याउने, र कुनै एउटै कम्पनीले फिर्ता लिन नसक्ने। बेफाइदा: कुनै कम्पनीले सहयोग गर्नैपर्ने बाध्यता छैन, कागजात पातलो हुन सक्छ, र हार्डवेयर बनाउनेले driver नदिन सक्छन्।

नेपालका सन्दर्भमा यसको खास अर्थ छ: open source चलाउने विद्यालयले हरेक कम्प्युटरको लाइसेन्स शुल्क तिर्नु पर्दैन, र त्यो बचाउन कानुन मिच्नु पनि पर्दैन।

Example 2 One computer, three kinds of software

Question: a school computer has Windows, MS-Word, an antivirus, a C compiler and a file-compression tool installed. Classify each, and name the one that would stop the machine working if it were removed.

For each one ask: would the computer still work without it? Write your five answers first — two of them are the ones people get wrong. हरेकका लागि सोध्नुहोस्: यो नभए पनि कम्प्युटर चल्छ? पहिले आफ्ना पाँच उत्तर लेख्नुहोस् — तीमध्ये दुई प्रायः गलत हुन्छन्।

Working
Windows SYSTEM the machine cannot run at all without it C compiler SYSTEM produces machine code the processor needs; serves the MACHINE, not your task MS-Word APPLICATION does the job you sat down to do antivirus UTILITY looks after the machine; you start it compression tool UTILITY maintenance on files, not your task Remove-and-it-stops: WINDOWS. Remove any of the other four and the computer still starts and runs.

The compiler and the antivirus are the two that move. Both are started by a person, which is why they feel like applications — but who starts it is not the test. Who it serves is. सर्ने दुई — compiler र antivirus। दुवै मान्छेले खोल्छ, त्यसैले application जस्तो लाग्छ — तर कसले खोल्छ भन्ने जाँच होइन। कसको सेवा गर्छ भन्ने हो।

Mistakes that cost marks here — यहाँ अङ्क गुमाउने गल्तीहरू

  • Defining an operating system as "Windows". Windows is an example. The definition is about controlling hardware, managing resources and providing an interface.
  • Calling antivirus an application. It serves the machine, not your task — it is utility software.
  • Saying open source means free of cost. It means the source code is open. Free of charge is usual, not required.
  • Writing only "GUI is easier" for a CUI/GUI comparison. Four marks want two advantages each way, and CUI's advantages are speed for an expert, low memory use, and commands that can be saved and repeated.
  • Confusing functions with characteristics of an OS. A function is a job it performs; a characteristic is a quality it has.
OS लाई "Windows" भन्नु: Windows उदाहरण हो; परिभाषा हार्डवेयर नियन्त्रण, स्रोत व्यवस्थापन र इन्टरफेसको हो। Antivirus लाई application भन्नु: यसले मेसिनको सेवा गर्छ — utility software हो। Open source लाई निःशुल्क भन्नु: अर्थ source code खुला हुनु हो। CUI/GUI मा "GUI सजिलो" मात्र लेख्नु: चार अंकले दुवैतिरका दुई–दुई फाइदा खोज्छ। OS का कार्य र विशेषता मिसाउनु: कार्य भनेको गर्ने काम, विशेषता भनेको गुण।

Memory hook — System serves the machine, application serves you, utility serves the machine but waits to be asked. सम्झने तरिका — System ले मेसिनको, application ले तपाईंको सेवा गर्छ; utility ले मेसिनकै गर्छ तर भनेपछि।

2 marks Practice question

What is system software? Give two examples. System software भनेको के हो? दुई उदाहरण दिनुहोस्।

System software is software that controls and manages the computer itself and makes it ready for the user and for application software to run on.

Examples: operating system (Windows, Linux), language translators (compiler, interpreter, assembler), device drivers. Any two.

System software ले कम्प्युटर आफैंलाई नियन्त्रण र व्यवस्थापन गर्छ र प्रयोगकर्ता तथा application चल्न तयार बनाउँछ। उदाहरण: operating system, भाषा अनुवादक, device driver — कुनै दुई।
4 marks Practice question

List any four functions of an operating system. Operating system का कुनै चार कार्य लेख्नुहोस्।

Any four of:

1. Process management — decides which program uses the processor and for how long.
2. Memory management — allocates RAM to each program and reclaims it afterwards.
3. File management — creates, stores, finds and deletes files and folders.
4. Device management — controls input and output devices through drivers.
5. Security — protects the system with user accounts and passwords.
6. Providing a user interface — CUI or GUI.

One mark each. Naming the function is enough, but a short phrase of explanation protects you if the marker wants it.

कुनै चार: process management, memory management, file management, device management, security, user interface दिने। प्रत्येकको एक अंक; नाम लेखे पुग्छ, तर छोटो व्याख्या थपे सुरक्षित हुन्छ।
4 marks Practice question

Differentiate between CUI and GUI with examples. CUI र GUI बीचको फरक उदाहरणसहित लेख्नुहोस्।

CUI (Character User Interface) — the user types commands. It needs the commands to be memorised, uses little memory, is fast for a trained user, and commands can be saved and run again. Example: MS-DOS, the Linux terminal.

GUI (Graphical User Interface) — the user points at windows, icons and menus. Nothing has to be memorised, it is easy for a beginner, but it needs more memory and more processing. Example: Windows, macOS, Android.

Write it as pairs of opposites. Four marks usually means two differences stated from both sides.

CUI — आदेश टाइप गर्ने; आदेश सम्झनुपर्ने, मेमोरी थोरै, दक्ष प्रयोगकर्तालाई छिटो, आदेश सुरक्षित गरेर फेरि चलाउन मिल्ने। उदाहरण: MS-DOS, Linux terminal। GUI — window, icon, menu मा देखाउने; सम्झनै नपर्ने, नयाँलाई सजिलो, तर बढी मेमोरी र प्रशोधन चाहिने। उदाहरण: Windows, macOS, Android।
2 marks Practice question

What is open source software? Write any one advantage. Open source software भनेको के हो? कुनै एक फाइदा लेख्नुहोस्।

Open source software is software whose source code is made publicly available, so that anyone can read it, modify it and redistribute it.

One advantage: it is usually free of cost; or it can be modified to suit a particular need; or faults are found and corrected by a large community.

Do not define it as "free software" — that is a consequence, not the meaning.

Open source software त्यो हो जसको source code सार्वजनिक हुन्छ — जोसुकैले पढ्न, बदल्न र पुनर्वितरण गर्न सक्छ। फाइदा: प्रायः निःशुल्क; वा आवश्यकताअनुसार बदल्न मिल्ने; वा ठूलो समुदायले गल्ती भेटेर सच्याउने। "निःशुल्क सफ्टवेयर" भनेर परिभाषा नलेख्नुहोस्।

Key points from this unit

  • Software is the instructions; hardware is the ability. Neither works alone.
  • System software serves the computer, application software serves the user, utility software serves the computer but is started by the user.
  • An OS controls hardware, manages resources and provides an interface — and is the first software to load.
  • Its functions: process, memory, file, device management, security, user interface.
  • OS types follow the pressure: how many users, how many tasks, how urgent.
  • CUI: memorise, fast, scriptable, light. GUI: see, easy, heavier.
  • Open source = published source code. Free of charge is usual, not the definition.
सफ्टवेयर = निर्देशन, हार्डवेयर = क्षमता। System ले कम्प्युटरको, application ले प्रयोगकर्ताको, utility ले कम्प्युटरकै सेवा गर्छ तर प्रयोगकर्ताले खोल्छ। OS ले हार्डवेयर नियन्त्रण, स्रोत व्यवस्थापन र इन्टरफेस दिन्छ, र सबैभन्दा पहिले लोड हुन्छ। कार्य: process, memory, file, device management, security, user interface। CUI: सम्झने, छिटो, स्क्रिप्ट गर्न मिल्ने, हलुका। GUI: देखिने, सजिलो, गह्रौं। Open source = खुला source code।
